# Bestandsversleuteling

Of een wachtwoord nodig is om het projectbestand te openen.

Dubbelklik op de optie “Bestandsversleuteling” in de “projectbeheerder”; het dialoogvenster van afbeelding 7-12 verschijnt:

<img src="../../setting/file-protect.files/image004.jpg" width="286" />

Afbeelding 7-12    Dialoogvenster bestandsversleuteling

Vink in het dialoogvenster hierboven “Bestand met wachtwoord beveiligen” aan, voer het wachtwoord in en bevestig het, en klik op “OK”.

Opent de gebruiker het project daarna opnieuw, dan verschijnt het wachtwoordvenster van afbeelding 7-13:

<img src="../../setting/file-protect.files/image002.jpg" width="331" alt="ScreenShot00055.jpg" />

Afbeelding 7-13    Wachtwoordvenster

De gebruiker moet het wachtwoord invoeren om het project te openen.
