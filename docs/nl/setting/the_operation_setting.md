# Bedieningsinstellingen

Instellingen voor de bediening van de configuratie:

<img src="../../setting/the_operation_setting.files/image002.jpg" width="360" alt="ScreenShot00056.jpg" />

• Selectiemodus

Gebiedsselectie: een object wordt geselecteerd zodra het met de muis getrokken gebied het object gedeeltelijk bevat

Objectselectie: een object wordt alleen geselecteerd als het met de muis getrokken gebied het object volledig bevat

•  Plakmodus

Plakken met muisklik: na het kopiëren van een object plaatst een klik het geplakte object op de gekozen plek

Plakken op dezelfde positie: na het kopiëren plakt u het object op de plaats van het gekopieerde object

•  Type bestand voor USB-stick extraheren

Versie 6.0: maakt een USB-stickbestand van versie 6.0

Hoger dan 6.0: maakt een USB-stickbestand van een versie hoger dan 6.0
