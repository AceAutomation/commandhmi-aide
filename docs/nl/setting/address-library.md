# Adresbibliotheek

Met de adresbibliotheek geeft de gebruiker een register een alias; de te lezen variabele is dan op twee manieren bereikbaar: via het adreslabel of via het registeradres.

Hieronder het gebruik van de adresbibliotheek

<img src="../../setting/addresslibrary.files/image002.jpg" width="270" alt="ScreenShot00776.jpg" />

Ø  Adreslabels instellen

Dubbelklik op de optie “Adresbibliotheek”; het volgende dialoogvenster verschijnt

Klik op de knop “Nieuw”; het volgende dialoogvenster verschijnt

Beschrijving: voegt een beschrijving toe aan het nieuwe adreslabel, zodat de gebruiker de informatie en het gebruik van de variabele kan nalezen

Label: het zelfgedefinieerde adreslabel is een alias voor het register; door het label te kiezen gebruikt u het register

Adrestype: gegevenstype van de alias; er zijn slechts twee opties

Adres: het registeradres dat aan het label is gekoppeld

Aantal adressen: de gebruiker kan labels in bulk toevoegen; de labelfunctie ondersteunt momenteel alleen afzonderlijke variabelen, geen arrays
