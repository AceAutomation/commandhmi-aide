# HTTP

<img src="../../setting/lisanbaojing.files/image007.jpg" width="133" alt="lisanbaojing2414" /> Alleen het scherm op afstand ondersteunt deze functie

![](../../setting/http.files/open.png)

Met deze functie configureert de gebruiker eenvoudig de parameters van de HTTP-server

Ø  Pagina “Algemeen”

<img src="../../setting/http.files/general.png" width="606" />

- Naam

Verbindingsnaam

- URL

De doel-URL van het HTTP-verzoek

- Methode

Methode van het HTTP-verzoek: GET of POST

- Codering

Coderingsformaat

- Request header

Header van het HTTP-verzoek

- Time-out

Antwoordtijd HTTP

- Formaten

JSON (algemeen) of JSON (geavanceerd), [zoals bij 【MQTT】](mqtttheme.md#anchor-name)

- Verzendmodi

automatisch of via bittrigger

Ø  Pagina “Adres” (JSON algemeen)

Instelbaar als op de pagina \[Algemeen\] het formaat \[JSON algemeen\] is gekozen.

Voegt een waarde toe. Het type kan bit of woord zijn; de waarde kan vast zijn of van een opgegeven adres worden gelezen. [Zie 【MQTT】](mqtttheme.md#anchor-name1)

Ø  Pagina “JSON verzenden” (JSON geavanceerd)

Instelbaar als op de pagina \[Algemeen\] het formaat \[JSON geavanceerd\] is gekozen.
<img src="../../setting/http.files/sendjson.png" width="606" />

Stelt de te verzenden gegevens in. De adresinstelling ondersteunt een boomstructuur met componenten, arrays enz.; tijdstempel en gegevensnaam kunnen ook worden aangepast. [Zie 【MQTT】](mqtttheme.md#anchor-name1)

Ø  Pagina “JSON ontvangen”

<img src="../../setting/http.files/receivejson.png" width="606" />

Stelt de te ontvangen gegevens in. De adresinstelling ondersteunt een boomstructuur met componenten, arrays enz.; tijdstempel en gegevensnaam kunnen ook worden aangepast. Zie [【JSON verzenden】](#anchor-name)

Ø  Pagina “Beveiliging”

Zie de pagina \[Beveiliging\] bij [\[MQTT\].](mqtttheme.md#anchor-name2)
