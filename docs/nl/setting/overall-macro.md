# Globaal script

Maakt van een met succes gecompileerd script een globaal script: het wordt uitgevoerd zodra de configuratie start en blijft tijdens de werking draaien, ongeacht het scherm. Er kunnen maximaal 64 globale scripts worden toegevoegd, die in de ingestelde volgorde worden uitgevoerd.

Klik in het menu “Instellingen” op “Globaal script”; het dialoogvenster verschijnt:

<img src="../../setting/overall-macro.files/overall-macro384.png" width="437" />

Klik op het lijstitem om alle met succes gecompileerde scripts te tonen en bepaal of het script door een bit wordt bestuurd en met welke frequentie het wordt uitgevoerd. Het gekozen script wordt tijdens de werking als globaal script uitgevoerd.
