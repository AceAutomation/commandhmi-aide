# Initialisatiescript

Maakt van een met succes gecompileerd script een initialisatiescript: het script wordt één keer uitgevoerd, ongeacht het scherm. Er kunnen maximaal 64 initialisatiescripts worden toegevoegd, die in de ingestelde volgorde worden uitgevoerd.

Klik in het menu “Instellingen” op “Initialisatiescript”; het dialoogvenster verschijnt:

<img src="../../setting/init-macro.files/init-macro309.png" width="436" />

Klik op het lijstitem om alle met succes gecompileerde scripts te tonen. Het gekozen script wordt tijdens de werking als initialisatiescript uitgevoerd.
