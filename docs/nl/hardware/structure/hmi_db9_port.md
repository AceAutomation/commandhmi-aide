# Pintoewijzing

Pintoewijzing van de 9-polige communicatiepoort, zoals in de afbeelding hieronder:

<img src="../../../hardware/structure/hmi_db9_port.files/image002.jpg" width="473" alt="pin.jpg" />

9-polige communicatiepoort

Deze poort dient voor de aansluiting van PLC's of andere besturingen met een RS232/RS422/RS485-communicatiepoort

|     |       |       |       |
|-----|-------|-------|-------|
| Pin | RS232 | RS422 | RS485 |
| 1   |       |       |       |
| 2   | RX    |       |       |
| 3   | TX    |       |       |
| 4   |       |       |       |
| 5   | GND   |       |       |
| 6   |       | RX-   |       |
| 7   |       | RX+   |       |
| 8   |       | TX-   | B     |
| 9   |       | TX+   | A     |
