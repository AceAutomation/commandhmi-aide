# Communicatiepoort

De communicatiepoorten van de HMI zitten in het onderpaneel.

Met een afgeschermde kabel mag de RS232-communicatieafstand niet meer dan 15 meter zijn. Voor de verbinding met de computer is er een USB-interface voor het downloaden van de configuratie (gegevensoverdracht), met een snelheid tot 10 Mbps. De aansluiting van de communicatie-interface verschilt per aangesloten PLC (vermeld bij de bestelling het type PLC, zodat de juiste communicatiekabel kan worden geleverd).
