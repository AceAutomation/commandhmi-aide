# Het project uploaden

De software CommandHMI kan het project van de HMI naar de harde schijf uploaden. Verbind de HMI met de pc, kies in het dialoogvenster “Projectbestand uploaden”; het venster “Samdraw-bestand uploaden” verschijnt.

![](../../start-new-project/upload-project.files/001.png)

• Bestandspad: klik op “Bladeren” om het opslagpad te kiezen.

• Projectnaam: naam van het project.

• Uploaden starten: klik op “Bestand uploaden” om te beginnen.

Na een geslaagde upload kunt u kiezen of het projectbestand wordt geopend.

<img src="../../start-new-project/upload-project.files/upload-project507.png" width="130" />

Het geüploade bestand moet worden uitgepakt voordat het kan worden geopend.
