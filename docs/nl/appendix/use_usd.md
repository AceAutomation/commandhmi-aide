# Project bijwerken via USB-stick

HMI's uit de HM-serie kunnen het project importeren en bijwerken via een USB-stick.

**Het projectbestand bijwerken via USB-stick**

**1. Project compileren**

Start CommandHMI, open het bij te werken project en klik op <img src="../../appendix/use_usd.files/image002.jpg" width="71" /> om het gecompileerde bestand aan te maken.

**2. Klik op “Project opslaan als” in het menu “Download” en kies de doelmap**

Het bestand u-disk-prj.bin wordt in de gekozen map opgeslagen.

**3. Gecompileerd bestand naar de USB-stick kopiëren**

Open de map en kopieer u-disk-prj.bin naar de USB-stick.

**4. USB-stick in de HMI steken**

**5. Bestand kopiëren en project bijwerken**

Steek de USB-stick in de HMI en klik in het pop-upvenster op YES om bij te werken.

**6. HMI opnieuw starten om het bijwerken te voltooien**

Schakel de voeding uit en weer in of start de HMI opnieuw met de knop “Opnieuw starten” op het scherm.

<img src="../../appendix/use_usd.files/image006.gif" width="595" />

Opmerking

 • Verwijder de USB-stick niet tijdens het bijwerken;

• Houd de HMI ingeschakeld tijdens het bijwerken.
