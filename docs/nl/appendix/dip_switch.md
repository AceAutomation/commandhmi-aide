# DIP-schakelaars

Elke HMI uit de HM-serie heeft DIP-schakelaars, elk met een eigen functie.

<img src="../../appendix/dip_switch.files/image004.gif" width="212" />

**Functies van de DIP-schakelaars**

|                   |                             |
|-------------------|-----------------------------|
| DIP-schakelaar (5-1) | Functie                    |
| Alle op OFF           | Normale bedrijfsmodus       |
| 1 op ON              | Kalibratiemodus coördinaten |
| 2 op ON              | Parameterweergave      |
| 1 en 2 op ON       | Terminalmodus               |
| 1 en 3 op ON      | Parameterinstelling      |

<img src="../../appendix/dip_switch.files/image005.gif" width="595" />

Opmerking:

Na het verzetten van de DIP-schakelaars moet de HMI opnieuw worden gestart;

Gebruik bij normaal gebruik van de HMI de normale bedrijfsmodus;

In de modus parameterinstelling worden tijd, helderheid en IP-adres ingesteld.
