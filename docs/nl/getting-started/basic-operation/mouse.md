Bij het maken van configuratieschermen in de schermeditor wordt de muis gebruikt zoals in afbeelding 2-45:

Afbeelding 2-45        Schema van de muis

Hieronder enkele gangbare muisbewerkingen en hun doel:

◎ Linksklikken

Linkerknop indrukken en loslaten<span id="OLE_LINK219"></span><span id="OLE_LINK218"></span>: in deze handleiding \[klikken\] genoemd; gebruikt om menu's te kiezen, objecten te selecteren, werkbalkknoppen te kiezen, configuratieschermen te bewerken en instellingen te bevestigen.

◎ Dubbelklikken

Linkerknop twee keer snel achter elkaar indrukken: in deze handleiding \[dubbelklikken\] genoemd; gebruikt om eigenschappen van bestaande elementen in het scherm in te stellen: scherm- en venstereigenschappen, verbindingseigenschappen van het touchscreen, objecteigenschappen; en om instellingen te wijzigen van de historische gegevensverzamelaar, recepten, alarmen en andere opties.

◎ Rechtsklikken

Rechterknop indrukken en loslaten: in deze handleiding \[rechtsklikken\] genoemd. Rechtsklikken op een element opent het contextmenu ervan; rechtsklikken op een lege plek opent het algemene contextmenu. U kunt er ook de bewerkingsmodus mee verlaten en de muisaanwijzer herstellen.

◎ Slepen

De muis bewegen met ingedrukte knop: in deze handleiding \[slepen\] genoemd; met slepen selecteert u meerdere items, verplaatst u elementen en verschuift u bewerkingsvensters.

|-------------------|-----------------------------------------------------|
| CTRL+C            | Copy                                                |
| CTRL+V            | Plakken                                               |
| CTRL+X            | Cut                                                 |
| CTRL+F            | Schermwissel                                        |
| Ctrl + slepen       | Geselecteerd object kopiëren en verplaatsen                 |
| Ctrl + linksklik | Meerdere objecten selecteren                             |
| ← → ↑ ↓           | Geselecteerd object naar links/rechts/boven/onder verplaatsen |
| ESC               | Bewerking ongedaan maken                                  |
