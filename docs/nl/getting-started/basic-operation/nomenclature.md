# Gangbare begrippen

Tabel 2-3 hieronder geeft enkele gangbare begrippen bij het configureren.

|                   |                                                                                                                                                                                                                                                                                                                                 |
|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Project           | Afkorting van de toepassing van de gebruiker. Het begrip project maakt complexe computerkennis toegankelijker voor engineers. Bestanden die met CommandHMI worden aangemaakt, hebben de extensie .vpm en kunnen op elke gewenste locatie worden opgeslagen.                                                            |
| Object            | Bediende elementen en hun omgeving heten samen object: vensters, componenten, gegevens, grafische elementen en objecten                                                                                                                                                                                                    |
| Object selecteren | Een venster of object met een muisklik bedienbaar maken heet een object selecteren; het geselecteerde object (ook een venster) heet het huidige object                                                                                                                                                                   |
| Configuratie     | Objecten in een vensteromgeving definiëren, aanmaken en bewerken en hun statuskenmerken (eigenschappen) instellen                                                                                                                                                                                                                         |
| Attribuut         | Naam, soort, status, eigenschappen en gebruik heten samen attribuut                                                                                                                                                                                                                                                     |
| Menu              | Een groep opdrachten. Het systeemmenu “Bestand” bevat bijvoorbeeld de opdrachten voor projectbestanden. Alle menu’s van CommandHMI zijn vervolgkeuzemenu’s die meerdere niveaus kunnen hebben; elk niveau heet submenu |
| Opdrachtknop    | Knoppen voor bepaalde opdrachten, deels in de werkbalk en deels in de menubalk                                                                                                                                                                                                                             |
| ON zetten            | Zet een object met bitstatusweergave in de status “ON”                                                                                                                                                                                                                                                                          |
| OFF zetten           | Zet een object met bitstatusweergave in de status “OFF”                                                                                                                                                                                                                                                                         |
| Stijl             | Overgangseffect van een object van voorgrond- naar achtergrondkleur                                                                                                                                                                                                                                                       |
| Adres           | Geheugenvariabelen van het huidige object                                                                                                                                                                                                                                                                                  |
| Aangesloten apparaat | Communicatieapparaten in het huidige project                                                                                                                                                                                                                                                                              |
| Object           | Groep bepaalde functies                                                                                                                                                                                                                                         |
