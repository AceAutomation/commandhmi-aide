# Systeemopbouw

CommandHMI is de configuratiesoftware voor de HMI's van CommandHMI. Engineers bewerken de configuratie op de pc en downloaden daarna de definitieve configuratie en het benodigde communicatiestuurprogramma via een USB-kabel naar het geheugen van het touchscreen. Aangesloten op PLC's of andere apparaten via de seriële communicatiepoorten kunnen de HMI's deze besturen en bewaken. Afbeelding 2-44 toont de systeemopbouw van CommandHMI.
