# Softwarevereisten

De configuratiesoftware CommandHMI werkt op de volgende besturingssystemen:

· Microsoft Windows NT Server 4.0 of hoger;

· Microsoft Windows NT Workstation 4.0 of hoger;

· Microsoft Windows 98, Me, 2000, XP, Windows 7 of hoger.

<img src="../../../getting-started/system-requirements/sw-requirements.files/image002.jpg" width="130" />

CommandHMI weigert de installatie op andere versies van het besturingssysteem.

<span id="OLE_LINK52"></span><span id="OLE_LINK53"></span>**Aanbevolen systemen:**

Windows XP SP3; Windows 7 32 bits; Windows 7

Er is geen verschil tussen een Chinees en een Engels besturingssysteem.
