# De software installeren

CommandHMI is een toepassing voor Microsoft Windows. Controleer vóór de installatie of de computer aan de minimale hardware- en softwarevereisten voldoet.

Start het meegeleverde installatieprogramma om CommandHMI te installeren. Werkwijze:

Download het installatieprogramma van de officiële website;

![2018_11_19_19_32_06.jpg](../../getting-started/install.files/setup.png)

Afbeelding 2-1      Installatiepakket CommandHMI

Na een dubbelklik op het programma verschijnt automatisch het installatievenster van CommandHMI.

Het eerste dialoogvenster is de “Licentieovereenkomst”; kies “Volgende” om de installatie voort te zetten of “Annuleren” om het installatieprogramma af te sluiten, zoals in afbeelding 2-2.

Kies “Ik ga akkoord met de overeenkomst” en klik daarna op “Volgende”.

<img src="../../getting-started/../image/2025-10-11/setup-1.png" width="513" alt="ScreenShot00201.jpg" />

Afbeelding 2-2      Dialoogvenster Licentieovereenkomst

Kies in het dialoogvenster “Doelmap” de installatiemap. De standaardmap is "C:\Program Files (x86)\CommandHMI"; met “Bladeren...” kiest u een ander pad; klik daarna op “Volgende”

  <img src="../../getting-started/../image/2025-10-11/setup-3.png" width="513" alt="ScreenShot00202.jpg" />
