# Scherm verwijderen

Met deze opdracht verwijdert u een scherm uit het huidige project, als volgt:

Kies “Scherm verwijderen” in het menu “Scherm”; of kies in de projectbeheerder met de linkermuisknop het te verwijderen scherm en kies met de rechtermuisknop “Verwijderen”; of klik met de rechtermuisknop op een lege plek in het scherm zonder geselecteerd object om het contextmenu met de opdracht “Verwijderen” te openen.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen407.png" width="382" />

Afbeelding 4-4 Scherm verwijderen

Klik op “OK” om het verwijderen te voltooien.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen483.png" width="130" />

Een verwijderd scherm kan niet worden teruggehaald! Gebruik deze opdracht voorzichtig.
