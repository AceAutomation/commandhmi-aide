# GIF-weergave

De GIF-weergave toont afbeeldingen in GIF-formaat met maximaal 32 frames. Werkwijze:

Klik op het pictogram GIF<img src="../../../configuration-guide/extended-controls/gif-display.files/image002.jpg" width="29" /> in de werkbalk om het dialoogvenster van afbeelding 4-48 te openen.

Afbeelding 4-48    Dialoogvenster GIF-weergave

Klik na het instellen van de eigenschappen op “OK”; in het bewerkingsgebied wordt de muisaanwijzer een kruis; teken met de linkermuisknop een rechthoek om het object aan het werkgebied (het scherm) toe te voegen

Kies de pagina “Geavanceerd” om de eigenschappen te tonen.

![](../../../configuration-guide/extended-controls/gif-display.files/image004.jpg)

Afbeelding 4-49    Pagina “Geavanceerd” van de GIF-weergave

Bitgestuurd: indien aangevinkt en de “Actieve status” 1, wordt de GIF-afbeelding alleen geanimeerd als het “Stuurbit” 1 is; anders wordt ze statisch getoond. Is de “Actieve status” 0, dan wordt ze alleen geanimeerd als het “Stuurbit” 0 is; anders statisch.

<img src="../../../configuration-guide/extended-controls/gif-display.files/image005.jpg" width="130" />

Zie voor de pagina “Zichtbaarheid” het gebruik van het object “Bit-knop”.
