# Draaien

Deze opdracht werkt op groepen. De bewerkingssoftware CommandHMI kan een of meer grafische objecten onder elke hoek draaien. Draaibaar zijn lijnen, cirkels, rechthoeken, elementen uit de systeembibliotheek, objecten, groepen en veelhoeken.

• **Horizontaal spiegelen**

“Horizontaal spiegelen” draait het geselecteerde object (of meerdere) 180° rond de verticale middenas. Selecteer een of meer grafische objecten en klik op “Horizontaal spiegelen” onder “Spiegelen” in het menu “Bewerken”, of op de knop Horizontaal spiegelen in de werkbalk<img src="../../../configuration-guide/edit-graph/turn.files/turn649.png" width="27" />.

• **Verticaal spiegelen**

“Verticaal spiegelen” draait het geselecteerde object (of meerdere) 180° rond de horizontale middenas. Selecteer een of meer grafische objecten en klik op “Verticaal spiegelen” onder “Spiegelen” in het menu “Bewerken”, of op de knop Verticaal spiegelen in de werkbalk<img src="../../../configuration-guide/edit-graph/turn.files/turn1297.png" width="26" />.

• Draaien

Momenteel ondersteunen alleen deze 12 objecten deze functie:

Tijdweergave, datumweergave, weekdagweergave, statische afbeelding, GIF-weergave, afbeelding, numerieke weergave, numerieke invoer, ASCII-weergave, ASCII-invoer, meerstandenlamp, meerstandenschakelaar

Draait het geselecteerde object 360° rond zijn middelpunt. Selecteer een object en klik op “Draaien” in het menu “Bewerken”, of op de draaiknop in de werkbalk<img src="../../../configuration-guide/edit-graph/turn.files/image001.jpg" width="36" alt="ScreenShot00091.jpg" />
