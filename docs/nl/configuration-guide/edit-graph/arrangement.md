# Lagen

De opdracht “Lagen” werkt op groepen. Ze regelt de weergavevolgorde van overlappende grafische objecten. Elk object in CommandHMI heeft een niveau: hogere objecten worden altijd boven lagere getoond, en met deze opdracht wijzigt u die volgorde. Een nieuw object krijgt standaard een hoger niveau dan de bestaande. “Lagen” omvat vier opdrachten: <span id="OLE_LINK363"></span><span id="OLE_LINK364"></span>Naar voren halen, Naar voren, Naar achteren sturen en Naar achteren. Selecteer een of meer grafische objecten op het huidige scherm en kies de opdracht in het menu “Bewerken” of in de werkbalk.

• **Naar voren halen**

Deze opdracht brengt het geselecteerde object naar de bovenste laag, zodat het de overlappende delen bedekt.

Kies een object uit meerdere grafische elementen en daarna “Naar voren halen” in het menu “Bewerken”, de knop<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement956.png" width="27" /> in de werkbalk of “Naar voren halen” onder “Lagen” in het snelmenu. Vergelijking voor/na: afbeelding 4-8.
