# Uitlijnen

Deze opdracht werkt op groepen, net als “Grootte”. De software CommandHMI kan meerdere grafische objecten uitlijnen en van grootte veranderen, maar alleen als er meerdere zijn geselecteerd. Selecteer ze met ingedrukte Ctrl-toets of door met de linkermuisknop een kader te trekken. Uitlijnen omvat vele opdrachten: links, rechts, verticaal centreren, horizontaal centreren, boven, onder, gelijke horizontale afstand, gelijke verticale afstand, gelijke breedte, gelijke hoogte, gelijke hoogte en breedte, enz.

• <img src="../../../configuration-guide/edit-graph/align.files/align610.png" width="33" />**Boven**

Uitlijnen “Boven” lijnt meerdere grafische objecten (minstens twee) boven uit via “Boven” onder “Uitlijnen” in het menu “Bewerken” of via het snelmenu. De objecten nemen de hoogste bovenrand als referentie en komen op dezelfde hoogte. Vergelijking voor/na: afbeelding 4-16:

• <img src="../../../configuration-guide/edit-graph/align.files/align3248.png" width="32" />**Gelijke breedte**

Deze opdracht geeft meerdere grafische objecten (minstens twee) dezelfde breedte via “Gelijke breedte” onder “Grootte” in het menu “Bewerken” of via het snelmenu. De objecten worden vanuit hun linkerbovenhoek verkleind of vergroot zonder hun hoogte te veranderen, zodat hun breedte gelijk wordt aan die van het eerst geselecteerde object (omringd door zwarte puntjes; de andere hebben groene puntjes).
