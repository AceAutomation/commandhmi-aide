# Groeperen en groep opheffen

De opdracht “Groeperen” werkt op groepen: ze voegt 2 of meer grafische objecten en objecten van het huidige scherm samen tot één object. De gegroepeerde elementen kunnen door de ontwerper getekende elementen zijn, elementen uit de systeembibliotheek of andere objecten, zoals alarmen, trends enz. Na het groeperen behoudt elk object zijn eigenschappen, die wijzigbaar blijven. “Groep opheffen” splitst een groep in de oorspronkelijke elementen: de omgekeerde bewerking van “Groeperen”.
