# Stappenknop

Met deze opdracht maakt u in het huidige scherm een stappenknop die cyclisch door de statussen schakelt. Klik op het pictogram<img src="../../../configuration-guide/new_add_control/steping.files/image002.jpg" width="31" /> om het dialoogvenster van afbeelding 4-113 te openen:

<img src="../../../configuration-guide/new_add_control/steping.files/image004.jpg" width="675" />

Afbeelding 4-113   Dialoogvenster stappenknop

Volgorde statussen: richting van de tekst op het object

Is het totale aantal statussen bijvoorbeeld 3, dan zijn de teksten van status 0, 1 en 2 respectievelijk 0, 1, 2.

• Van links naar rechts: het object staat horizontaal en de tekst loopt van links naar rechts: 0, 1, 2

• Van rechts naar links: het object staat horizontaal en de tekst loopt van rechts naar links: 2, 1, 0

• Van boven naar beneden: het object staat verticaal en de tekst loopt van boven naar beneden: 0, 1, 2

• Van beneden naar boven: het object staat verticaal en de tekst loopt van beneden naar boven: 2, 1, 0

Type status: zie de “Meerstandenlamp”.

Huidige status: achtergrond- en tekstkleur van de tekst in de huidige status.

Zie voor de pagina's “Tekst” en “Afbeelding” de “Meerstandenlamp”.

Zie voor de pagina “Geavanceerd” en de sneltoetsen de Bit-knop.

Voorbeeld: type status “Waarde”, schrijfadres LW1, totaal aantal statussen 3 en de teksten van status 0, 1 en 2 respectievelijk 0, 1 en 2. Na het downloaden van het project naar de HMI schakelt het object bij elke klik door de statussen 0-2 en wordt de bijbehorende waarde naar LW1 geschreven.
