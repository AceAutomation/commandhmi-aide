# Keuzerondje

Met deze opdracht maakt u in het huidige scherm een keuzerondje om naar een door de gebruiker gekozen status te schakelen. Klik op het pictogram<img src="../../../configuration-guide/new_add_control/singlebutton.files/image002.gif" width="26" /> om het dialoogvenster van afbeelding 4-114 te openen:

Afbeelding 4-114   Dialoogvenster keuzerondje

Volgorde statussen: richting van de tekst op het object

Is het totale aantal statussen bijvoorbeeld 3, dan zijn de teksten van status 0, 1 en 2 respectievelijk 0, 1, 2.

• Van links naar rechts: het object staat horizontaal en de tekst loopt van links naar rechts: 0, 1, 2

• Van rechts naar links: het object staat horizontaal en de tekst loopt van rechts naar links: 2, 1, 0

• Van boven naar beneden: het object staat verticaal en de tekst loopt van boven naar beneden: 0, 1, 2

• Van beneden naar boven: het object staat verticaal en de tekst loopt van beneden naar boven: 2, 1, 0

Type status: zie de “Meerstandenlamp”.

Huidige status: achtergrond- en tekstkleur van de tekst in de huidige status.

Zie voor de pagina's “Tekst” en “Afbeelding” de “Meerstandenlamp”.

Zie voor “Geavanceerd” en “Zichtbaarheid” de Bit-knop.
