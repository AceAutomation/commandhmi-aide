# Boogdiagram

Het boogdiagram (ook sectordiagram genoemd) werkt zoals het wijzerinstrument: het leest en toont de waarde van het bewakingsadres. Het reactiegebied wordt weergegeven met de “voorgrondkleur sector”, de “achtergrondkleur sector” en het “patroon”.
