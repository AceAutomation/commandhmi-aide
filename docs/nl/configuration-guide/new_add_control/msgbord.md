# Schrijfbord

Schrijfbord: een object waarop de gebruiker kan schrijven. Het pictogram in de werkbalk is: <img src="../../../configuration-guide/new_add_control/msgbord.files/image002.jpg" width="26" />. Klik erop om het dialoogvenster van afbeelding 4-121 te openen.

Afbeelding 4-121   Pagina “Algemeen” van het schrijfbord

• Lijnkleur: kleur van de op het object geschreven tekst

• Lijndikte: dikte van de schrijflijn

• Bedrijfsmodus:

Adres bedrijfsmodus: een woordadres, alleen geldig bij de waarde 0 of 1. De waarde 0 staat voor schrijven, 1 voor gummen.

Het woordadres neemt 3 opeenvolgende adressen in: het eerste bestuurt de bedrijfsmodus (0 schrijven, 1 gummen), het tweede de lijndikte en het derde de RGB-kleur van de pen.

• Scherm wissen

Adres scherm wissen: is de waarde gelijk aan de ingestelde status voor wissen (0 of 1), dan wordt alles wat op het object geschreven is automatisch gewist

Zie voor de pagina “Zichtbaarheid” de “Bit-knop”.
