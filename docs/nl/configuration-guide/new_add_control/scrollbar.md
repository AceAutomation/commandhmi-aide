# Schuifbalk

De schuifbalk is een object om door de gegevens van tabelobjecten te bladeren, zodat de gebruiker snel door de tabelgegevens kan gaan. Alleen de volgende objecten worden ondersteund: alarmweergave, weergave historische alarmen, receptweergave, weergave historische gegevens, bedieningslogboek

Het object wordt gebruikt als het gekoppelde object te veel gegevens heeft om ze in één keer volledig te tonen, en laat dan de rest van de gegevens zien

Dialoogvenster schuifbalk

De functies van het object worden hieronder beschreven (het object kent twee soorten: schuifknoppen en schuifbalk)

Ø  Schuifbalk: bladert met een schuifbalk door de tabelgegevens

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image005.jpg" width="859" alt="ScreenShot00820.jpg" />

l  Achtergrondkleur: achtergrondkleur van het object

l  Symboolkleur: kleur van de symbolen van het object

l  Richting: richting waarin de schuifbalk door de tabelgegevens bladert

n  Horizontaal: bladert horizontaal door de tabelgegevens

n  Verticaal: bladert verticaal door de tabelgegevens

l  Nummer gekoppeld object: staat op het huidige scherm een van de hierboven genoemde objecten, dan kan het worden gekoppeld zodat de schuifbalk erop werkt. Staat er geen van deze objecten op het scherm, dan verschijnt de foutmelding “Het gekoppelde object mag niet leeg zijn”. Het objectnummer is het nummer linksboven op het object.

Ø  Schuifknoppen: bladert met knoppen door de tabelgegevens

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image006.jpg" width="859" alt="ScreenShot00821.jpg" />

l Randkleur: randkleur van het object

l  Achtergrondkleur: achtergrondkleur van het object

l  Symboolkleur: kleur van de symbolen in het object

l  Richting

n  Horizontaal: bladert horizontaal door de tabelgegevens

n  Verticaal: bladert verticaal door de tabelgegevens

l  Nummer gekoppeld object: zie de beschrijving hierboven

l Functietoetsen

n  Knopafstand: ruimte tussen de knoppen

n  Naar begin / naar einde: zet de tabelgegevens op het begin of het einde. Staan de gegevens al aan het begin of einde, dan meldt een venster bij een klik dat de bewerking ongeldig is

n  Pagina omhoog / omlaag of links / rechts: verschuift telkens één pagina

n  Omhoog / omlaag of links / rechts: verschuift telkens één gegeven in de betreffende richting

n  Pauze: veranderen de tabelgegevens, dan stopt een klik op deze knop de wijzigingen; een tweede klik herstelt de oorspronkelijke toestand. Staat de tabel al vast, dan verandert er niets en meldt een venster dat de functie ongeldig is.
