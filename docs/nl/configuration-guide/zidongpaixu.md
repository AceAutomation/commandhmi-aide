# Automatisch sorteren

Met de opdracht “Automatisch sorteren” sorteert u de schermen in het huidige project. Werkwijze:

De opdracht automatisch sorteren sorteert de schermnummers in het huidige project. Werkwijze:

Selecteer in de projectbeheerder met de linkermuisknop de optie “Scherm”, kies met de rechtermuisknop “Automatisch sorteren”; het instellingenvenster verschijnt. Vink “Automatisch sorteren” aan en klik op “OK” om de schermen te sorteren (oplopend).
