# Datumweergave

Het object datumweergave toont de systeemdatum. Klik op het pictogram <img src="../../../configuration-guide/basic-control/date.files/image002.jpg" width="31" /> in de werkbalk; het dialoogvenster van afbeelding 4-106 verschijnt:

<img src="../../../configuration-guide/basic-control/date.files/image005.jpg" width="675" />

Afbeelding 4-106   Dialoogvenster Datumweergave

• Formaat: er zijn negen datumformaten beschikbaar.

YYYY-MM-DD

MM-DD-YYYY

DD-MM-YYYY

YYYY/MM/DD

MM/DD/YYYY

DD/MM/YYYY

YYYY.MM.DD

MM.DD.YYYY

DD.MM.YYYY

• Lettertype: lettertype van de tekst

• Lettergrootte: grootte van de weergave

• Kleur: kleur van de tekst

• Uitlijning: positie van de weergave: links, midden of rechts.

<span id="OLE_LINK738"></span><span id="OLE_LINK739"></span><span id="OLE_LINK749"></span>Klik na de instellingen op “OK” om het object aan het werkgebied (het scherm) toe te voegen
