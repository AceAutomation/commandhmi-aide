# Afbeeldingsweergave

De afbeeldingsweergave is een uitbreiding van de statische afbeelding: die toont één afbeelding, de afbeeldingsweergave tot 32. De werking hangt af van het gekozen statustype.

Werkwijze:

Klik op het pictogram afbeeldingsweergave<img src="../../../configuration-guide/basic-control/picture-display.files/image002.jpg" width="32" /> in de werkbalk. Het dialoogvenster van afbeelding 4-110 verschijnt:

Afbeelding 4-110   Dialoogvenster Afbeeldingsweergave

• Bit: bij “Bit” zijn er slechts twee statussen, 0 en 1. Het bewakingsadres kan alleen een bitadres zijn. Het object toont de afbeelding van status 0 of 1 van dat adres.

• Waarde: bij “Waarde” kunnen er tot 2048 statussen zijn en worden verschillende afbeeldingen getoond naar de waarde van het bewakingsadres. Is die 0, dan wordt de afbeelding van status 0 getoond, enz.

• Automatisch wisselen: met deze optie kunnen er tot 2048 statussen zijn en hangt het object niet af van het bewakingsadres: stel alleen het totale aantal statussen en de wisselfrequentie in. Op de HMI wisselt het object dan automatisch binnen dat bereik van afbeelding.

<img src="../../../configuration-guide/basic-control/picture-display.files/image004.jpg" width="130" />

Opmerking: de pagina “Afbeelding” van de afbeeldingsweergave is vergelijkbaar met die van de “Meerstandenlamp”.

Opmerking: zie voor de “Zichtbaarheid” het object “Bit-knop”.

Klik na de instellingen op “OK” om het object aan het werkgebied (het scherm) toe te voegen.
