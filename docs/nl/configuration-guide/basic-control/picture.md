# Statische afbeelding

Het object statische afbeelding toont een afbeelding in diverse formaten, uit een bestand of uit de bibliotheek. Het kan als schermachtergrond dienen om het project te verfraaien.

1\. Klik op het pictogram statische afbeelding<img src="../../../configuration-guide/basic-control/picture.files/image002.jpg" width="30" /> in de werkbalk; het dialoogvenster van afbeelding 4-109 verschijnt:

<img src="../../../configuration-guide/basic-control/picture.files/image004.jpg" width="675" />

Afbeelding 4-109   Dialoogvenster Statische afbeelding

2\. Kies een afbeelding en klik op “OK”; de muisaanwijzer wordt een kruis. Klik met de linkermuisknop op het scherm om het afbeeldingsobject toe te voegen.

3\. De grootte van de ingevoegde afbeelding kan met de muis worden aangepast. De configuratiesoftware CommandHMI ondersteunt de formaten JPG, BMP, PNG, WMF, EMF en GIF.
