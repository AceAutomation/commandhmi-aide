# Tijdweergave

Het object tijdweergave toont de systeemtijd. Klik op het pictogram<img src="../../../configuration-guide/basic-control/time.files/image002.jpg" width="31" />; het dialoogvenster van afbeelding 4-105 verschijnt.

Afbeelding 4-105    Dialoogvenster Tijdweergave

<img src="../../../configuration-guide/basic-control/time.files/image004.jpg" width="130" />

Opmerking: zie voor vorm, randkleur, voorgrondkleur, achtergrondkleur en patroon het object Bit-knop.

• Formaat: vier tijdformaten beschikbaar.

HH:MM                Uur: minuut

HH:MM:SS           Uur: minuut: seconde

HH-MM-SS           Uur- minuut- seconde

HH-MM                Uur- minuut

• Lettertype: lettertype van de tekst

• Lettergrootte: grootte van de weergave

• Kleur: kleur van de tekst

• Uitlijning: positie van de weergave: links, midden of rechts.

Klik na de instellingen op “OK” om het object aan het werkgebied (het scherm) toe te voegen
