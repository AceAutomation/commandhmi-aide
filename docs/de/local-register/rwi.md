# RWI

RWI

|                  |                         |                                                                        |
|------------------|-------------------------|------------------------------------------------------------------------|
| Registeradresse | Bedeutung                 | Note                                                                   |
| RWI0             | Rezeptnummernregister | Zeigt das Rezept mit der angegebenen Rezeptnummer an.                   |
| RWI1             | Rezept-Speicheradresse  | Gibt eine Rezeptnummer an, deren Rezeptdaten in RWI angezeigt werden. |
