# DIP-Schalter

Jedes HMI der HM-Serie besitzt DIP-Schalter mit jeweils eigener Funktion.

<img src="../../appendix/dip_switch.files/image004.gif" width="212" />

**Funktionen der DIP-Schalter**

|                   |                             |
|-------------------|-----------------------------|
| DIP-Schalter (5-1) | Funktion                    |
| Alle aus           | Normaler Betriebsmodus      |
| 1 ein              | Koordinatenkalibrierung     |
| 2 ein              | Parameteranzeige            |
| 1 und 2 ein        | Terminalmodus               |
| 1 und 3 ein        | Parametereinstellung        |

<img src="../../appendix/dip_switch.files/image005.gif" width="595" />

Hinweis:

Nach dem Verstellen der DIP-Schalter muss das HMI neu gestartet werden;

Für den normalen Gebrauch des HMI den normalen Betriebsmodus verwenden;

Im Modus Parametereinstellung werden Uhrzeit, Helligkeit und IP-Adresse eingestellt.
