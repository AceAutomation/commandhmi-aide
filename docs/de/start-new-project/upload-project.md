# Projekt hochladen (Upload)

CommandHMI unterstützt das Hochladen des Projekts vom HMI auf die Festplatte. Verbinden Sie das HMI mit dem PC und wählen Sie im Dialogfeld „Projektdatei hochladen“; es öffnet sich die Oberfläche „Samdraw-Datei hochladen“.

![](../../start-new-project/upload-project.files/001.png)

• Dateipfad: Klicken Sie auf „Durchsuchen“, um den Speicherpfad zu wählen.

• Projektname: Name des Projekts.

• Hochladen starten: Klicken Sie auf „Datei hochladen“.

Nach erfolgreichem Hochladen kann die Projektdatei direkt geöffnet werden.

<img src="../../start-new-project/upload-project.files/upload-project507.png" width="130" />

Die hochgeladene Datei muss vor dem Öffnen entpackt werden.
