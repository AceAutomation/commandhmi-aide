# Packen/Entpacken

Wählen Sie im Menü „Download“ den Befehl „<span id="OLE_LINK272"></span><span id="OLE_LINK273"></span>Packen/Entpacken“, um das Dialogfeld zu öffnen.

<img src="../../start-new-project/compression.files/image002.jpg" width="668" />

• Datei packen: packt die HM-Projektdatei in eine komprimierte Datei mit der Endung .sip. Verwendete externe Grafiken werden mit eingepackt. Wird die komprimierte Datei auf einen anderen Computer übertragen, sind die Grafiken nach dem Entpacken vorhanden. Wird dagegen nur die Projektdatei übertragen, fehlen die externen Grafiken auf dem anderen Computer, da der ursprüngliche Pfad nicht gefunden wird.

• Speicherpfad: <span id="OLE_LINK276"></span><span id="OLE_LINK277"></span>Speicherort der komprimierten Datei; wählen Sie den Pfad, klicken Sie auf „Komprimieren“ und schließen Sie das Fenster, wenn der Fortschrittsbalken 100 % erreicht.

• Datei entpacken: entpackt eine Datei .vpr in eine Datei .vpm, die direkt in CommandHMI geöffnet werden kann.

• Komprimierte Datei: Wahl der zu entpackenden Datei.

• Speicherpfad: Speicherort der entpackten Datei .vpm; wählen Sie den Pfad, klicken Sie auf „Entpacken“ und schließen Sie das Fenster, wenn der Fortschrittsbalken 100 % erreicht.
