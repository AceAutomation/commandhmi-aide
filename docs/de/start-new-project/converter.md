# Historische Daten hochladen

Starten Sie die Projektierungssoftware CommandHMI und klicken Sie auf <img src="../../start-new-project/converter.files/converter46.png" width="29" />.

![](../../start-new-project/converter.files/001.png)

„Historische Daten hochladen“ überträgt die Daten vom HMI auf die Festplatte.

• Dateipfad: Speicherort; wählen Sie ihn mit „Durchsuchen“.

• Dateiname: Name der hochgeladenen Datei; sie kann nicht direkt geöffnet werden, ein Konvertierungswerkzeug ist nötig. Siehe „Historische Daten und Alarme auf USB-Stick exportieren“ im Anhang der Hilfe.

• Klicken Sie auf „Datei hochladen“; die Datei wird am eingestellten Ort gespeichert.

• CommandHMI unterstützt neu mehrere Gruppen historischer Daten: Beim Hochladen wird zusätzlich zur Datenbankdatei jede Gruppe als .CSV-Datei gespeichert. Beispiel: Beim Hochladen der Datei „temp“ heißt die Datenbankdatei „temp“, die CSV-Datei der Gruppe 0 „temp_hisdata0.csv“, die der Gruppe 1 „temp_hisdata1.csv“ usw.

<img src="../../start-new-project/converter.files/converter954.png" width="130" />

Das Hochladen historischer Daten funktioniert wie das Hochladen von Rezepten und Projektdateien; die Konvertierung von Samdraw3.3 nach CommandHMI ist deaktiviert.
