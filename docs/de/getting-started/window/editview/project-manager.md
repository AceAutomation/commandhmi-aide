# Projektmanager

Der Projektmanager von CommandHMI befindet sich links im Fenster der Projektierungssoftware unter der Werkzeugleiste. Hier werden die Parameter des Touchscreens eingestellt: Mehrsprachigkeit, Verbindung, Einstellungen, Bild, Fenster, historischer Datensammler, Alarme, Rezepte, Datenübertragung und Skripte. „Verbindung“ umfasst die Einstellungen von Verbindung 1 und 2; „Einstellungen“ umfasst HMI-Parameter, HMI-Status, Steuerung durch die SPS, Uhr, Dateiverschlüsselung, HMI-Schutz und Variablentabelle.
