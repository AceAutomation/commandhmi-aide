# Softwarevoraussetzungen

Die Projektierungssoftware CommandHMI läuft unter folgenden Betriebssystemen:

· Microsoft Windows NT Server 4.0 oder höher;

· Microsoft Windows NT Workstation 4.0 oder höher;

· Microsoft Windows 98, Me, 2000, XP, Win7 oder höher.

<img src="../../../getting-started/system-requirements/sw-requirements.files/image002.jpg" width="130" />

Bei anderen Betriebssystemversionen verweigert CommandHMI die Installation.

<span id="OLE_LINK52"></span><span id="OLE_LINK53"></span>**Empfohlene Systeme:**

Windows XP SP3; Windows 7 32 Bit; Windows 7

Es gibt keinen Unterschied zwischen chinesischem und englischem Betriebssystem.
