# Hardwarevoraussetzungen

Mindestanforderungen an die Hardware für CommandHMI:

CPU: mindestens Pentium 3 mit 800 MHz;

Arbeitsspeicher: unter Windows 9X mindestens 128 MB;

<span id="OLE_LINK68"></span><span id="OLE_LINK69"></span><span id="OLE_LINK60"></span><span id="OLE_LINK61"></span>Unter Windows NT mindestens 256 MB Arbeitsspeicher;

Unter Windows 2000 oder XP mindestens 256 MB Arbeitsspeicher;

Grafik: <span id="OLE_LINK71"></span><span id="OLE_LINK70"></span>Windows-<span id="OLE_LINK62"></span><span id="OLE_LINK63"></span>kompatibel, mehr als 1 MB Grafikspeicher, Auflösung 1024 \* 768, 256 Farben;

Festplatte: CommandHMI belegt mindestens 200 MB.

Computer mit USB-Anschluss;

Maus mit zwei Tasten und Tastatur.

<img src="../../../getting-started/system-requirements/hw-requirements.files/image002.jpg" width="130" />

Liegt die Ausstattung des Computers darunter, kann die Installation oder Ausführung von CommandHMI fehlschlagen.

**Empfohlene Ausstattung:**

CPU: Intel Pentium 800 oder gleichwertig bzw. höher;

Arbeitsspeicher: unter Windows 9X mindestens 256 MB;

Unter Windows NT mindestens 512 MB Arbeitsspeicher;

Unter Windows 2000 oder XP mindestens 512 MB Arbeitsspeicher.

Grafikkarte: Windows-kompatibel, mehr als 1 MB Grafikspeicher, Auflösung 1024 \* 768, 65535 Farben.

Festplatte: mindestens 200 MB frei.
