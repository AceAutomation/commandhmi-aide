# Software installieren

CommandHMI ist eine Anwendung für Microsoft Windows. Prüfen Sie vor der Installation, ob Software und Hardware des Computers die Mindestanforderungen erfüllen.

Installieren Sie CommandHMI mit dem mitgelieferten Installationsprogramm wie folgt:

Laden Sie das Installationsprogramm von der offiziellen Website herunter;

![2018_11_19_19_32_06.jpg](../../getting-started/install.files/setup.png)

Abbildung 2-1      Installationspaket von CommandHMI

Nach einem Doppelklick auf das Programm öffnet sich automatisch das Installationsfenster von CommandHMI.

Das erste Dialogfeld ist „Lizenzvereinbarung“; klicken Sie auf „Next“, um fortzufahren, oder auf „Cancel“, um die Installation abzubrechen, wie in Abbildung 2-2.

Wählen Sie „I accept the agreement“; dann können Sie auf „Next“ klicken.

<img src="../../getting-started/../image/2025-10-11/setup-1.png" width="513" alt="ScreenShot00201.jpg" />

Abbildung 2-2      Dialogfeld Lizenzvereinbarung

Wählen Sie im Dialogfeld „Zielordner“ den Installationsordner. Standard ist „C:\Program Files (x86)\CommandHMI“; über „Browse...“ wählen Sie einen anderen Pfad, dann klicken Sie auf „Next“

  <img src="../../getting-started/../image/2025-10-11/setup-3.png" width="513" alt="ScreenShot00202.jpg" />

Abbildung 2-5      Auswahl des Installationspfads

Nach „Next“ in Abbildung 2-5 erscheint die Auswahl des Speicherorts der Dateien (Standard oder anderer); klicken Sie auf „Next“, wie in Abbildung 2-6:

<img src="../../getting-started/../image/2025-10-11/setup-3.1.png" width="513" alt="ScreenShot00203.jpg" />

Abbildung 2-6      Auswahl der Installationsdateien

Im Fenster „Desktopverknüpfung erstellen“ klicken Sie auf „Next“, wie in Abbildung 2-7:

<img src="../../getting-started/../image/2025-10-11/setup-4.png" width="513" alt="ScreenShot00204.jpg" />

Abbildung 2-7      Desktopverknüpfung erstellen

Das Bestätigungsfenster zeigt drei Angaben: Installationspfad, zu installierende Dateien und ob eine Verknüpfung erstellt wird.

  <img src="../../getting-started/../image/2025-10-11/setup-5.png" width="513" alt="ScreenShot00205.jpg" />

Abbildung 2-8      Installationsbestätigung
