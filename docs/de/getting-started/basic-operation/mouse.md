Die wichtigsten Mausaktionen und ihr Zweck:

◎ Linksklick

Linke Taste drücken und loslassen<span id="OLE_LINK219"></span><span id="OLE_LINK218"></span> – in diesem Handbuch \[Klick\] genannt. Damit wählen Sie Menüs, Objekte und Werkzeugschaltflächen, bearbeiten Bilder und bestätigen Einstellungen.

◎ Doppelklick links

Linke Taste zweimal schnell hintereinander drücken – in diesem Handbuch \[Doppelklick\] genannt. Damit öffnen Sie die Eigenschaften vorhandener Elemente: Bild- und Fenstereigenschaften, Verbindungseigenschaften des Touchscreens, Einstellungen; ebenso die Einstellungen von historischem Datensammler, Rezepten, Alarmen und anderen Objekten.

◎ Rechtsklick

Rechte Taste drücken und loslassen – in diesem Handbuch \[Rechtsklick\] genannt. Ein Rechtsklick auf ein Element öffnet dessen Kontextmenü, ein Rechtsklick auf eine freie Stelle das allgemeine Kontextmenü. Außerdem beendet er den Bearbeitungsmodus und stellt den normalen Mauszeiger wieder her.

◎ Ziehen

Maus bei gedrückter Taste bewegen – in diesem Handbuch \[Ziehen\] genannt. Durch Ziehen wählen Sie mehrere Elemente aus, verschieben Elemente und bewegen Bearbeitungsfenster.

### <span id="OLE_LINK225"></span><span id="OLE_LINK224"></span>Tastenkürzel

Tabelle 2-2 listet häufige Tastenkürzel auf, mit denen die Projektierung schneller geht.

|                   |                                                     |
|-------------------|-----------------------------------------------------|
| CTRL+C            | Copy                                                |
| CTRL+V            | Einfügen                                               |
| CTRL+X            | Cut                                                 |
| CTRL+F            | Bildwechsel                                        |
| Strg + Ziehen       | Ausgewähltes Objekt kopieren und verschieben                 |
| Strg + Linksklick | Mehrere Objekte auswählen                             |
| ← → ↑ ↓           | Ausgewähltes Objekt nach links/rechts/oben/unten verschieben |
| ESC               | Vorgang rückgängig machen                                  |
|                   | Löschen                                              |
