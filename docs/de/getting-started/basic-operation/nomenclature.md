# Begriffe

Tabelle 2-3 erläutert einige Begriffe der Projektierung.

|                   |                                                                                                                                                                                                                                                                                                                                 |
|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Projekt           | Kurz für die Anwendung des Benutzers. Der Projektbegriff macht komplexes Computerwissen für Ingenieure einfacher handhabbar. In CommandHMI angelegte Dateien haben die Endung .vpm und können an beliebigem Ort gespeichert werden.                                                            |
| Objekt            | Bedienziele und Bedienumgebung heißen zusammen Objekt, z. B. Fenster, Komponenten, Daten, Grafiken und Objekte                                                                                                                                                                                                    |
| Objekt auswählen | Ein Fenster oder Objekt per Mausklick bedienbar machen heißt Objekt auswählen; das ausgewählte Objekt (auch Fenster) heißt aktuelles Objekt                                                                                                                                                                   |
| Projektierung     | Objekte in einer Fensterumgebung definieren, anlegen und bearbeiten und ihre Zustandsmerkmale (Eigenschaften) festlegen                                                                                                                                                                                                                         |
| Attribut         | Name, Art, Zustand, Eigenschaften und Verwendung heißen zusammen Attribut                                                                                                                                                                                                                                                     |
| Menu              | Eine Gruppe von Befehlen. Das Systemmenü „Datei“ etwa enthält die Befehle für Projektdateien. Alle Menüs von CommandHMI sind Pulldown-Menüs, die sich in mehrere Ebenen gliedern können; jede Ebene heißt Untermenü |
| Befehlsschaltfläche    | Schaltflächen für bestimmte Befehle, teils in der Werkzeugleiste, teils in der Menüleiste                                                                                                                                                                                                                             |
| Set ON            | Schaltet ein Objekt mit Bitstatusanzeige auf „ON“                                                                                                                                                                                                                                                                          |
| Set OFF           | Schaltet ein Objekt mit Bitstatusanzeige auf „OFF“                                                                                                                                                                                                                                                                         |
| Stil             | Übergangseffekt eines Objekts von der Vorder- zur Hintergrundfarbe                                                                                                                                                                                                                                                       |
| Adresse           | Speichervariablen des aktuellen Objekts                                                                                                                                                                                                                                                                                  |
| Angeschlossenes Gerät | Im aktuellen Projekt angeschlossene Kommunikationsgeräte                                                                                                                                                                                                                                                                              |
| Objekt           | Gruppe bestimmter Funktionen                                                                                                                                                                                                                                         |
