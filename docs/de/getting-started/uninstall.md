# Software deinstallieren

Um die Projektierungssoftware CommandHMI zu deinstallieren, gehen Sie wie folgt vor:

**Methode 1:**

Schritt 1: Öffnen Sie den Installationsordner von CommandHMI; dort finden Sie unins000.exe.

Siehe Abbildung 2-13:

<img src="../../getting-started/../image/2025-10-11/uninstall-0.png" width="500" alt="ScreenShot00208.jpg" />

Abbildung 2-13        unins000.exe

Schritt 2: Doppelklicken Sie auf unins000.exe, klicken Sie im Dialogfeld auf „Yes“ und warten Sie, bis Windows CommandHMI automatisch entfernt hat. Klicken Sie danach auf „Finish“, wie in Abbildung 2-14 und 2-15:

<img src="../../getting-started/../image/2025-10-11/uninstall-2.png" width="496" alt="ScreenShot00210.jpg" />

Abbildung 2-14        Deinstallation bestätigen

![ScreenShot00212.jpg](../../getting-started/../image/2025-10-11/uninstall-3.png)

Abbildung 2-15        Deinstallation abgeschlossen

**Methode 2:**

Schritt 1: Wählen Sie in Windows „Start“ - „Einstellungen“ - „Systemsteuerung“ und dann „Software“ (Programme hinzufügen/entfernen), wie in Abbildung 2-16

<img src="../../getting-started/../image/2025-10-11/uninstall-1.png" width="600" alt="ScreenShot00209.jpg" />

Abbildung 2-16        Programme hinzufügen/entfernen

Schritt 2: Wählen Sie links in Abbildung 2-16 CommandHMI, klicken Sie auf „Ändern/Entfernen“ und folgen Sie Schritt 2 und 3 der ersten Methode. Das System entfernt die Projektierungssoftware CommandHMI und ihre Komponenten automatisch.
