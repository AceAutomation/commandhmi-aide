# Adressbibliothek

Mit der Adressbibliothek erhält ein Register einen Alias: Der Benutzer greift auf die Variable entweder über das Adresslabel oder über die Registeradresse zu.

Verwendung der Adressbibliothek:

<img src="../../setting/addresslibrary.files/image002.jpg" width="270" alt="ScreenShot00776.jpg" />

Ø  Adresslabel anlegen

Doppelklicken Sie auf „Adressbibliothek“; es öffnet sich folgendes Dialogfeld

Klicken Sie auf „Neu“; es öffnet sich folgendes Dialogfeld

Beschreibung: Beschreibung des angelegten Adresslabels, damit Bedeutung und Verwendung der Variablen leicht erkennbar sind

Befehl: Das benutzerdefinierte Adresslabel ist ein Alias für das Register; bei der Adresseingabe wird dieser Alias gewählt, um das Register zu verwenden

Adresstyp: Datentyp des Alias; nur zwei Optionen

Adresse: Registeradresse, die dem Label zugeordnet ist

Anzahl: Labels können in Serie angelegt werden; ein Label bezieht sich jedoch nur auf eine einzelne Variable, nicht auf ein Array

Ø  Adresslabel verwenden
