# Globales Skript

Ein erfolgreich kompiliertes Skript wird als globales Skript festgelegt: Es wird beim Start des Projekts ausgeführt und läuft während der gesamten Laufzeit, unabhängig von den Bildern. Bis zu 64 globale Skripte können hinzugefügt werden; sie werden in der eingestellten Reihenfolge ausgeführt.

Klicken Sie im Menü „Einstellungen“ auf „Globales Skript“; es öffnet sich folgendes Dialogfeld:

<img src="../../setting/overall-macro.files/overall-macro384.png" width="437" />

Ein Klick auf das Listenelement zeigt alle erfolgreich kompilierten Skripte; legen Sie dann fest, ob das Skript durch ein Bit gesteuert wird und mit welcher Häufigkeit es ausgeführt wird. Das gewählte Skript wird zur Laufzeit als globales Skript ausgeführt.
