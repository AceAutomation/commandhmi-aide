# Textbibliothek

Die Textbibliothek legt eine gemeinsame Textsammlung an und erspart wiederholte Texteingaben.

<img src="../../setting/textlibrary.files/image009.jpg" width="826" alt="ScreenShot00769.jpg" />

Kurze Einführung in die Verwendung.

1.      Daten der Textbibliothek anlegen

<img src="../../setting/textlibrary.files/image010.jpg" width="315" alt="ScreenShot00768.jpg" />

Legen Sie die Daten der Textbibliothek und die Anzahl der Zustände fest

<img src="../../setting/textlibrary.files/image011.jpg" width="826" alt="ScreenShot00770.jpg" />

Doppelklicken Sie in der jeweiligen Sprache auf das Eingabefeld, um die Daten einzugeben

2.      Textbibliothek in einem Objekt verwenden

Beispiel Schalter: Aktivieren Sie die Textbibliothek, wählen Sie die Sprache und dann den entsprechenden Text

<img src="../../setting/textlibrary.files/image012.jpg" width="675" alt="ScreenShot00771.jpg" />

<img src="../../setting/textlibrary.files/image013.jpg" width="675" alt="ScreenShot00772.jpg" />

<img src="../../setting/textlibrary.files/image014.jpg" width="675" alt="ScreenShot00773.jpg" />

3.      Unterschiedliche Texte je Zustand derselben Variablen

     Hat das Objekt mehrere Zustände, wechselt es automatisch zum Text der Bibliothek, der dem jeweiligen Zustand entspricht; wird z. B. der Schalter betätigt, wechselt der Text automatisch zu Zustand 1
