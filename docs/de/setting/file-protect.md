# Dateiverschlüsselung

Legt fest, ob zum Öffnen der Projektdatei ein Passwort nötig ist.

Doppelklicken Sie im Projektmanager auf „Dateiverschlüsselung“; es öffnet sich das Dialogfeld in Abbildung 7-12:

<img src="../../setting/file-protect.files/image004.jpg" width="286" />

Abbildung 7-12    Dialogfeld Dateiverschlüsselung

Aktivieren Sie „Datei mit Passwort schützen“, geben Sie Passwort und Bestätigung ein und klicken Sie auf „OK“.

Beim erneuten Öffnen des Projekts erscheint dann ein Passwortfeld, wie in Abbildung 7-13:

<img src="../../setting/file-protect.files/image002.jpg" width="331" alt="ScreenShot00055.jpg" />

Abbildung 7-13    Passworteingabe

Zum Öffnen des Projekts muss das Passwort eingegeben werden.
