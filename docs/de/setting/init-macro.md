# Initialisierungsskript

Ein erfolgreich kompiliertes Skript wird als Initialisierungsskript festgelegt: Es wird nur einmal ausgeführt, unabhängig von den Bildern. Bis zu 64 Initialisierungsskripte können hinzugefügt werden; sie werden in der eingestellten Reihenfolge ausgeführt.

Klicken Sie im Menü „Einstellungen“ auf „Initialisierungsskript“; es öffnet sich folgendes Dialogfeld:

<img src="../../setting/init-macro.files/init-macro309.png" width="436" />

Ein Klick auf das Listenelement zeigt alle erfolgreich kompilierten Skripte. Das gewählte Skript wird zur Laufzeit als Initialisierungsskript ausgeführt.
