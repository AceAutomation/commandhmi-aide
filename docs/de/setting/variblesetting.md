# Variablentabelle

Eine Variable wird mit einer Adresse definiert; bei ihrer Verwendung wird die zugehörige Adresse angesprochen. Doppelklicken Sie im Projektmanager auf „Variablentabelle“; es öffnet sich das Dialogfeld in Abbildung 7-15:

<img src="../../setting/variblesetting.files/variblesetting735.png" width="614" />

Abbildung 7-15    Dialogfeld Variablentabelle

• Neu: fügt eine Variable hinzu; höchstens 1000

• Löschen: löscht die gewählte Variable.

• Ändern: ändert die gewählte Variable (auch per Doppelklick).

• Alle löschen: löscht alle Variablen.

• Importieren: öffnet einen Öffnen-Dialog zum Import einer Variablentabelle.

• Exportieren: öffnet einen Speichern-Dialog zum Export der aktuellen Variablentabelle.

<img src="../../setting/variblesetting.files/variblesetting1256.png" width="277" />

Abbildung 7-16    Dialogfeld neue Variable

• Variablenname: Name der neuen Variable.

• Adresstyp: Datentyp der Adresse.

• Adresse: zugeordnete Adresse.
