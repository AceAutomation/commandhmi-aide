# Bedieneinstellungen

Bedieneinstellungen der Projektierung:

<img src="../../setting/the_operation_setting.files/image002.jpg" width="360" alt="ScreenShot00056.jpg" />

• Auswahlmodus

Bereichsauswahl: Ein Objekt wird ausgewählt, wenn der mit der Maus aufgezogene Bereich einen Teil davon enthält

Objektauswahl: Ein Objekt wird nur ausgewählt, wenn der mit der Maus aufgezogene Bereich es vollständig enthält

•  Einfügemodus

Einfügen per Mausklick: Nach dem Kopieren wird das Objekt an der angeklickten Stelle eingefügt

Einfügen an gleicher Position: Nach dem Kopieren wird das Objekt neben der Position des kopierten Objekts eingefügt

•  Dateityp der USB-Extraktion (diHM)

Version 6.0: erzeugt eine diHM-Datei der Version 6.0

Höher als Version 6.0: erzeugt eine diHM-Datei einer Version höher als 6.0
