# Bildeigenschaften ändern

Um die Eigenschaften des Bildes wie Name und Hintergrundfarbe zu ändern, gehen Sie wie folgt vor:

Ist kein Objekt ausgewählt (klicken Sie auf eine freie Stelle im aktuellen Bild), wählen Sie den Befehl <img src="../../../configuration-guide/screen/edit-screen.files/edit-screen760.png" width="26" /> in der Werkzeugleiste, oder wählen Sie das Bild im Projektmanager und klicken Sie mit der rechten Maustaste darauf, oder klicken Sie bei nicht ausgewähltem Objekt mit der rechten Maustaste in das Bild und wählen Sie im Kontextmenü „Eigenschaften“.

<img src="../../../configuration-guide/screen/edit-screen.files/edit-screen1019.png" width="522" />

Abbildung 4-3      Bildeigenschaften

 Legen Sie im Dialogfeld „Neues Bild“ Name, Hintergrundfarbe und die Einstellungen für gemeinsame Bilder fest und klicken Sie auf OK. Standardname eines neuen Bildes ist die Bildnummer.

Standard: Hintergrundfarbe, Vordergrundfarbe und Stil des Bildes.

Grafik: Eine Grafik kann als Hintergrund verwendet werden.

Einstellungen für gemeinsame Bilder

Standardbild: legt ein normales Bild an.

Als gemeinsames Bild festlegen: legt ein gemeinsames Bild an, dessen Objekte in anderen Bildern verwendet werden können; ihre Eigenschaften lassen sich aber nur in diesem Bild ändern.

Gemeinsames Bild verwenden: verwendet ein angelegtes gemeinsames Bild, ohne die Eigenschaften seiner Objekte zu ändern.
