# Bild kopieren

Mit diesem Befehl wird ein Bild des aktuellen Projekts kopiert:

Klicken Sie im Projektmanager mit der linken Maustaste auf das zu kopierende Bild, wählen Sie im Kontextmenü (Rechtsklick) „Kopieren“ und danach im Kontextmenü „Einfügen“ (Abbildung 4-5).

Es entsteht ein neues Bild als Kopie des gewählten.
