# Bild löschen

Mit diesem Befehl wird ein Bild des aktuellen Projekts gelöscht:

Wählen Sie „Bild löschen“ im Menü „Bild“, oder wählen Sie das Bild im Projektmanager mit der linken Maustaste und dann „Löschen“ per Rechtsklick, oder klicken Sie bei nicht ausgewähltem Objekt mit der rechten Maustaste auf eine freie Stelle im Bild und wählen Sie im Kontextmenü „Löschen“.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen407.png" width="382" />

Abbildung 4-4 Bild löschen

Klicken Sie auf OK, um das Löschen abzuschließen.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen483.png" width="130" />

Ein gelöschtes Bild kann nicht wiederhergestellt werden! Verwenden Sie diesen Befehl mit Vorsicht.
