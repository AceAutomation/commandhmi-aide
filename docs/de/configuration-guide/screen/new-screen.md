# Neues Bild anlegen

Mit „Neues Bild“ wird im aktuellen Projekt ein neues Bild angelegt:

1\. Wählen Sie den Befehl „Neues Bild“ im Menü „Bild“, klicken Sie auf die Schaltfläche <img src="../../../configuration-guide/screen/new-screen.files/new-screen210.png" width="39" />, oder klicken Sie im Projektmanager mit der rechten Maustaste auf „Bild“ und wählen Sie „Bild hinzufügen“, wie in Abbildung 4 -1:

<img src="../../../configuration-guide/screen/new-screen.files/new-screen328.png" width="260" />

Abbildung 4-1 Neues Bild

2\. Legen Sie im Dialogfeld „Neues Bild“ Name und Hintergrundfarbe fest und klicken Sie auf OK. Standardname ist die Bildnummer, Standard-Hintergrundfarbe Blau, wie in Abbildung 4-2:

<img src="../../../configuration-guide/screen/new-screen.files/new-screen581.png" width="517" />

Abbildung 4-2 Dialogfeld Bild hinzufügen

Standard: normales Bild

Gemeinsam: Ein gemeinsames Bild kann mehrfach verwendet werden; die Eigenschaften seiner Objekte lassen sich nur in diesem Bild ändern

Gemeinsames verwenden: verwendet ein angelegtes gemeinsames Bild, dessen Objekteigenschaften dort nicht geändert werden können

Hintergrundfarbe, Vordergrundfarbe und Muster des neuen Bildes sind einstellbar.

Grafik: Eine Grafik kann als Hintergrund des neuen Bildes festgelegt werden.
