# GIF-Anzeige

Die GIF-Anzeige zeigt Bilder im GIF-Format mit höchstens 32 Frames an. Vorgehen:

Klicken Sie auf das Symbol GIF <img src="../../../configuration-guide/extended-controls/gif-display.files/image002.jpg" width="29" /> in der Werkzeugleiste, um das Dialogfeld in Abbildung 4-48 zu öffnen.

Abbildung 4-48    Dialogfeld GIF-Anzeige

Klicken Sie nach den Einstellungen auf „OK“; im Bearbeitungsbereich wird der Mauszeiger zum Kreuz. Ziehen Sie mit der linken Maustaste ein Rechteck auf, um das Objekt in den Ansichtsbereich (das Bild) einzufügen

Auf der Seite „Erweitert“ werden die weiteren Eigenschaften angezeigt.

![](../../../configuration-guide/extended-controls/gif-display.files/image004.jpg)

Abbildung 4-49    Seite „Erweitert“ der GIF-Anzeige

Bitgesteuert: Ist „Bitgesteuert“ aktiviert und der „Gültige Zustand“ 1, wird das GIF nur animiert, wenn das „Steuerbit“ 1 ist, sonst statisch angezeigt; ist der „Gültige Zustand“ 0, wird es nur animiert, wenn das „Steuerbit“ 0 ist, sonst statisch angezeigt.

<img src="../../../configuration-guide/extended-controls/gif-display.files/image005.jpg" width="130" />

Zur Seite „Sichtbarkeit“ siehe Objekt „Bit-Taste“.
