# ASCII-Anzeige

Die ASCII-Anzeige zeigt ASCII-Zeichen aus dem Gerät an.

Klicken Sie auf das Symbol ASCII-Anzeige <img src="../../../configuration-guide/basic-control/asc-display.files/image002.jpg" width="29" />; es öffnet sich das Dialogfeld in Abbildung 4-99:

Abbildung 4-99    Dialogfeld ASCII-Anzeige

In diesem Dialogfeld legen Sie die Überwachungsadresse des verbundenen Geräts, die Schriftgröße des angezeigten Textes und weitere Eigenschaften fest.

• Überwachungsadresse (Monitor Address): Die unter dieser Adresse gespeicherten Daten werden in Echtzeit angezeigt, oder es können Daten in diese Adresse eingegeben werden.

• Anzahl (Total): Maximale Anzahl angezeigter Zeichen.

• Schriftgröße: Schriftgröße der angezeigten Zeichen

<span id="OLE_LINK711"></span><span id="OLE_LINK710"></span>• High- und Low-Byte der Eingabe tauschen: High- und Low-Byte des eingegebenen Werts werden vertauscht und das Ergebnis in der überwachten Wortadresse gespeichert.

<span id="OLE_LINK713"></span><span id="OLE_LINK712"></span>• Passwort: Ist diese Option aktiviert, zeigt das Objekt statt der Zeichen Sternchen (\*) an

• UNICODE verwenden: Der Wert der Überwachungsadresse wird in Unicode-Kodierung angezeigt

Ausrichtung:

• Links: Die <span id="OLE_LINK703"></span><span id="OLE_LINK702"></span>Zeichen werden im linken Teil des Anzeigebereichs dargestellt.

• Mitte: Die Zeichen werden in der Mitte des Anzeigebereichs dargestellt.

• Rechts: Die Zeichen werden im rechten Teil des Anzeigebereichs dargestellt.

Hinweis: Ist das Objekt transparent eingestellt, ist die Hintergrundfarbe wirkungslos.
