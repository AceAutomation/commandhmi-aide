# Datumsanzeige

Das Objekt Datumsanzeige zeigt das Systemdatum an. Klicken Sie auf das Symbol <img src="../../../configuration-guide/basic-control/date.files/image002.jpg" width="31" /> in der Werkzeugleiste; es erscheint das Dialogfeld in Abbildung 4-106:

<img src="../../../configuration-guide/basic-control/date.files/image005.jpg" width="675" />

Abbildung 4-106   Dialogfeld Datumsanzeige

• Format: Neun Datumsformate stehen zur Auswahl.

YYYY-MM-DD

MM-DD-YYYY

DD-MM-YYYY

YYYY/MM/DD

MM/DD/YYYY

DD/MM/YYYY

YYYY.MM.DD

MM.DD.YYYY

DD.MM.YYYY

• Schriftart: Schriftart des Textes

• Schriftgröße: Schriftgröße der Anzeige

• Farbe: Textfarbe der Anzeige

• Ausrichtung: Position der Anzeige: links, mittig oder rechts.

<span id="OLE_LINK738"></span><span id="OLE_LINK739"></span><span id="OLE_LINK749"></span>Klicken Sie nach den Einstellungen auf „OK“, um das Objekt in den Ansichtsbereich (das Bild) einzufügen

<img src="../../../configuration-guide/basic-control/date.files/image004.jpg" width="130" />

Hinweis: Form, Rahmenfarbe, Vordergrundfarbe, Hintergrundfarbe und Muster siehe Objekt „Bit-Taste“.
