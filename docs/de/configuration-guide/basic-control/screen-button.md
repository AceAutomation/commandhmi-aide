# Bildwechsel-Taste

Die Bildwechsel-Taste dient zum Wechseln des Bildes, zum Ändern der Benutzerebene, zum Öffnen von Fenstern usw. Sie wechselt von einem Bild/Fenster zu einem bestimmten Bild/Fenster; gleichzeitig kann die Benutzerebene geändert werden.

• Klicken Sie auf das Symbol <img src="../../../configuration-guide/basic-control/screen-button.files/screen-button293.png" width="30" /> in der Werkzeugleiste, um das Dialogfeld zu öffnen, wie in Abbildung 4-80.

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button364.png" width="671" />

Abbildung 4-80 Dialogfeld Bildwechsel-Taste

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button404.png" width="130" />

Form, Rahmenfarbe, Vordergrundfarbe, Hintergrundfarbe und Muster siehe „Bit-Taste“.

**Funktionen:**

• Bild öffnen: Beim Antippen wird zum gewählten Bild gewechselt. Diese Funktion kann in einem Bild oder in einem Fenster verwendet werden.

• Vorheriges Bild öffnen: Beim Antippen wird zum vorher angezeigten Bild gewechselt. Diese Funktion kann nur in einem Bild verwendet werden.

• Schließen und öffnen: Nur in einem Fenster verwendbar. Schließt das aktuelle Fenster und öffnet ein anderes Fenster oder Bild.

• Schließen: Nur in einem Fenster verwendbar. Schließt das aktuelle Fenster.

**Benutzerebene wechseln:**

• Abmelden: Setzt die aktuelle Benutzerebene auf die Standard-Benutzerebene zurück

• Festgelegte Benutzerebene: Setzt die aktuelle Benutzerebene auf die festgelegte Ebene

**Auslösung:**

• Drücken: Der Bildwechsel erfolgt beim Drücken der Maustaste.

• Loslassen: Der Bildwechsel erfolgt beim Loslassen der Maustaste.

**Anmeldung bei unzureichender Ebene:**

Ist auf der Seite „Erweitert“ der Bildwechsel-Taste „Benutzerebenen-gesteuert“ aktiviert und die „Niedrigste gültige Ebene“ geändert, ist die Taste nur wirksam, wenn die aktuelle Benutzerebene mindestens dieser Ebene entspricht. Ist die aktuelle Benutzerebene niedriger, erscheint beim Antippen der Taste auf dem Touchscreen ein Passwort-Eingabefeld, wie in Abbildung 4-81:

![](../../../configuration-guide/basic-control/screen-button.files/001.png)

Abbildung 4-81 Passwort-Eingabetastatur

Das Bild wird nur geöffnet, wenn das eingegebene Passwort zu einer ausreichenden Ebene gehört; die aktuelle Benutzerebene ergibt sich dann aus dem soeben eingegebenen Passwort.

**Skripte:**

„Skript verwenden“ zeigt eine Skriptliste an. Der Benutzer kann ein Skript wählen, das beim Drücken der Taste ausgeführt wird. Nur kompilierte Skripte erscheinen in der Liste.

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button2377.png" width="130" />

Die Seite „Beschriftung“ der Bildwechsel-Taste entspricht weitgehend der der „Bit-Taste“. Da die Bildwechsel-Taste nur einen Zustand hat, enthält ihre Seite „Beschriftung“ nur einen Text und eine Grafik. Ansonsten sind die Funktionen gleich.

Die Seiten „Erweitert“ und „Sichtbarkeit“ der Bildwechsel-Taste entsprechen denen der „Bit-Taste“.

Klicken Sie nach allen Einstellungen auf „OK“; der Mauszeiger wird zum Kreuz. Klicken Sie mit der linken Maustaste in den Ansichtsbereich, um das Objekt in das Bild einzufügen.
