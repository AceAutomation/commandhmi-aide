# Statische Grafik

Das Objekt „Statische Grafik“ zeigt eine Grafik in verschiedenen Formaten aus einer Datei oder der Bibliothek an. Es kann z. B. als Bildhintergrund dienen, um die Oberfläche des Projekts zu gestalten.

1\. Klicken Sie auf das Symbol Statische Grafik <img src="../../../configuration-guide/basic-control/picture.files/image002.jpg" width="30" /> in der Werkzeugleiste; es erscheint das Dialogfeld in Abbildung 4-109:

<img src="../../../configuration-guide/basic-control/picture.files/image004.jpg" width="675" />

Abbildung 4-109   Dialogfeld Statische Grafik

2\. Wählen Sie eine Grafik und klicken Sie auf OK; der Mauszeiger wird zum Kreuz. Klicken Sie mit der linken Maustaste an eine beliebige Stelle im Bild, um das Grafikobjekt einzufügen.

3\. Die Größe der eingefügten Grafik kann mit der Maus geändert werden. Die Projektierungssoftware CommandHMI unterstützt verschiedene Formate: JPG, BMP, PNG, WMF, EMF, GIF.
