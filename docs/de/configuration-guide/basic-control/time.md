# Zeitanzeige

Das Objekt Zeitanzeige zeigt die Systemzeit an. Klicken Sie auf das Symbol <img src="../../../configuration-guide/basic-control/time.files/image002.jpg" width="31" />; es erscheint das Dialogfeld in Abbildung 4-105.

Abbildung 4-105    Dialogfeld Zeitanzeige

<img src="../../../configuration-guide/basic-control/time.files/image004.jpg" width="130" />

Hinweis: Form, Rahmenfarbe, Vordergrundfarbe, Hintergrundfarbe und Muster siehe Objekt „Bit-Taste“.

• Format: Vier Zeitformate stehen zur Auswahl.

HH:MM                Stunde:Minute

HH:MM:SS           Stunde:Minute:Sekunde

HH-MM-SS           Stunde-Minute-Sekunde

HH-MM                Stunde-Minute

• Schriftart: Schriftart des Textes

• Schriftgröße: Schriftgröße der Anzeige

• Farbe: Textfarbe der Anzeige

• Ausrichtung: Position der Anzeige: links, mittig oder rechts.

Klicken Sie nach den Einstellungen auf „OK“, um das Objekt in den Ansichtsbereich (das Bild) einzufügen
