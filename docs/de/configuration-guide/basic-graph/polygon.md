# Polygon

Wählen Sie den Befehl „Polygon“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche Polygon <img src="../../../configuration-guide/basic-graph/polygon.files/image002.jpg" width="31" /> in der Werkzeugleiste. Im Bearbeitungsfenster wird der Mauszeiger zum Kreuz, und Sie können ein Polygon im Bild zeichnen.

Bewegen Sie die Maus an die gewünschte Stelle und klicken Sie mit der linken Maustaste (oder halten Sie sie gedrückt): Im Bildbearbeitungsfenster erscheint ein kleiner grüner Punkt, der Anfangspunkt des Polygons.

Bewegen Sie die Maus an eine andere Stelle im Bild; das System zeichnet automatisch eine gerade Linie. Jeder weitere Linksklick zeichnet eine neue Seite des Polygons; ein Rechtsklick beendet die Zeichnung. Siehe Abbildung 4-33:

<img src="../../../configuration-guide/basic-graph/samdra30.gif" width="233" />

Abbildung 4-33   Polygon zeichnen

Um die Form eines Polygons zu ändern, klicken Sie darauf; es erscheinen mehrere grüne Punkte (je nach Seitenzahl), die anzeigen, dass das Polygon ausgewählt ist. Bewegen Sie den Mauszeiger auf einen der Punkte, bis er seine Form ändert, und ziehen Sie ihn mit gedrückter linker Maustaste an die gewünschte Stelle; so ändern sich Länge und Lage der beiden an diesem Eckpunkt verbundenen Seiten. Lassen Sie die Maustaste los, um abzuschließen.

Die Eigenschaften des Polygons lassen sich über Auswahllisten und Feineinstellungstasten anpassen. Die Projektierungssoftware CommandHMI bietet für Polygone bis zu 15 Rahmenlinienarten, 10 Rahmenlinienbreiten und 21 Füllmuster. Siehe Abbildung 4-34:
