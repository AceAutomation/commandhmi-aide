# Text

Wählen Sie den Befehl „Text“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche Text <img src="../../../configuration-guide/basic-graph/text.files/image002.jpg" width="30" /> in der Werkzeugleiste, um das Dialogfeld Statischer Text zu öffnen, wie in Abbildung 4-36:

Abbildung 4-36 Dialogfeld Statischer Text

• Geben Sie im Feld TEXT den anzuzeigenden Text ein.

• Die Schriftgröße wird in der Auswahlliste „Schriftgröße“ geändert; die Projektierungssoftware CommandHMI bietet Größen von 7 bis 56 Punkt.

• Die Schriftart wird in der Auswahlliste „Schriftart“ geändert; die Projektierungssoftware CommandHMI bietet nahezu alle Schriftarten.

• Sprache: Für jede Sprache können im Textfeld eigene Inhalte sowie eigene Schriftart und Schriftgröße festgelegt werden.

• Mit den Kontrollkästchen „Fett“ und „Kursiv“ ändern Sie den Schriftstil.

• Zeichen- und Zeilenabstand lassen sich mit den Feineinstellungstasten von 0 bis 15 einstellen

• Die Projektierungssoftware CommandHMI bietet außerdem bis zu 16 Unterstreichungsarten; Position des Textes im Textfeld, Füllmuster und Transparenz sind ebenfalls änderbar.

**Textdarstellung**

• Nachdem Sie die Schrifteigenschaften geändert haben, schließen Sie das Dialogfeld mit OK. Bewegen Sie die Maus an die gewünschte Stelle im Bearbeitungsfenster und klicken Sie links; das System zeichnet automatisch ein Rechteck.

• Um den Text zu ändern oder neu einzugeben, doppelklicken Sie auf das Textelement und geben den Inhalt über die Tastatur ein. Mit der Eingabetaste erzeugen Sie einen Zeilenumbruch.

• Um die Größe des Texthintergrunds zu ändern, markieren Sie das Textelement und bewegen die Maus an dessen Rand. Wird der Mauszeiger zu <img src="../../../configuration-guide/basic-graph/text.files/image004.jpg" width="22" />, <img src="../../../configuration-guide/basic-graph/text.files/image005.jpg" width="23" /> oder <img src="../../../configuration-guide/basic-graph/text.files/image006.jpg" width="21" />, ziehen Sie das Textfeld mit gedrückter linker Maustaste auf die gewünschte Größe und lassen dann los.
