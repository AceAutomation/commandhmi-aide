# Sektor

Wählen Sie den Befehl „Sektor“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche Sektor <img src="../../../configuration-guide/basic-graph/arcbase.files/image002.jpg" width="30" /> in der Werkzeugleiste; im Bildbearbeitungsfenster wird der Mauszeiger zum Kreuz, und Sie können einen Kreissektor zeichnen. Siehe Abbildung 4-35:

<img src="../../../configuration-guide/basic-graph/arcbase.files/image003.gif" width="143" />

Abbildung 4-35   Sektor zeichnen

Bewegen Sie die Maus auf einen der grünen Punkte in der Mitte des Rechtecks; der Mauszeiger ändert seine Form. Durch Ziehen ändern Sie den Bogen des Sektors.
