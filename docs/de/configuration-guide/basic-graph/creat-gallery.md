# In Bibliothek speichern

Wählen Sie den Befehl „In Bibliothek speichern“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche <img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" /> in der Werkzeugleiste, um das Dialogfeld der Bibliotheksliste zu öffnen, wie in Abbildung 4-46:

Abbildung 4-46       Dialog „In Bibliothek speichern“

• Mit der Projektierungssoftware CommandHMI kann der Projektierer fertige Bildelemente für die spätere Verwendung speichern. Nach einem Klick auf „In Bibliothek speichern“ wird das Grafikobjekt des aktuellen Bildes im weißen Bereich in der Mitte des Dialogs angezeigt, wie oben.

• Drei Optionen stehen zur Auswahl:

Auswahl als Bibliothek: Die im Bild ausgewählten Objekte werden als Bibliotheksobjekt verwendet

Bibliothek importieren: Importiert eine externe Bibliotheksdatei mit der Endung HM (die Datei wird in der Regel von CommandHMI bereitgestellt).

Grafik aus Datei importieren: Importiert eine Grafik aus einer externen Datei als Bibliotheksobjekt.

• Klicken Sie auf „Save to...“ und wählen Sie „Library II“, wie in Abbildung 4-47:

<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image004.jpg" width="753" />

Abbildung 4-47     Auswahl des Speicherpfads

Wählen Sie im Auswahlfeld links den Speicherpfad. Die Projektierungssoftware CommandHMI bietet 8 benutzerdefinierte Objektbibliotheken und 8 benutzerdefinierte Grafikbibliotheken. Wählen Sie den Speicherpfad und klicken Sie unten auf „Speichern“, um das Grafikobjekt zu speichern; es erscheint im weißen Bereich rechts. Klicken Sie dann auf OK. Um die neu gespeicherten Grafiken anzusehen, klicken Sie auf die Schaltfläche „Bibliothek öffnen“ <img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" />, ziehen im Dialogfeld die Bildlaufleiste der linken Liste ganz nach unten und wählen „Custom Gallery“ unter „Gallery II“.
