# Externe Grafik

In CommandHMI können Grafiken in zahlreiche Objekte eingefügt werden; Beispiel „Statische Grafik“:

<img src="../../../configuration-guide/basic-graph/externpic.files/image002.gif" width="675" />

Grafik:

Bibliothek: In das System integrierte Grafikbibliothek, wie unten:

<img src="../../../configuration-guide/basic-graph/externpic.files/image003.gif" width="732" />

Datei: Externe Datei oder Systemdatei. Externe Grafiken stammen vom Computer; Systemgrafiken können von der offiziellen Website heruntergeladen werden und werden im Ordner Extern_Pic des Installationsverzeichnisses gespeichert.

Bei Auswahl von „System“ erscheint folgendes Dialogfeld:

<img src="../../../configuration-guide/basic-graph/externpic.files/image004.gif" width="804" />

Diese Grafiken liegen im Ordner Extern_Pic des Installationsverzeichnisses, wie unten:

<img src="../../../configuration-guide/basic-graph/externpic.files/image005.jpg" width="852" />

Der Ordner Extern_Pic enthält zwei Ordner: share_picture und system_picture; sie entsprechen den gemeinsamen Grafiken und den Systemgrafiken in der [Grafikliste der Bibliothek](#图库图片列表). Die Grafiken im Ordner system_picture sind Systemgrafiken und können weder ergänzt noch geändert werden. Die im Ordner share_picture dagegen schon, wie in der folgenden Abbildung:

<img src="../../../configuration-guide/basic-graph/externpic.files/image006.jpg" width="852" />

Im Ordner share_picture können Sie eigene Ordner anlegen oder vorhandene umbenennen (z. B. Motor); der Name des Ordners share_picture selbst darf nicht geändert werden. Grafiken im Ordner Motor können ergänzt oder gelöscht werden.

<img src="../../../configuration-guide/basic-graph/externpic.files/image007.jpg" width="130" />

Das Archiv share_picture.rar kann von der offiziellen Website heruntergeladen werden; entpacken Sie es auf dem PC und fügen Sie es wie oben beschrieben in den Ordner share_picture ein. Die Grafiken stehen dann ebenfalls in der [Grafikliste der Bibliothek](#图库图片列表) zur Verfügung.
