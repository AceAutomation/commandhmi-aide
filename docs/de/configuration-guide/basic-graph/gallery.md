# Bibliothek öffnen

Wählen Sie den Befehl „Bibliothek öffnen“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche <img src="../../../configuration-guide/basic-graph/gallery.files/image002.jpg" width="31" /> in der Werkzeugleiste, um das Dialogfeld der Bibliotheksliste zu öffnen, wie in Abbildung 4-43:

<img src="../../../configuration-guide/basic-graph/gallery.files/image006.jpg" width="732" />

Abbildung 4-43     Bibliotheksliste

Die Systembibliothek der Projektierungssoftware CommandHMI bietet dem Projektierer eine Vielzahl von Grafikobjekten; diese Version enthält zusätzlich viele Tasten, Anzeigen und weitere Grafiken. Mit einem passenden Grafikobjekt spart der Projektierer Zeit beim Entwurf.

Klicken Sie links in der Systembibliothek auf die gewünschte Kategorie. Ein Klick auf das +-Zeichen öffnet die Unterkategorien; wählen Sie dann die gewünschte Grafik. Klicken Sie auf die Grafik und anschließend, wenn der Mauszeiger zum Kreuz wird, in das Bild, um das Grafikobjekt einzufügen.

Ändern: Wählen Sie die zu ändernde Grafik und klicken Sie unten links im Dialogfeld auf „Modify“, wie in Abbildung 4-44:

<img src="../../../configuration-guide/basic-graph/gallery.files/image007.jpg" width="812" />

Abbildung 4-44 Dialogfeld zum Ändern der Bibliothek

Wählen Sie im Fenster in Abbildung 4-44 die Grafik und führen Sie in der Werkzeugleiste „Aufteilen“ aus, um das Objekt zu zerlegen. Dann können Sie einen Teil ändern: Vordergrundfarbe, Hintergrundfarbe, Muster usw. finden Sie rechts im Dialogfeld. Gruppieren Sie die zerlegten Teile anschließend wieder und klicken Sie auf „Speichern“.

<img src="../../../configuration-guide/basic-graph/gallery.files/image008.jpg" width="753" />

Abbildung 4-45     Angezeigtes Dialogfeld

Wählen Sie in der Liste „Benutzerdefiniert“ links im Dialogfeld den Speicherort der geänderten Grafik (z. B. „Library 2“) und klicken Sie auf „Speichern“. <span id="OLE_LINK480"></span><span id="OLE_LINK481"></span>Um die neu gespeicherten Grafiken anzusehen, klicken Sie auf die Schaltfläche „Bibliothek öffnen“ <img src="../../../configuration-guide/basic-graph/gallery.files/image002.jpg" width="31" /> und wählen im Dialogfeld „Custom Library“.
