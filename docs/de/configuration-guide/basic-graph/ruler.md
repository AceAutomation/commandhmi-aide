# Skala

Wählen Sie den Befehl „Skala“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche <img src="../../../configuration-guide/basic-graph/ruler.files/image002.jpg" width="24" /> in der Werkzeugleiste; es erscheint das Dialogfeld Skala, wie in Abbildung 4-41:

Abbildung 4-41     Dialogfeld Skala

In diesem Dialogfeld bietet die Projektierungssoftware CommandHMI die Bereiche Farbe, Achse und Text. Unter „Farbe“ wählen Sie Linien- und Textfarbe. Unter „Achse“ legen Sie fest, ob die Achsen angezeigt werden, und stellen die Anzahl der Haupt- und Unterteilungen über die Feineinstellungstasten oder per Direkteingabe ein. Unter „Text“ legen Sie fest, ob Text angezeigt wird, und ändern Höchst- und Mindestwert der Skala, die Textgröße und die Nachkommastellen der Skalenwerte.

Nachdem Sie die Eigenschaften geändert und das Dialogfeld mit OK geschlossen haben, bewegen Sie die Maus an die Stelle, an der die Skala erscheinen soll. Ein Linksklick zeichnet automatisch eine Skala. Siehe Abbildung 4-42:

<img src="../../../configuration-guide/basic-graph/samdra47.gif" width="460" />

Abbildung 4-42     Beispiel einer Skala

So entsteht eine Skala wie die erste von links in der Abbildung oben. Um sie in die Form der zweiten von links zu bringen, markieren Sie die Skala, bewegen die Maus auf eine der Höhenseiten, drücken die linke Maustaste, wenn der Mauszeiger zu <img src="../../../configuration-guide/basic-graph/ruler.files/image004.jpg" width="22" /> wird, und ziehen die Maus über die andere Höhenseite hinaus. Für die rechten Formen in der Abbildung verwenden Sie „Frei drehen“.
