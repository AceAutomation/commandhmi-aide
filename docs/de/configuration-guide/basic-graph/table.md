# Tabelle

Wählen Sie den Befehl „Tabelle“ im Menü „Zeichnen“ oder klicken Sie auf die Schaltfläche <img src="../../../configuration-guide/basic-graph/table.files/image002.jpg" width="29" /> in der Werkzeugleiste; es erscheint das Dialogfeld Tabelle, wie in Abbildung 4-39:

Abbildung 4-39     Dialogfeld Tabelle

In diesem Dialogfeld bietet die Projektierungssoftware CommandHMI die Bereiche Hintergrundfarbe, Rahmen, Raster und Rasterlinien. Unter „Raster“ legen Sie fest, ob senkrechte oder waagerechte Rasterlinien angezeigt werden; Art und Farbe der Linien sind änderbar.

<img src="../../../configuration-guide/basic-graph/table.files/image004.jpg" width="130" />

Die Tabelle ist nur ein Grafikobjekt: Text, Daten oder andere Objekte können nicht in die Tabelle eingefügt werden; sie dient nur als Hintergrundgrafik. Um Text, Daten oder andere Objekte in einer Tabelle anzuzeigen, legen Sie Text- und Anzeigeobjekte über die Tabelle und bringen sie in den Vordergrund.
