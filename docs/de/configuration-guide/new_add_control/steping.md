# Schritttaste

Mit diesem Befehl wird im aktuellen Bild eine Schritttaste angelegt, die zyklisch zwischen Zuständen wechselt. Klicken Sie auf das Symbol <img src="../../../configuration-guide/new_add_control/steping.files/image002.jpg" width="31" />; es erscheint das Dialogfeld in Abbildung 4-113:

<img src="../../../configuration-guide/new_add_control/steping.files/image004.jpg" width="675" />

Abbildung 4-113   Dialogfeld Schritttaste

Zustandsreihenfolge: Richtung der Texte im Objekt

Beispiel: Bei 3 Zuständen lauten die Texte von Zustand 0, 1 und 2 „0“, „1“ und „2“.

• Von links nach rechts: Das Objekt liegt waagerecht, die Texte stehen von links nach rechts: 0, 1, 2

• Von rechts nach links: Das Objekt liegt waagerecht, die Texte stehen von rechts nach links: 2, 1, 0

• Von oben nach unten: Das Objekt steht senkrecht, die Texte stehen von oben nach unten: 0, 1, 2

• Von unten nach oben: Das Objekt steht senkrecht, die Texte stehen von unten nach oben: 2, 1, 0

Zustandstyp: siehe „Mehrzustandslampe“.

Aktueller Zustand: Hintergrund- und Textfarbe des Textes im aktuellen Zustand.

Zu den Seiten „Text“ und „Grafik“ siehe „Mehrzustandslampe“.

Zur Seite „Erweitert“ und zu Tastenkürzeln siehe Bit-Taste.

Beispiel: Zustandstyp „Wert“, Schreibadresse LW1, 3 Zustände, Texte der Zustände 0, 1 und 2 „0“, „1“ und „2“. Nach dem Download auf das HMI wechselt das Objekt bei jedem Antippen zyklisch zwischen 0 und 2, und der jeweilige Wert wird in LW1 geschrieben.
