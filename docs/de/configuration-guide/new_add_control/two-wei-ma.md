# QR-Code

Wählen Sie das Symbol <img src="../../../configuration-guide/new_add_control/two-wei-ma.files/image002.jpg" width="33" /> in der Werkzeugleiste und legen Sie die Eigenschaften im folgenden Dialogfeld fest:

Abbildung 4-132     Dialogfeld QR-Code

• Überwachungsadresse: Adresse, deren Inhalt als QR-Code dargestellt wird

• Länge: Maximale Zahl der darstellbaren Zeichen
