# Multifenster

Das Multifenster stellt einen rechteckigen Bereich bereit, in dem ein zugewiesenes Fenster angezeigt wird.

 Klicken Sie auf das Symbol <img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow619.png" width="54" /> in der Werkzeugleiste; es erscheint das Dialogfeld Multifenster, wie in Abbildung 4-136.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow881.png" width="662" />

Abbildung 4-136 Dialogfeld Multifenster

• Datentyp: Datentyp, der das angezeigte Fenster steuert: Bool oder Wort.

„Bool“: Ob das zugewiesene Fenster im Rechteck geöffnet wird, hängt von einer Bedingung ab.

„Wort“: Wählen Sie die Steueradresse und „Mit Fenster verknüpfen“ oder „Nicht mit Fenster verknüpfen“, wie in Abbildung 4-138.

• Adresse: Der Wert der Adresse steuert das Öffnen des Fensters;

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1265.png" width="664" />

Abbildung 4-138 Dialogfeld Multifenster

„Mit Fenster verknüpfen“: Der Wert der Adresse ist die ID des zugewiesenen Fensters.

„Nicht mit Fenster verknüpfen“: Wählen Sie eine Funktion; ist ihre Bedingung erfüllt, wird das zugewiesene Fenster geöffnet. Die Funktionen sehen Sie unten.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1507.png" width="349" />

Abbildung 4-139

<span id="OLE_LINK677"></span><span id="OLE_LINK676"></span>      Zur Seite „Sichtbarkeit“ siehe „Bit-Taste“.

Klicken Sie nach dem Einstellen auf „OK“ und ziehen Sie mit der Maus im Bildbereich ein Rechteck auf. In diesem Bereich wird das Multifenster angezeigt, wie in Abbildung 4-140.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1958.png" width="307" />
