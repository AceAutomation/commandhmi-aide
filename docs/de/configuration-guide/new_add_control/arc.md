# Bogendiagramm

Das Bogendiagramm (auch Kreissegmentdiagramm) funktioniert ähnlich wie das Zeigerinstrument: Es liest den Wert der Überwachungsadresse und stellt ihn dar. Der Wert wird über „Vordergrundfarbe“, „Hintergrundfarbe“ und „Muster“ des Bogens angezeigt.
