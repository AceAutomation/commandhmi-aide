# Rezeptauswahl

Die Rezeptauswahl listet alle Namen der angelegten Rezepte auf. Bei Auswahl eines Rezeptnamens in der Liste wird die Rezeptnummer in das Rezeptnummernregister RWI0 geschrieben. Umgekehrt springt die Rezeptauswahl bei einer Änderung von RWI0 auf den entsprechenden Rezeptnamen. Das Symbol in der Werkzeugleiste ist <img src="../../../configuration-guide/new_add_control/recipeselect.files/recipeselect411.png" width="28" />; ein Klick darauf öffnet folgendes Dialogfeld:

<img src="../../../configuration-guide/new_add_control/recipeselect.files/recipeselect467.png" width="461" />

Abbildung 4-127 Dialogfeld Rezeptauswahl

• Darstellung

Darstellungsart der Rezeptauswahl

Liste: Die Rezeptauswahl wird als Liste angezeigt.

Auswahlliste: Die Rezeptauswahl wird als Dropdown-Liste angezeigt.

• Schriftart, Schriftgröße, Textfarbe und Hintergrundfarbe sind Einstellungen der Liste und des Textinhalts

• Zeilen: Nur verfügbar, wenn die Darstellung „Liste“ gewählt ist.
