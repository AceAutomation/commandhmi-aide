# Schreibtafel

Schreibtafel: Ein Objekt, auf dem der Benutzer schreiben kann. Das Symbol in der Werkzeugleiste ist <img src="../../../configuration-guide/new_add_control/msgbord.files/image002.jpg" width="26" />; ein Klick darauf öffnet das Dialogfeld in Abbildung 4-121.

Abbildung 4-121   Seite „Allgemein“ der Schreibtafel

• Linienfarbe: Farbe der Schrift auf dem Objekt

• Linienbreite: Breite der Schriftlinie

• Betriebsart:

Adresse der Betriebsart: Wortadresse, nur bei Wert 0 oder 1 wirksam. 0 bedeutet Schreiben, 1 Radieren.

Die Wortadresse belegt 3 aufeinanderfolgende Adressen: Die erste steuert die Betriebsart (0 Schreiben, 1 Radieren), die zweite die Linienbreite und die dritte die RGB-Farbe des Stifts.

• Löschen

Löschadresse: Entspricht der Wert dem eingestellten Löschzustand (0 oder 1), wird der gesamte Inhalt des Objekts automatisch gelöscht

Zur Seite „Sichtbarkeit“ siehe „Bit-Taste“.
