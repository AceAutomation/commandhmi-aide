# Rezeptanzeige

Die Rezeptanzeige listet die Daten aller angelegten Rezepte auf. Das Symbol in der Werkzeugleiste ist <img src="../../../configuration-guide/new_add_control/recipedisplay.files/recipedisplay150.png" width="31" />; ein Klick darauf öffnet folgendes Dialogfeld:

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image001.jpg" width="481" alt="ScreenShot00674.jpg" />

Abbildung 4-129   Seite „Allgemein“ der Rezeptanzeige

Die Seite „Allgemein“ enthält die Einstellungen für Texte und Listeneigenschaften.

Seite „Datenelemente“, wie unten

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image002.jpg" width="481" alt="ScreenShot00675.jpg" />

Abbildung 4-130   Seite „Daten“ der Rezeptanzeige

• Sprache: Wählen Sie eine Sprache, um die Rezeptnamen in dieser Sprache aufzulisten.

• Name: Liste aller Rezeptnamen

• Anzeigen: Legt nach Bedarf fest, ob ein Rezept angezeigt wird.

• ALL: Wählt alle Einträge unter „Anzeigen“ aus.

CommandHMI unterstützt mehrere Rezeptgruppen; bei diesem Objekt kann der Projektierer die anzuzeigende Gruppe wählen, wie unten:

Abbildung 4-131   Auswahl der angezeigten Rezepte
