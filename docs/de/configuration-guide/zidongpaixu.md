# Automatische Sortierung

Mit „Automatische Sortierung“ wird im aktuellen Projekt ein neues Bild angelegt. Vorgehen:

Der Befehl „Automatische Sortierung“ sortiert die Bildnummern des Projekts. Vorgehen:

Wählen Sie im Projektmanager mit der linken Maustaste den Eintrag „Bild“ und dann im Kontextmenü „Automatische Sortierung“. Es erscheint ein Einstellungsfenster; aktivieren Sie die automatische Sortierung und klicken Sie auf OK, um die Bilder zu sortieren (aufsteigend).

Klicken Sie links auf den Eintrag und wählen Sie per Rechtsklick „Automatische Sortierung“

Aktivieren Sie die automatische Sortierung und klicken Sie auf OK
