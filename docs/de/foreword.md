# Vorwort

Willkommen bei CommandHMI, der Software zur Erstellung von Bedienoberflächen speziell für die Bediengeräte (HMI) der Serie CommandHMI. Damit Sie die leistungsfähigen Funktionen dieser Software voll nutzen können, beschreibt dieses Handbuch ausführlich die Kernfunktionen von CommandHMI und ihre Bedienung.     Damit Sie CommandHMI noch effizienter beherrschen und einsetzen, stehen Ihnen folgende Hilfen zur Verfügung:     1. Eine Online-Hilfe, in der Sie über Suchbegriffe schnell die passenden Anleitungen und Lösungen finden.     2. In der Software können Sie direkt auf ein beliebiges Objekt klicken und dann unten rechts im Fenster auf „Hilfe“, um sofort die zugehörige Anleitung zu erhalten.     Bitte lesen Sie dieses Handbuch vor der ersten Verwendung sorgfältig, damit Sie die Software richtig bedienen, effizienter arbeiten und das volle Potenzial von CommandHMI nutzen. Bei Problemen hilft Ihnen unser technischer Support gern weiter.     Vielen Dank, dass Sie sich für CommandHMI entschieden haben; wir freuen uns darauf, gemeinsam mit Ihnen effizient und innovativ zu arbeiten.
