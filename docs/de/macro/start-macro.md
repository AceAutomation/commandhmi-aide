# Programmieren mit Skriptfunktionen

Dieser Abschnitt stellt die Grundfunktionen der Skripte vor und beschreibt kurz die Steuerfunktionen und ihre Anwendung.

Methode 1: Wählen Sie im Menü „Einstellungen (S) -&gt; Skript“, wie in Abbildung 5-1 (Skriptmenü); es öffnet sich das Fenster in Abbildung 5-1 (Skripteditor).
