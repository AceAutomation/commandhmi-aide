# break-Anweisung

Die break-Anweisung wird nur in switch- und Schleifenanweisungen verwendet. Sie verlässt die switch-Anweisung bzw. die aktuelle Schleife und setzt das Programm danach fort. Da das Sprungziel von break festgelegt ist, sind keine Sprungmarken nötig. Die allgemeine Form ist break. Wie im obigen Beispiel wird break in switch- und for-Anweisungen zum Verlassen verwendet. break bietet mehrere Ausgänge aus einer Schleife und macht die Programmierung in manchen Fällen flexibler.
