# Software Demand

CommandHMI configuration software can run on the following operating systems:

· Microsoft Windows NT Server 4.0 or later;

· Microsoft Windows NT Workstation 4.0 or later;

· Microsoft Windows 98, Me, 2000, XP, win7 or later.

<img src="sw-requirements.files/image002.jpg" width="130" />

CommandHMI will refuse to install if it does not match the above versions of operating systems.
