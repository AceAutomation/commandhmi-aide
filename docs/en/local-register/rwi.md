# RWI

RWI

|                  |                         |                                                                        |
|------------------|-------------------------|------------------------------------------------------------------------|
| Register address | Meaning                 | Note                                                                   |
| RWI0             | Formula number register | Display the formula specified by the formula number.                   |
| RWI1             | Formula memory address  | Specify a formula number to display corresponding formula data in RWI. |
