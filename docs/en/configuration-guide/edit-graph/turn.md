# Rotaty

This command is by group. CommandHMI configuration editor software allows engineers to rotate one or more graphical objects at any angle. Graphic objects that can be rotated to contain straight lines, circles, rectangles, graphics system library, controls, a combination of graphics, and polygons.

• **Flip Horizontal**

“Flip horizontal” allows engineers to rotate the graphic object (may be a plurality of graphic objects) at 180°by the axis of vertical center in the horizontal plane after selecting. First select one or more graphical objects, then click “Flip Horizontal” in the Edit menu "Mirror" or click the Flip Horizontal button in the Tool bar<img src="turn.files/turn649.png" width="27" />.
