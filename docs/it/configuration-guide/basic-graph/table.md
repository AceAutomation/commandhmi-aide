# Tabella

Selezionare il comando Table nel menu Draw oppure fare clic sul pulsante<img src="../../../configuration-guide/basic-graph/table.files/image002.jpg" width="29" /> nella barra degli strumenti: compare la finestra della tabella, come mostrato nella Figura 4-39:

Figura 4-39     Finestra della tabella

In questa finestra il software di configurazione CommandHMI offre le opzioni Background Color, Border, Grid e Grid lines. Nell'opzione Grid si sceglie se visualizzare le linee verticali o orizzontali della griglia, di cui si possono modificare tipo e colore.

<img src="../../../configuration-guide/basic-graph/table.files/image004.jpg" width="130" />

La tabella è solo un oggetto grafico: non è possibile inserirvi testo, dati o altri oggetti. Può essere usata solo come immagine di base. Per visualizzare testo, dati o altri oggetti su una tabella, sovrapporre alla tabella oggetti di testo e di visualizzazione numerica e portarli in primo piano.
