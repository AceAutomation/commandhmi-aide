# Settore

Selezionare il comando Sector nel menu Draw oppure fare clic sul pulsante Sector <img src="../../../configuration-guide/basic-graph/arcbase.files/image002.jpg" width="30" /> nella barra degli strumenti; spostando il mouse nella finestra di modifica della pagina il cursore assume la forma di una croce e si può disegnare un settore. Come mostrato nella Figura 4-35:

<img src="../../../configuration-guide/basic-graph/arcbase.files/image003.gif" width="143" />

Figura 4-35   Disegno di un settore

Spostare il mouse su uno dei punti verdi al centro del rettangolo: il cursore cambia forma; spostando il mouse si modifica l'arco del settore.
