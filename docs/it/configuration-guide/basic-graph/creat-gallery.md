# Salva nella libreria

Selezionare il comando Save to Library nel menu Draw oppure fare clic sul pulsante Save to Library<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" /> nella barra degli strumenti per aprire la finestra di dialogo della libreria, come mostrato nella Figura 4-46:

Figura 4-46       Finestra Save to Library

• Il software di configurazione CommandHMI permette di salvare gli elementi grafici realizzati per riutilizzarli in seguito. Facendo clic su Save to Library, come mostrato nella figura precedente, gli oggetti grafici della pagina corrente vengono visualizzati nell'area bianca al centro della finestra.

• Le funzioni disponibili sono tre:

Selezionare l'area come libreria: salva l'oggetto selezionato nella pagina come oggetto di libreria

Importa libreria: importa da una sorgente esterna un file di libreria con estensione HM (in genere fornito da CommandHMI).

Importa un'immagine da file: importa un'immagine da un file esterno come oggetto di libreria.

• Fare clic sul pulsante "Save to..." e selezionare "Library II", come mostrato nella Figura 4-47:

<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image004.jpg" width="753" />

Figura 4-47     Finestra di selezione del percorso di salvataggio

Scegliere il percorso di salvataggio nella casella a sinistra. Il software di configurazione CommandHMI mette a disposizione 8 librerie di oggetti personalizzate e 8 librerie grafiche personalizzate: selezionato il percorso, fare clic su "Save" in basso per salvare l'oggetto grafico, che viene visualizzato nell'area bianca a destra. Fare quindi clic su OK per completare l'operazione. Per visualizzare gli elementi grafici salvati, fare clic sul pulsante Open Lib<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" />, scorrere fino in fondo l'elenco a sinistra della finestra che compare e selezionare "Custom Gallery" in "Gallery II".
