# Apri libreria

Selezionare il comando Open Library nel menu Draw oppure fare clic sul pulsante Open Library<img src="../../../configuration-guide/basic-graph/gallery.files/image002.jpg" width="31" /> nella barra degli strumenti per aprire la finestra dell'elenco delle librerie, come mostrato nella Figura 4-43:

<img src="../../../configuration-guide/basic-graph/gallery.files/image006.jpg" width="732" />

Figura 4-43     Elenco delle librerie

La libreria di sistema del software di configurazione CommandHMI mette a disposizione numerosi oggetti grafici, arricchiti nella versione CommandHMI da molti pulsanti, spie e altri elementi. Il progettista può trovarvi l'oggetto grafico adatto e risparmiare tempo di progettazione.

Basta fare clic sulla categoria desiderata nella libreria di sistema a sinistra, aprire le sottocategorie con il segno + e selezionare l'elemento grafico. Fare clic sull'immagine per selezionarla, quindi fare clic nella pagina, quando il cursore assume la forma di una croce, per aggiungere l'oggetto grafico.

Modifica: dopo aver selezionato l'elemento grafico da modificare, fare clic sul pulsante "Modify" in basso a sinistra nella finestra, come mostrato nella Figura 4-44:

<img src="../../../configuration-guide/basic-graph/gallery.files/image007.jpg" width="812" />

Figura 4-44 Finestra di modifica della libreria

Nell'interfaccia della Figura 4-44, selezionare l'elemento grafico ed eseguire la funzione "Split" della barra degli strumenti per scomporlo. Si può quindi modificare una singola parte: le impostazioni di colore di primo piano, colore di sfondo, motivo e altro si trovano a destra della finestra. Dopo la modifica, raggruppare di nuovo tutte le parti con il comando Group e fare clic su "Save".

<img src="../../../configuration-guide/basic-graph/gallery.files/image008.jpg" width="753" />

Figura 4-45     Finestra visualizzata

Nell'elenco "Custom" a sinistra della finestra, selezionare la posizione in cui salvare l'elemento modificato (per esempio "Library 2") e fare clic su "Save". <span id="OLE_LINK480"></span><span id="OLE_LINK481"></span>Per visualizzare gli elementi salvati, fare clic sul pulsante Open Lib <img src="../../../configuration-guide/basic-graph/gallery.files/image002.jpg" width="31" /> e, nella finestra che compare, selezionare "Custom Library".
