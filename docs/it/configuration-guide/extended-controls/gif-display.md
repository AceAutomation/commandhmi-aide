# Visualizzazione GIF

La visualizzazione GIF serve a mostrare immagini in formato GIF, con al massimo 32 fotogrammi. Procedere come segue:

Fare clic sull'icona GIF<img src="../../../configuration-guide/extended-controls/gif-display.files/image002.jpg" width="29" /> nella barra degli strumenti per aprire la finestra di dialogo mostrata nella Figura 4-48.

Figura 4-48    Finestra GIF Display

Dopo aver impostato le proprietà, fare clic su "OK": nell'area di modifica il cursore assume la forma di una croce; tracciare un rettangolo con il tasto sinistro per aggiungere l'oggetto all'area di visualizzazione (cioè la pagina)

Selezionare la scheda "Advanced" per visualizzarne le proprietà.

![](../../../configuration-guide/extended-controls/gif-display.files/image004.jpg)

Figura 4-49    Scheda "Advanced" della visualizzazione GIF

Controllato da bit (Controlled By bit): con questa opzione, se "Active Status" è 1 l'immagine GIF è animata solo quando il valore del "Control bit" è 1, altrimenti è visualizzata come immagine fissa; se "Active Status" è 0, l'immagine è animata solo quando il valore del "Control Bit" è 0, altrimenti è fissa.

<img src="../../../configuration-guide/extended-controls/gif-display.files/image005.jpg" width="130" />

Per la scheda "Visibility", vedere l'uso dell'oggetto "Pulsante di bit".
