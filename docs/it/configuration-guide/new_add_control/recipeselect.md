# Selettore ricette

Il selettore ricette elenca i nomi di tutte le ricette create. Selezionando un nome nell'elenco, il numero della ricetta viene scritto nel registro RWI0. Viceversa, se il valore di RWI0 cambia, il selettore punta al nome di ricetta corrispondente. L'icona dell'oggetto nella barra degli strumenti è: <img src="../../../configuration-guide/new_add_control/recipeselect.files/recipeselect411.png" width="28" />; facendo clic compare la finestra seguente:

• Stile di visualizzazione (Display style)

Imposta lo stile di visualizzazione del selettore ricette

Elenco (List): il selettore è visualizzato come elenco.

Elenco a discesa (Dropdown box): il selettore è visualizzato come elenco a discesa.

• Carattere, dimensione, colore del testo e colore di sfondo sono le impostazioni dell'elenco e del testo

• Righe (Rows): disponibile solo con lo stile "List".
