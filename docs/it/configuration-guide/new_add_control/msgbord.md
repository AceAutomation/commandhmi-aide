# Bacheca messaggi

Bacheca messaggi: un oggetto su cui l'utente può scrivere. L'icona dell'oggetto nella barra degli strumenti è: <img src="../../../configuration-guide/new_add_control/msgbord.files/image002.jpg" width="26" />. Facendo clic si apre la finestra di dialogo mostrata nella Figura 4-121.

Figura 4-121   Scheda General della bacheca messaggi

• Colore linea (Line color): colore della scrittura sull'oggetto

• Spessore linea (Line width): spessore del tratto

• Modalità operativa (Operating mode):

Indirizzo della modalità operativa: indirizzo word, valido solo con valore 0 o 1. Il valore 0 indica scrittura, il valore 1 cancellazione.

L'indirizzo è un indirizzo word che occupa 3 indirizzi consecutivi: il primo controlla la modalità operativa (0 scrittura, 1 cancellazione), il secondo lo spessore della linea, il terzo il colore RGB del pennello.

• Cancella schermo (Clear Screen)

Indirizzo di cancellazione: quando il valore dell'indirizzo è uguale allo stato di cancellazione impostato (0 o 1), tutto il contenuto scritto sull'oggetto viene cancellato automaticamente

Per l'uso della scheda "Visibility", vedere il "Pulsante di bit".
