# Visualizzazione PDF

<span id="1040"></span>
L'oggetto apre e visualizza nell'HMI i documenti PDF presenti sulla chiavetta USB.
<img src="../../../configuration-guide/new_add_control/pdfreading_files/image.jpg" width="551" />L'area 1 è l'elenco dei file PDF presenti nella cartella principale della chiavetta USB; se il numero o il nome dei file PDF cambia, fare clic sul pulsante di aggiornamento nell'area 2 per aggiornare l'elenco dell'area 1.
L'area 2 visualizza il contenuto del documento PDF; in basso e a destra dell'area sono presenti barre di scorrimento per spostare l'area visibile.
L'area 3 contiene i pulsanti funzione: pagina precedente e successiva per scorrere il documento selezionato, salto diretto a un numero di pagina, ingrandimento e riduzione del testo, ripristino dello zoom al 100%, uscita dalla finestra corrente e stampa del documento PDF selezionato tramite la stampante collegata.
Nota:

1.  La visualizzazione PDF funziona solo sul touch screen, non nella simulazione su PC; se il documento PDF è protetto da una password di apertura, occorre inserirla correttamente prima di aprirlo.

<!-- -->

2.  2. Il nome dei documenti PDF sulla chiavetta USB deve contenere solo lettere o cifre: i nomi in caratteri cinesi vengono visualizzati come caratteri illeggibili.
