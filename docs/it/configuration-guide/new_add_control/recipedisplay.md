# Visualizzazione ricette

La visualizzazione ricette elenca i dati di tutte le ricette create. L'icona dell'oggetto nella barra degli strumenti è<img src="../../../configuration-guide/new_add_control/recipedisplay.files/recipedisplay150.png" width="31" />: facendo clic compare la finestra seguente:

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image001.jpg" width="481" alt="ScreenShot00674.jpg" />

Figura 4-129   Scheda General della visualizzazione ricette

La scheda General contiene le impostazioni del testo e delle proprietà dell'elenco.

Scheda Data Item, mostrata di seguito

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image002.jpg" width="481" alt="ScreenShot00675.jpg" />

Figura 4-130   Scheda Data della visualizzazione ricette

• Lingua (Language): permette di elencare i nomi delle ricette nelle diverse lingue.

• Nome (Name): elenco di tutti i nomi delle ricette

• Visualizza (Display): sceglie quali ricette visualizzare.

• ALL: seleziona tutte le voci di Display.

CommandHMI gestisce più gruppi di ricette: usando questo oggetto si può scegliere quale gruppo visualizzare, come mostrato di seguito:
