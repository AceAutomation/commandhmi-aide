# Modificare le proprietà della pagina

Per modificare le proprietà della pagina, come nome e colore di sfondo, procedere come segue:

Senza oggetti selezionati (fare clic in un punto vuoto della pagina corrente), selezionare il comando <img src="../../../configuration-guide/screen/edit-screen.files/edit-screen760.png" width="26" /> nella barra degli strumenti, oppure selezionare la pagina in Gestione progetto e fare clic con il tasto destro, oppure fare clic con il tasto destro nella pagina senza oggetti selezionati: nel menu contestuale si trova il comando "Property".

<img src="../../../configuration-guide/screen/edit-screen.files/edit-screen1019.png" width="522" />

Figura 4-3      Impostazione delle proprietà della pagina

 Nella finestra "New Screen" impostare nome, colore di sfondo e impostazioni di pagina comune, quindi fare clic su OK. Il nome predefinito della nuova pagina è il suo numero.

Predefinito (Default): colore di sfondo, colore di primo piano e stile della pagina.

Immagine (Photo): è possibile usare un'immagine come sfondo.

Impostazioni di pagina comune

Pagina standard: crea una pagina standard.

Imposta come pagina comune: crea una pagina comune, i cui oggetti possono essere usati in altre pagine ma le cui proprietà sono modificabili solo in questa pagina.

Usa pagina comune: usa una pagina comune già creata, senza poter modificare le proprietà dei suoi oggetti.
