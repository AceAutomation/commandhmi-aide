# Eliminare una pagina

Questo comando elimina una pagina del progetto corrente, come segue:

Selezionare "Delete Screen" nel menu Screen; oppure, in Gestione progetto, fare clic con il tasto sinistro sulla pagina da eliminare e scegliere "Delete" dal menu del tasto destro; oppure, senza oggetti selezionati, fare clic con il tasto destro in un punto vuoto della pagina e scegliere "Delete" nel menu contestuale.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen407.png" width="382" />

Figura 4-4 Eliminazione di una pagina

Fare clic su OK per completare l'eliminazione.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen483.png" width="130" />

Una pagina eliminata non può essere recuperata! Usare questo comando con cautela.
