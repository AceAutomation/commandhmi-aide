# Copiare una pagina

Questo comando copia una pagina del progetto corrente, come segue:

In Gestione progetto, fare clic con il tasto sinistro sulla pagina da copiare, poi con il tasto destro aprire il menu contestuale e selezionare "Copy"; quindi, sempre dal menu contestuale, selezionare "Paste" (Figura 4-5).

Viene creata una nuova pagina, copia di quella indicata.
