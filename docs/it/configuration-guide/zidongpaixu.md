# Ordinamento automatico

Il comando "Automatic sorting" agisce sulle pagine del progetto corrente, come segue:

Il comando di ordinamento automatico riordina i numeri delle pagine. Procedere come segue:

In Gestione progetto, selezionare la voce delle pagine con il tasto sinistro, poi con il tasto destro scegliere "automatic sorting": compare la finestra delle impostazioni; selezionare l'ordinamento automatico e fare clic su OK per ordinare le pagine (in ordine crescente).
