# Visualizzazione ora

L'oggetto Visualizzazione ora serve principalmente a visualizzare l'ora di sistema. Fare clic sull'icona dell'oggetto<img src="../../../configuration-guide/basic-control/time.files/image002.jpg" width="31" />: compare la finestra di dialogo mostrata nella Figura 4-105.

Figura 4-105    Finestra di dialogo Time Display

<img src="../../../configuration-guide/basic-control/time.files/image004.jpg" width="130" />

Nota: per Forma, Colore bordo, Colore primo piano, Colore sfondo e Motivo, vedere l'oggetto Pulsante di bit.

• Formato (Format): sono disponibili quattro formati dell'ora.

HH:MM                Ore: Minuti

HH:MM:SS           Ore: Minuti: Secondi

HH-MM-SS           Ore- Minuti-Secondi

HH-MM                Ore- Minuti

• Carattere (Font): tipo di carattere del testo

• Dimensione carattere (Font Size): dimensione del testo visualizzato

• Colore (Color): colore del testo visualizzato

• Allineamento (Alignment): posizione del testo: a sinistra, al centro o a destra.

Dopo le impostazioni, fare clic su "OK" per aggiungere l'oggetto all'area di visualizzazione (la pagina)
