# Immagine statica

L'oggetto Immagine statica serve principalmente a mostrare un'immagine, in vari formati, presa da un file o dalla libreria. Può essere usato come sfondo della pagina per migliorare l'aspetto dell'interfaccia del progetto.

1\. Fare clic sull'icona dell'immagine statica<img src="../../../configuration-guide/basic-control/picture.files/image002.jpg" width="30" /> nella barra degli strumenti per aprire la finestra di dialogo mostrata nella Figura 4-109:

<img src="../../../configuration-guide/basic-control/picture.files/image004.jpg" width="675" />

Figura 4-109   Finestra di dialogo Static Picture

2\. Dopo aver selezionato un'immagine, fare clic su OK: il cursore assume la forma di una croce; fare clic con il tasto sinistro in un punto qualsiasi della pagina per aggiungere l'oggetto immagine.

3\. Le dimensioni dell'immagine inserita possono essere modificate con il mouse. Il software di configurazione CommandHMI supporta vari formati di immagine: JPG, BMP, PNG, WMF, EMF, GIF.
