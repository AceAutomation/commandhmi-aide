# Visualizzazione data

L'oggetto Visualizzazione data serve principalmente a visualizzare la data di sistema. Fare clic sull'icona <img src="../../../configuration-guide/basic-control/date.files/image002.jpg" width="31" /> nella barra degli strumenti: compare la finestra di dialogo mostrata nella Figura 4-106:

<img src="../../../configuration-guide/basic-control/date.files/image005.jpg" width="675" />

Figura 4-106   Finestra di dialogo Date Display

• Formato (Format): sono disponibili nove formati di data.

YYYY-MM-DD

MM-DD-YYYY

DD-MM-YYYY

YYYY/MM/DD

MM/DD/YYYY

DD/MM/YYYY

YYYY.MM.DD

MM.DD.YYYY

DD.MM.YYYY

• Carattere (Font): tipo di carattere del testo

• Dimensione carattere (Font Size): dimensione del testo visualizzato

• Colore (Color): colore del testo visualizzato

• Allineamento (Alignment): posizione del testo: a sinistra, al centro o a destra.

<span id="OLE_LINK738"></span><span id="OLE_LINK739"></span><span id="OLE_LINK749"></span>Dopo le impostazioni, fare clic su "OK" per aggiungere l'oggetto all'area di visualizzazione (la pagina)

<img src="../../../configuration-guide/basic-control/date.files/image004.jpg" width="130" />

Nota: per Forma, Colore bordo, Colore primo piano, Colore sfondo e Motivo, vedere l'oggetto Pulsante di bit.
