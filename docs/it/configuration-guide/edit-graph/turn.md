# Rotazione

Questo comando agisce su un gruppo di oggetti. Il software di configurazione CommandHMI permette di ruotare uno o più oggetti grafici di qualsiasi angolo. Possono essere ruotati linee, cerchi, rettangoli, elementi della libreria di sistema, oggetti, gruppi di elementi grafici e poligoni.

• **Capovolgi orizzontalmente (Flip Horizontal)**

"Flip horizontal" ruota l'oggetto grafico selezionato (o più oggetti) di 180° attorno al suo asse verticale centrale. Selezionare uno o più oggetti, quindi fare clic su "Flip Horizontal" nel sottomenu "Mirror" del menu Edit oppure sul pulsante Flip Horizontal nella barra degli strumenti<img src="../../../configuration-guide/edit-graph/turn.files/turn649.png" width="27" />.

• **Capovolgi verticalmente (Flip Vertical)**

"Flip Vertical" ruota l'oggetto grafico selezionato (o più oggetti) di 180° attorno al suo asse orizzontale centrale. Selezionare uno o più oggetti, quindi fare clic su "Flip Vertical" nel sottomenu "Mirror" del menu Edit oppure sul pulsante Flip Vertical nella barra degli strumenti<img src="../../../configuration-guide/edit-graph/turn.files/turn1297.png" width="26" />.

• Rotazione

Attualmente questa funzione è supportata solo dai 12 oggetti seguenti:

Visualizzazione ora, Visualizzazione data, Visualizzazione giorno della settimana, Immagine statica, Visualizzazione GIF, Immagine, Visualizzazione numerica, Inserimento numerico, Visualizzazione ASCII, Inserimento ASCII, Spia multistato, Pulsante multistato

La rotazione permette al progettista di ruotare l'oggetto selezionato fino a 360° attorno al suo centro. Selezionare un oggetto e fare clic sul comando "rotate" nel menu Edit oppure sul pulsante di rotazione nella barra degli strumenti<img src="../../../configuration-guide/edit-graph/turn.files/image001.jpg" width="36" alt="ScreenShot00091.jpg" />
