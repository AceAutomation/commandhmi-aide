# Livelli

Il comando Livelli agisce su un gruppo di oggetti e serve a regolare l'ordine di visualizzazione degli oggetti grafici sovrapposti. In CommandHMI ogni oggetto ha un livello grafico: gli oggetti di livello superiore sono sempre visualizzati sopra quelli di livello inferiore, e questo comando permette di modificarne l'ordine. Un nuovo oggetto grafico ha per impostazione predefinita un livello superiore a quelli esistenti. Il comando Livelli di CommandHMI comprende quattro comandi: <span id="OLE_LINK363"></span><span id="OLE_LINK364"></span>Porta in primo piano, Porta avanti, Porta in fondo e Porta indietro. Per eseguirli, selezionare uno o più oggetti grafici nella pagina corrente e scegliere il comando corrispondente nel menu Edit o nella barra degli strumenti.

• **Porta in primo piano (Bring To Top)**

Sposta l'oggetto grafico selezionato al livello più alto, in modo che copra le parti sovrapposte degli altri oggetti.

Selezionare un oggetto tra quelli presenti, quindi scegliere il comando Bring To Top nel menu Edit, oppure il pulsante<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement956.png" width="27" /> nella barra degli strumenti, oppure il comando Bring To Top dell'opzione Layer nel menu contestuale. Il confronto prima/dopo è mostrato nella Figura 4-8.

• **Porta in fondo (Send To Bottom)**

Sposta l'oggetto grafico selezionato al livello più basso, in modo che le sue parti sovrapposte risultino nascoste.

Selezionare un oggetto tra quelli presenti, quindi scegliere il comando Send To Bottom nel menu Edit, oppure il pulsante<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement1482.png" width="25" /> nella barra degli strumenti, oppure il comando Send To Bottom dell'opzione Layer nel menu contestuale. Il confronto prima/dopo è mostrato nella Figura 4-9.

<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement1800.png" width="488" />

Figura 4-9 Confronto prima/dopo del comando Send To Bottom

• **Porta avanti (Bring Forward)**

<span id="OLE_LINK375"></span><span id="OLE_LINK376"></span>Sposta l'oggetto grafico selezionato di un livello verso l'alto rispetto agli oggetti sovrapposti. Selezionare un oggetto, quindi scegliere "<span id="OLE_LINK373"></span><span id="OLE_LINK374"></span>Bring forward" nel menu Edit o nella barra degli strumenti, oppure nei comandi Layer del menu contestuale.

Selezionare un oggetto tra quelli presenti, quindi scegliere il comando Bring Forward nel menu Edit, oppure il pulsante<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement2335.png" width="24" /> nella barra degli strumenti, oppure il comando Bring Forward dell'opzione Layer nel menu contestuale. • **Porta indietro (Send Backward)**

Sposta l'oggetto grafico selezionato di un livello verso il basso rispetto agli oggetti sovrapposti. Selezionare un oggetto, quindi scegliere "Send backward" nel menu Edit o nella barra degli strumenti, oppure nei comandi Layer del menu contestuale.

Selezionare un oggetto tra quelli presenti, quindi scegliere il comando Send Backward nel menu Edit, oppure il pulsante<img src="../../../configuration-guide/edit-graph/arrangement.files/arrangement3043.png" width="23" /> nella barra degli strumenti, oppure il comando Send Backward dell'opzione Layer nel menu contestuale.
