# Raggruppa e separa

Il comando Raggruppa agisce su un gruppo di oggetti: combina due o più oggetti grafici e oggetti della pagina corrente in un unico oggetto. Gli elementi raggruppati possono essere grafica disegnata dal progettista, elementi della libreria di sistema o altri oggetti, come allarmi, grafici di tendenza, ecc. Dopo il raggruppamento ogni oggetto conserva le sue proprietà, che restano modificabili. Il comando Separa scompone un gruppo negli elementi originali ed è quindi l'operazione inversa del raggruppamento.

**Come raggruppare:**

Selezionare più oggetti grafici, quindi scegliere il comando Group <img src="../../../configuration-guide/edit-graph/combine.files/combine1314.png" width="33" /> nel menu Edit, oppure il pulsante corrispondente nella barra degli strumenti, oppure la voce "Group" del menu contestuale.
