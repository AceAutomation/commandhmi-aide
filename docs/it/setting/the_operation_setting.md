# Impostazioni operative

Impostazioni operative della configurazione:

<img src="../../setting/the_operation_setting.files/image002.jpg" width="360" alt="ScreenShot00056.jpg" />

• Modalità di selezione

Selezione per area: vengono selezionati gli oggetti che la cornice tracciata con il mouse tocca anche solo in parte

Selezione per oggetto: vengono selezionati solo gli oggetti interamente contenuti nella cornice tracciata con il mouse

•  Modalità incolla

Incolla con clic del mouse: dopo aver copiato un oggetto e scelto Incolla, l'utente fa clic dove posizionarlo

Incolla nella stessa posizione: dopo aver copiato un oggetto e scelto Incolla, l'oggetto viene incollato vicino alla posizione dell'oggetto copiato

•  Tipo di file per chiavetta USB

6. Versione 6.0: genera un file per chiavetta USB della versione 6.0

Superiore alla versione 6.0: genera un file per chiavetta USB di versione superiore alla 6.0
