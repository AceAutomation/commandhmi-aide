# Tabella delle variabili

Definisce un'etichetta associata a un indirizzo: quando si usa l'etichetta, si fa riferimento all'indirizzo corrispondente. Per configurare le variabili, fare doppio clic sulla voce "Tabella variabili" nel "Gestore di progetto": compare la finestra mostrata nella Figura 7-15:

<img src="../../setting/variblesetting.files/variblesetting735.png" width="614" />

Figura 7-15    Finestra Tabella variabili

• Nuovo: aggiunge una nuova etichetta; il numero massimo totale è 1000

• Elimina: elimina l'etichetta selezionata.

• Modifica: modifica l'etichetta selezionata (oppure fare doppio clic su di essa).

• Elimina tutto: elimina tutte le etichette di variabile.

• Importa: apre la finestra Apri file per importare un file di tabella variabili.

• Esporta: apre la finestra Salva con nome per esportare la tabella variabili corrente.

<img src="../../setting/variblesetting.files/variblesetting1256.png" width="277" />

Figura 7-16    Finestra di creazione variabile

• Nome variabile: imposta il nome della nuova variabile.

• Tipo di indirizzo: seleziona il tipo di dati dell'indirizzo.

• Indirizzo: seleziona l'indirizzo collegato.
