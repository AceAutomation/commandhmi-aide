# Crittografia dei file

Indica se è necessaria una password per aprire il file di progetto.

Fare doppio clic sulla voce "Crittografia file" (File Encryption) nel "Gestore di progetto": compare la finestra della Figura 7-12:

<img src="../../setting/file-protect.files/image004.jpg" width="286" />

Figura 7-12    Finestra Crittografia file

Selezionare "Usa password per proteggere il file" nella finestra sopra, inserire Password e Conferma password e fare clic su "OK" per completare.

Da questo momento, quando l'utente riapre il progetto, compare una finestra di immissione password, come mostrato nella Figura 7-13:

<img src="../../setting/file-protect.files/image002.jpg" width="331" alt="ScreenShot00055.jpg" />

Figura 7-13    Finestra di immissione password

Per aprire il progetto l'utente deve inserire la password.
