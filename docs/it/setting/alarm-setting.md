# Impostazioni allarmi

Le impostazioni allarmi di CommandHMI comprendono la registrazione degli allarmi digitali e degli allarmi analogici. Dopo averle configurate, l'utente può vedere il tipo di allarme e l'ora in cui si è verificato tramite l'oggetto Allarme o la Barra allarmi.

**Indice:**

• [Registrazione allarmi digitali](dig-alarm.md)

• [Registrazione allarmi analogici](anal-alarm.md)

• [Oggetti di visualizzazione allarmi](alarm-display.md)

• [Registrazione allarmi discreti](lisanbaojing.md)
