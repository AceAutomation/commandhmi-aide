# Script di inizializzazione

Imposta uno script compilato correttamente come script di inizializzazione: lo script viene eseguito una sola volta, indipendentemente dalle pagine. Si possono aggiungere fino a 64 script di inizializzazione, eseguiti nell'ordine impostato.

Fare clic su "Script di inizializzazione" (Init Script) nel menu "Impostazioni", come mostrato nella finestra:

<img src="../../setting/init-macro.files/init-macro309.png" width="436" />

Fare clic sulla voce dell'elenco per visualizzare tutti gli script compilati correttamente. Lo script selezionato viene eseguito come macro di inizializzazione durante il runtime.
