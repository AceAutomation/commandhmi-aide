# Registrazione allarmi discreti

Espandendo le opzioni di registrazione allarmi, fare doppio clic su "Nuova registrazione allarmi discreti" per aprire la finestra delle impostazioni degli allarmi discreti

<img src="../../setting/lisanbaojing.files/image001.jpg" width="766" />

• Nuovo: aggiunge un nuovo allarme; la categoria di dati è liberamente selezionabile

<img src="../../setting/lisanbaojing.files/image002.jpg" width="178" />

• Elimina: elimina un allarme

• Elimina tutto: elimina tutti gli allarmi

• Esporta: esporta gli allarmi impostati

• Importa: importa allarmi impostati

Pagina di impostazione di un nuovo allarme:

• Categoria di dati: scegliere la categoria di dati appropriata in base alla condizione di allarme

• Indirizzo: imposta l'indirizzo da monitorare per l'allarme

• Numero di consecutivi: imposta se monitorare N indirizzi consecutivi

• Messaggio di allarme: il messaggio mostrato quando il valore dell'indirizzo soddisfa la condizione di allarme

• Condizione di allarme: imposta la condizione di allarme sul valore dell'indirizzo; le condizioni sono le seguenti:

<img src="../../setting/lisanbaojing.files/image004.jpg" width="179" /><img src="../../setting/lisanbaojing.files/image005.jpg" width="184" />

• L Allarme bit ON: con categoria bool, l'allarme scatta quando l'indirizzo è ON

• L Allarme bit OFF: con categoria bool, l'allarme scatta quando l'indirizzo è OFF

• L Allarme a valore fisso: l'allarme scatta quando l'indirizzo ha il valore impostato

• L Allarme in intervallo: l'allarme scatta quando il valore dell'indirizzo è all'interno dell'intervallo impostato

• L Allarme fuori intervallo: l'allarme scatta quando il valore dell'indirizzo è fuori dall'intervallo impostato

• Colore allarme: imposta il colore del messaggio quando scatta l'allarme
