# Script globale

Imposta uno script compilato correttamente come script globale: lo script viene eseguito all'avvio della configurazione e per tutto il runtime, indipendentemente dalle pagine. Si possono aggiungere fino a 64 script globali, eseguiti nell'ordine impostato.

Fare clic su "Script globale" (Global Script) nel menu "Impostazioni", come mostrato nella finestra:

<img src="../../setting/overall-macro.files/overall-macro384.png" width="437" />

Fare clic sulla voce dell'elenco per visualizzare tutti gli script compilati correttamente, poi scegliere se lo script è controllato da un bit e con quale frequenza viene eseguito. Lo script selezionato viene eseguito come script globale durante il runtime.
