# Istruzione continue

L'istruzione continue si usa solo nel corpo di un ciclo. La sua forma generale è continue;

Significato: termina l'iterazione corrente senza eseguire le istruzioni che seguono continue nel corpo del ciclo, quindi passa a valutare la condizione per l'iterazione successiva. Attenzione: questa istruzione termina solo l'iterazione corrente del ciclo in cui si trova, senza uscire dal ciclo.
