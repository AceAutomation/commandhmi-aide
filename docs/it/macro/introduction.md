# Pulsanti funzione dell'editor di script

Gli oggetti funzionali sono disposti nella finestra dell'editor di script come mostrato in Figura 5-3 (Editor di script).

<img src="../../macro/introduction.files/introduction563.png" width="1086" />

Figura 5-3 (Editor di script)

**&lt;1&gt; Elenco degli script:**

**1.**<img src="../../macro/introduction.files/introduction768.png" width="26" />**Nuovo (New):** crea un nuovo script

**2.**<img src="../../macro/introduction.files/introduction952.png" width="31" />**Importa (Import):** importa uno script esistente.

**3.  Riusciti (Success):** script compilati correttamente

**4.  Falliti (Fail):** script la cui compilazione non è riuscita

**5.  Non completati (Not complited):** script non ancora completati

6\. **Non salvati (Not save):** script non ancora salvati

7\. **Elimina (Delete): ‘**selezionare lo script con il clic sinistro, poi con il clic destro compare 'Elimina script'; fare clic per eliminarlo

   <img src="../../macro/introduction.files/introduction1460.png" width="275" />

**
**

**&lt;2&gt; Finestra di modifica script:** in questa finestra si scrive e si compila lo script. "ID": numero dello script in modifica; "Script": nome dello script in modifica, modificabile.

<img src="../../macro/introduction.files/introduction1778.png" width="324" />: menu di modifica script, composto da dieci pulsanti:

<img src="../../macro/introduction.files/introduction1990.png" width="32" /> **Annulla (Undo):** annulla l'ultima operazione.

<img src="../../macro/introduction.files/introduction2177.png" width="31" />  **Ripeti (Redo):** ripete l'operazione annullata.

<img src="../../macro/introduction.files/introduction2363.png" width="19" />  **Taglia (Cut)**: taglia la parte di script selezionata.

<img src="../../macro/introduction.files/introduction2547.png" width="32" /> **Incolla (Paste)**: incolla lo script.

<img src="../../macro/introduction.files/introduction2722.png" width="21" /> **Copia (copy)**: copia lo script.

<img src="../../macro/introduction.files/introduction2895.png" width="23" /> **Salva (Save)**: salva lo script.

<img src="../../macro/introduction.files/introduction3068.png" width="29" />**Esporta (Export)**: apre la finestra di salvataggio file; scegliere percorso e nome per salvare lo script come file \*.csv.

<img src="../../macro/introduction.files/introduction3313.png" width="26" /> **Compila (Compile)**: compila il codice sorgente dello script corrente e verifica gli errori di sintassi.

<img src="../../macro/introduction.files/introduction3544.png" width="26" /> **Comprime/mostra la finestra di impostazioni e output.**

<img src="../../macro/introduction.files/introduction3740.png" width="22" /> **Guida (Help)**: mostra il file della guida.

**&lt;3&gt; Finestra di impostazioni e output:** in questa finestra si impostano le variabili e compaiono le informazioni di compilazione.

**Scheda "Impostazione variabili" (Variable Setting):** fare clic su "Nuovo" in questa scheda per aprire la finestra "Nuove variabili dello script", come mostrato nella Figura 5.6. La variabile viene associata a un registro.

  <img src="../../macro/introduction.files/introduction4182.png" width="500" />

Figura 5-5 Nuove variabili di script

**Scheda "Output informazioni di compilazione" (Compile information output):** la finestra mostra le informazioni sulla compilazione e sul collegamento del programma. L'utente può eseguire il debug e le correzioni in base ai messaggi visualizzati.

<img src="../../macro/introduction.files/introduction4565.png" width="773" />

Figura 5-6 Output delle informazioni di compilazione

**&lt;4&gt; Elenco funzioni (Function List):** l'utente può scegliere una funzione di sistema e inserirla nella finestra di modifica dello script.
