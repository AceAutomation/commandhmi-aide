# Inserire funzioni di libreria nel programma

Fare clic sul pulsante "Function": si apre la finestra di dialogo mostrata in Figura 5-5. Selezionare la funzione di libreria desiderata nell'elenco dei nomi delle funzioni e fare clic su "Conferma": la funzione viene inserita automaticamente nella posizione del cursore nella finestra di modifica.

Per le funzioni, i tipi di parametri e le altre istruzioni dettagliate sulle funzioni di libreria, consultare l'Appendice 1.
