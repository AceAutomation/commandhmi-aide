# Istruzione break

L'istruzione break si usa solo all'interno di un'istruzione switch o di un ciclo. Serve per uscire dallo switch o dal ciclo corrente e proseguire con il resto del programma. Poiché la destinazione del salto di break è fissa, non sono necessarie etichette. La forma generale è break;. Come mostrato nell'esempio precedente, l'istruzione break si usa nelle istruzioni switch e for per uscire. L'istruzione break offre più punti di uscita da un ciclo, rendendo la programmazione più flessibile e comoda in alcune situazioni.
