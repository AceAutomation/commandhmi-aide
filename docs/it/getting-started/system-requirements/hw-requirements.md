# Requisiti hardware

I requisiti hardware minimi di CommandHMI sono:

CPU: almeno Pentium 3 a 800 MHz;

Memoria: almeno 128 MB con sistema operativo Windows 9X;

<span id="OLE_LINK68"></span><span id="OLE_LINK69"></span><span id="OLE_LINK60"></span><span id="OLE_LINK61"></span>almeno 256 MB con sistema operativo Windows NT;

almeno 256 MB con sistema operativo Windows 2000 o XP;

Scheda grafica: <span id="OLE_LINK71"></span><span id="OLE_LINK70"></span>compatibile <span id="OLE_LINK62"></span><span id="OLE_LINK63"></span>Windows, con almeno 1 MB di memoria video, risoluzione 1024 \* 768 a 256 colori;

Disco: almeno 200 MB di spazio libero per il software di configurazione CommandHMI.

Computer con interfaccia USB;

Mouse a due tasti e tastiera.

<img src="../../../getting-started/system-requirements/hw-requirements.files/image002.jpg" width="130" />

Con una configurazione inferiore a quella indicata, l'installazione o l'esecuzione di CommandHMI potrebbero non riuscire.

**Configurazione consigliata:**

CPU: Intel Pentium 800 o equivalente, o superiore;

Memoria: almeno 256 MB con sistema operativo Windows 9X;

almeno 512 MB con sistema operativo Windows NT;

almeno 512 MB con sistema operativo Windows 2000 o XP.

Scheda grafica: compatibile Windows, con almeno 1 MB di memoria video, risoluzione 1024 \* 768 a 65535 colori.

Disco: almeno 200 MB di spazio libero.
