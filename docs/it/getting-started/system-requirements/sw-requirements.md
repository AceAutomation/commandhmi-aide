# Requisiti software

Il software di configurazione CommandHMI funziona con i seguenti sistemi operativi:

· Microsoft Windows NT Server 4.0 o successivo;

· Microsoft Windows NT Workstation 4.0 o successivo;

· Microsoft Windows 98, Me, 2000, XP, Windows 7 o successivo.

<img src="../../../getting-started/system-requirements/sw-requirements.files/image002.jpg" width="130" />

Con sistemi operativi diversi da quelli indicati, CommandHMI non si installa.

<span id="OLE_LINK52"></span><span id="OLE_LINK53"></span>**Sistemi consigliati:**

Windows XP SP3; Windows 7 32 bit; Windows 7

Non ci sono differenze tra sistemi operativi in cinese e in inglese.
