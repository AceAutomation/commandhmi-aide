# Termini comuni

La tabella 2-3 riporta alcuni termini comuni della configurazione.

|                   |                                                                                                                                                                                                                                                                                                                                 |
|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Progetto | Indica l'applicazione dell'utente. Il concetto di progetto rende più accessibili ai tecnici le competenze informatiche complesse. I file creati con CommandHMI hanno estensione .vpm e possono essere salvati in qualsiasi posizione. |
| Oggetto | Gli elementi su cui si opera e l'ambiente operativo sono detti oggetti: finestre, componenti, dati, elementi grafici, ecc. |
| Selezionare l'oggetto | Rendere operabile una finestra o un oggetto con un clic del mouse si dice selezionare l'oggetto; l'oggetto selezionato (finestre comprese) è detto anche oggetto corrente |
| Configurazione | Definire, creare e modificare oggetti in una finestra e impostarne i parametri di stato (attributi) |
| Attributo | Nome, tipo, stato, proprietà e uso di un oggetto sono detti complessivamente attributi |
| Menu | <span id="OLE_LINK237"></span><span id="OLE_LINK236"></span>Insieme di comandi. Per esempio, il menu "File" contiene i comandi relativi ai file di progetto. I menu di CommandHMI sono tutti menu a discesa e possono avere più livelli di sottomenu |
| Pulsante di comando | Pulsante associato a un comando, presente nella barra degli strumenti o nella barra dei menu |
| Set ON | Porta a "ON" un oggetto con visualizzazione dello stato di un bit |
| Set OFF | Porta a "OFF" un oggetto con visualizzazione dello stato di un bit |
| Stile | Effetto di sfumatura dell'oggetto dal colore di primo piano al colore di sfondo |
| Indirizzo | Variabili di memoria associate all'oggetto corrente |
| Dispositivo collegato | Dispositivi di comunicazione collegati al progetto corrente |
| Oggetto (control) | <span id="OLE_LINK231"></span><span id="OLE_LINK230"></span>Insieme di funzioni specifiche |
