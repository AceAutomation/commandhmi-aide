# Uso del mouse e tasti di scelta rapida

Quando si usa il mouse per creare le pagine nell'editor di configurazione, il cursore si presenta come nella Figura 2-45:

<img src="../../../getting-started/basic-operation/mouse.files/image010.jpg" width="318" />

Figura 2-45        Cursore del mouse

Ecco alcune operazioni comuni con il mouse e il loro scopo:

◎ Clic sinistro

Premere e rilasciare il tasto sinistro<span id="OLE_LINK219"></span><span id="OLE_LINK218"></span>: in questo manuale si chiama \[clic\]; serve a scegliere le voci di menu, selezionare oggetti, scegliere i pulsanti degli strumenti, modificare le pagine e confermare le impostazioni.

◎ Doppio clic sinistro

Premere rapidamente due volte il tasto sinistro: in questo manuale si chiama \[doppio clic\]; serve ad aprire le proprietà degli elementi presenti nella pagina (attributi di pagine e finestre, proprietà di collegamento del touch screen, ecc.) e a modificare le impostazioni di raccolta dati storici, ricette, allarmi e altri oggetti.

◎ Clic destro

Premere e rilasciare il tasto destro: in questo manuale si chiama \[clic destro\]. Facendo clic con il tasto destro su un elemento si apre il relativo menu, mentre in un punto vuoto si apre il menu contestuale. Il clic destro permette anche di uscire dalla modalità di modifica e ripristinare il cursore normale.

◎ Trascinamento

Spostare il mouse tenendo premuto il tasto: in questo manuale si chiama \[trascinamento\]; serve a selezionare più elementi, spostare oggetti e spostare le finestre di modifica.

### <span id="OLE_LINK225"></span><span id="OLE_LINK224"></span>Tasti di scelta rapida

La tabella 2-2 elenca i tasti di scelta rapida più comuni, che permettono di velocizzare la configurazione.

|                   |                                                     |
|-------------------|-----------------------------------------------------|
| CTRL+C | Copia |
| CTRL+V | Incolla |
| CTRL+X | Taglia |
| CTRL+F | Vai alla pagina |
| CTRL + trascinamento | Copia l'oggetto selezionato e lo sposta |
| CTRL + clic sinistro | Seleziona più oggetti |
| ← → ↑ ↓ | Sposta l'oggetto selezionato a sinistra, a destra, in alto, in basso |
| ESC | Annulla l'operazione |
|                   | Elimina |
