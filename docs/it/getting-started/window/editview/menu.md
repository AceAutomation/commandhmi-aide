# Barra dei menu

La barra dei menu del software di configurazione CommandHMI offre numerose opzioni, che coprono quasi tutti gli strumenti e i comandi di modifica necessari. Comprende i menu File, Edit, View, Draw, Object, Screen, Setting, Download, Help, il menu di selezione della lingua e il menu contestuale (tasto destro).

Figura 2-28        Barra dei menu

**Menu File**

Il menu "File" comprende New project (N), Open Project (O), Close, Save (S), Save As e Quit (Q). Una voce in grigio indica che l'operazione non è disponibile nel contesto corrente. Per aprire il menu, fare clic su "File (F)" in alto a sinistra: compare il menu a discesa File.

<img src="../../../../getting-started/window/editview/menu.files/menu742.png" width="278" />

Figura 2-29 Menu "File"

• New Project: tasto di scelta rapida Ctrl + N; crea un progetto vuoto.

• Open Project: tasto di scelta rapida Ctrl + O; apre un file di progetto .vpm creato e salvato in precedenza.

• Close: chiude il progetto corrente senza uscire dal software di configurazione CommandHMI.

• Save: tasto di scelta rapida Ctrl + S; salva il file di configurazione corrente modificato, con lo stesso nome e percorso.

• Save As: salva il file di configurazione corrente con un nome e un percorso diversi.

• Exit: chiude il software di configurazione CommandHMI.

**Menu Edit**

Il menu "Edit" contiene i comandi per modificare testi, elementi grafici e altri contenuti della pagina: Undo, Restore, Cut (T), Copy (C), Multiple copy (D), Paste (P), Delete (D), Select All (A), Align, Layer, Group, Mirror, Zoom, Grid, Property setting, Find Address, Address Table, Reverse Select, Macro search, Macro Manager. Un comando in grigio non è disponibile nel contesto corrente. Per eseguire questi comandi, selezionare prima l'oggetto grafico da modificare, quindi il comando nel menu "Edit". Alcuni comandi del menu "Edit" sono gruppi di comandi: in questo caso a destra compare un piccolo triangolo che apre un sottomenu, e ogni comando ha un tasto di scelta rapida.

• Undo: tasto di scelta rapida Ctrl + Z; annulla l'ultima operazione.

• Restore: tasto di scelta rapida Ctrl + Y; ripristina l'ultima operazione annullata.

• Cut: tasto di scelta rapida Ctrl + X; elimina gli oggetti grafici selezionati copiandoli negli appunti.

• Copy: tasto di scelta rapida Ctrl + C; copia negli appunti l'oggetto grafico selezionato.

• Multiple copy: copia più volte gli oggetti selezionati in orizzontale e in verticale, con indirizzi crescenti da 0 a 255 unità.

• Paste: tasto di scelta rapida Ctrl + V; incolla nella pagina corrente gli oggetti grafici presenti negli appunti.

• Delete: tasto Canc; elimina dalla pagina l'oggetto grafico selezionato.

<img src="../../../../getting-started/window/editview/menu.files/menu2833.png" width="193" />

Figura 2-30 Menu "Edit"

• Select: tasto di scelta rapida Ctrl + A; seleziona tutti gli oggetti della pagina corrente.

• Align: allinea gli oggetti selezionati (almeno due) secondo il tipo scelto: Top, Bottom, Vertical Center, Left, Right, Horizontal Equal Interval, Vertical Equal Interval, Make same width, Make same height, Make same width and height.

• Layer: sposta gli oggetti selezionati a un altro livello: Bring To Top, Bring Forward, Send to Bottom o Send Backward.

• Group: combina gli oggetti selezionati (almeno due) in un unico oggetto, oppure scompone un oggetto raggruppato negli oggetti originali. Non raggruppare oggetti che devono rispondere al tocco, altrimenti dopo il download nel touch screen non saranno più utilizzabili; per sovrapporre oggetti sensibili al tocco usare il comando Layer.

<img src="../../../../getting-started/window/editview/menu.files/menu3850.png" width="130" />

Non raggruppare oggetti che devono rispondere al tocco, altrimenti dopo il download nel touch screen non saranno più utilizzabili. Per sovrapporre oggetti sensibili al tocco usare il comando Layer.

• Mirror: capovolge l'oggetto selezionato in orizzontale o in verticale.

• Zoom: ingrandisce o riduce la pagina corrente per lavorare con maggiore precisione: Zoom In, Zoom Fit e Zoom Out.

• Grid: mostra o nasconde nella pagina corrente una griglia di passo definito.

• Property settings: apre la finestra delle proprietà dell'oggetto selezionato (un solo oggetto) o della pagina (nessun oggetto selezionato).

• Find Address: cerca un indirizzo in uso.

• Address Table: apre o chiude l'elenco degli indirizzi usati dagli oggetti, utile per cercarli e sostituirli.

• Invert Selection: seleziona tutti gli oggetti della pagina corrente non selezionati, deselezionando quelli selezionati.

• Macro Search: individua le chiamate di una macro nel progetto; la macro può essere scelta o digitata manualmente.

• Macro Manager: mostra dove sono usate tutte le macro, in tutte le pagine o in una pagina specifica.

**Menu View**

Questo menu permette di personalizzare l'interfaccia di lavoro, scegliendo quali finestre mostrare. Il segno √ a sinistra di un comando indica che l'elemento è visibile, altrimenti è nascosto.

<img src="../../../../getting-started/window/editview/menu.files/menu5440.png" width="385" />

**Menu Draw**

Questo menu serve principalmente a disegnare elementi grafici nella pagina. CommandHMI offre Line (L), Polyline (B), Curve / Arc (A), Free Lines, Rectangles (R), Round Rectangle, Ellipse (E), Polygon (Y), Arc, Text (T), Open Library (O), Build Library (C), Table e Scale. Colore, testo, dimensioni e posizione degli elementi creati possono essere modificati facilmente.

<img src="../../../../getting-started/window/editview/menu.files/menu5835.png" width="153" />

Figura 2-31        Menu "Draw"

• Line: disegna una linea retta in qualsiasi direzione nella pagina corrente.

• Polyline: disegna una polilinea in qualsiasi direzione nella pagina corrente.

• Curve / Arc: disegna una linea nella pagina corrente; dopo averla completata con il tasto destro, se ne può regolare la curvatura.

• Free line: disegna una linea a mano libera che segue il movimento del mouse.

• Rectangle: disegna un rettangolo di qualsiasi dimensione nella pagina corrente.

• Rounded Rectangle: disegna un rettangolo con angoli arrotondati nella pagina corrente.

• Ellipse: disegna un'ellisse di qualsiasi dimensione nella pagina corrente.

• Polygon: disegna un poligono qualsiasi nella pagina corrente.

• Arc: disegna un settore qualsiasi nella pagina corrente.

• Text: crea un rettangolo trasparente in cui inserire un testo.

• Open Library: apre la libreria di immagini del sistema.

• Build Library: salva l'elemento grafico disegnato dall'utente come file di libreria, per riutilizzarlo facilmente.

• Table: crea nella pagina corrente una tabella con il numero di righe e colonne desiderato.

• Scale: disegna una scala graduata.

**Menu Object**

Il menu "Object" raccoglie tasti a sfioramento e tasti funzione: Bit Switch, Word Switch, Screen Button, Function Button, Multifunction key, Stepping Button, Single Button, Combo Box, Sliders, Numerical Display, Numerical Input Display, ASCII Display, ASCII Entry, Bit Lamp, Multistate Switch, Multistate Lamp, Message display, Time Display, Date Display, Weekday Display, Static Picture, Picture Display, GIF Display, Dynamic Diagram, Dynamic circle, Dynamic Rectangle, Flowing block, Graphics Move, Animation, Bar Graph, Meter, Arc chart, Trend Chart, XY Trend Chart, Historic trend, Data group, Historical data, Alarm Control, Alarm Bar, Historical Alarm, Timer, Message Board, Recipe selector, Recipe data display, Keyboard e Qrcode. Il menu "Object" corrisponde alla terza riga della barra degli strumenti.

• Bit Switch: crea tasti a sfioramento che eseguono operazioni sui bit del dispositivo collegato: Set ON, Set OFF, impulsivo e inversione.

• Word switch: crea nella pagina corrente un tasto a sfioramento che esegue operazioni su word del dispositivo collegato: Add, Subtract, Increasing, Decreasing, Set Constant, Enter Value, Enter Password.

• More Button: dà accesso a Screen Button, Function Button, Multifunction key, Stepping Button, Single button, Combo Box e Sliders.

• Numerical Display: disegna nella pagina corrente un riquadro di visualizzazione numerica del valore di un indirizzo monitorato.

• Numeric Input Display: disegna nella pagina corrente un riquadro per l'inserimento di dati e la visualizzazione del valore di un indirizzo monitorato.

• ASCII Display: disegna nella pagina corrente un riquadro di visualizzazione di testo ASCII.

• ASCII Input Display: disegna nella pagina corrente un riquadro di inserimento e visualizzazione di testo ASCII.

• Bit Lamp: crea nella pagina corrente un'immagine che monitora lo stato di un bit del dispositivo collegato.

• Multistate Switch: crea un pulsante multistato che monitora le variazioni del valore di un indirizzo del dispositivo collegato e cambia stato di conseguenza.

• Multistate Lamp: inserisce nella pagina corrente un'immagine che monitora lo stato di una word del dispositivo.

<img src="../../../../getting-started/window/editview/menu.files/menu9590.png" width="174" />

Figura 2-32        Menu "Object"

• Message Display: crea nella pagina corrente un oggetto che visualizza messaggi preconfigurati.

• Time Display: inserisce nella pagina un oggetto che visualizza l'ora.

• Date Display: inserisce nella pagina un oggetto che visualizza la data.

• Week Display: inserisce nella pagina corrente un oggetto che visualizza il giorno della settimana.

• Static Picture: inserisce nella pagina corrente un'immagine statica presente sul disco locale.

• Picture Display: disegna nella pagina corrente un riquadro per visualizzare più immagini.

• GIF Display: disegna nella pagina corrente un riquadro per visualizzare un'immagine .GIF statica o animata.

• Dynamic Diagram: apre gli oggetti Dynamic Circle, Dynamic Rectangle, Flowing block, Graphics Move e Animation.

• Bar Graph: inserisce nella pagina corrente un grafico a barre, che mostra le variazioni del valore dell'indirizzo monitorato con l'innalzarsi o l'abbassarsi (o lo spostamento laterale) della barra.

• Meter: crea nella pagina corrente uno strumento a lancetta che monitora le variazioni del valore di un indirizzo del dispositivo collegato.

• Arc chart: inserisce nella pagina corrente un grafico a settore che rappresenta il valore dell'indirizzo monitorato; l'area attiva può essere rappresentata con Pie FG Color, Pie BG Color o Bottom Color.

• Chart: apre gli oggetti Trend Chart, XY Trend Chart, Historical trend e Data group.

• Historical Data: crea nella pagina corrente un oggetto che visualizza i dati salvati dalla raccolta dati storici.

• Alarm: apre gli oggetti Alarm Control, Alarm Bar e History Alarm.

• Timer: inserisce nella pagina corrente un oggetto che attiva una funzione in base a condizioni temporali.

• Message Board: inserisce nella pagina corrente un oggetto su cui l'utente può scrivere.

• Recipe Selector: inserisce nella pagina corrente un oggetto che mostra i nomi di tutte le ricette esistenti.

• Recipe Data Display: inserisce nella pagina corrente un oggetto che mostra tutti i dati delle ricette configurate.

• Keyboard: inserisce nella pagina corrente un oggetto tastiera, i cui tasti possono essere personalizzati.

• Qrcode: inserisce nella pagina un oggetto codice QR personalizzato; va usato insieme a un oggetto di inserimento, altrimenti l'indirizzo non è valido e il codice QR non compare.

**Menu Screen**

Il menu "Screen (P)" contiene i comandi sulle pagine: New Screen, Screen Properties (P) e Delete Screen (D)

<img src="../../../../getting-started/window/editview/menu.files/menu12542.png" width="192" />

Figura 2-33        Menu "Screen"

• New Screen: crea una nuova pagina nel progetto corrente.

• Screen Properties: apre le proprietà della pagina corrente, in cui impostare nome e sfondo.

• Delete Screen: elimina la pagina corrente.

<img src="../../../../getting-started/window/editview/menu.files/menu12848.png" width="130" />

Prima di procedere, verificare che la pagina corrente sia quella da eliminare e che non contenga oggetti necessari: l'operazione non può essere annullata.

**Menu Setting**

Il menu "Setting (S)" contiene i comandi: Preference Settings (P), File Protection (M), Macro Editor, Global Macro, Initialization Macro e Add Customize Keyboard.

<img src="../../../../getting-started/window/editview/menu.files/menu13188.png" width="217" />

Figura 2-34        Menu "Setting"

• Preference Setting: apre la finestra delle preferenze, in cui modificare modello di HMI, modalità di visualizzazione, pagina iniziale, tempo dello screen saver, frequenza di lampeggio, suono di allarme, suono al tocco, password e livello iniziale.

• File Protection: apre la finestra in cui impostare una password per proteggere il file del progetto corrente.

• Macro Editor: apre l'editor di macro, in cui aggiungere, modificare, compilare o eliminare una macro.

• Global Macro: apre la pagina di impostazione delle macro globali.

• Initialization Macro: apre la pagina di impostazione delle macro di inizializzazione.

• Add Customize keyboard: apre la creazione di una tastiera personalizzata.

<img src="../../../../getting-started/window/editview/menu.files/menu14111.png" width="130" />

Conservare la password: una volta impostata, è necessaria per aprire il file del progetto. La password distingue maiuscole e minuscole.

**Menu Download**

Il menu "Download", che serve a compilare e scaricare il progetto, contiene otto comandi: Compile (C), Off-line Simulation (M), Online simulation, USB download (D), Upload, Pack/Unpack, Extract project & save as e Extract Remote Simulation Engineering (A). Collegando il PC al touch screen con un cavo USB, il progetto può essere scaricato con USB download, ma deve essere compilato prima del download.

<img src="../../../../getting-started/window/editview/menu.files/menu14738.png" width="346" />

Figura 2-35        Menu "Download"

• Compile: verifica il progetto creato dall'utente e lo prepara al download.

• Off-line Simulation: avvia l'applicazione di simulazione di CommandHMI. L'utente può simulare sul PC il progetto corrente per verificarne l'aspetto e correggere le pagine. Salvare il progetto prima della simulazione offline.

• Online Simulation: avvia l'applicazione di simulazione di CommandHMI, in cui l'utente può simulare sul PC il progetto corrente per verificarne l'aspetto e correggere le pagine. Nella simulazione online il PC comunica con i dispositivi collegati tramite Ethernet o seriale, per verificare lo scambio dati e lo stato della comunicazione. Salvare il progetto prima della simulazione online.

• USB Download: scarica nell'HMI il progetto compilato con CommandHMI tramite il cavo USB fornito con il touch screen. Prima del download, compilare e salvare il progetto.

• Upload: carica dall'HMI al PC dati storici, configurazione, ricette e storico allarmi tramite il cavo USB fornito con il prodotto.

• Pack/ Unpack: comprime il progetto in un file XXX.vpr, oppure estrae il file compresso nel file di progetto .vpm.

• Extract Project & Save As: compila il progetto corrente in un file binario u-disk-prj.bin. Salvato su chiavetta USB, permette di aggiornare automaticamente l'HMI senza cavo USB.

**Menu contestuale (tasto destro)**

Il menu contestuale facilita le operazioni e rispetta le abitudini della maggior parte degli utenti Windows. Raccoglie molte funzioni di configurazione: Attribute, Objects, Library, Cut, Copy, Multiple copy, Paste, Delete, Select all, Align, Layer, Group, Zoom, Grid, Screen.

<img src="../../../../getting-started/window/editview/menu.files/menu17926.png" width="176" />

Figura 2-40        Menu contestuale

• Attribute: apre la finestra delle proprietà dell'oggetto selezionato (un solo oggetto) o della pagina (nessun oggetto selezionato).

• Object: dà accesso a tutti gli oggetti del menu Object.

• Library: apre la galleria o genera immagini di libreria.

• Cut: tasto di scelta rapida Ctrl + X; elimina gli oggetti grafici selezionati copiandoli negli appunti.

• Copy: tasto di scelta rapida Ctrl + C; copia negli appunti l'oggetto grafico selezionato.

• Multiple copy: copia più volte gli oggetti selezionati in orizzontale e in verticale, con indirizzi crescenti da 0 a 255 unità.

• Paste: tasto di scelta rapida Ctrl + V; incolla nella pagina corrente gli oggetti grafici presenti negli appunti.

• Delete: tasto Canc; elimina dalla pagina l'oggetto grafico selezionato.

• Select: tasto di scelta rapida Ctrl + A; seleziona tutti gli oggetti della pagina corrente.

• Align: allinea gli oggetti selezionati (almeno due) secondo il tipo scelto: Top, Bottom, Vertical Center, Left, Right, Horizontal Equal Interval, Vertical Equal Interval, Make same width, Make same height, Make same width and height.

• Layer: sposta gli oggetti selezionati a un altro livello: Bring To Top, Bring Forward, Send to Bottom o Send Backward.

• Group: combina gli oggetti selezionati (almeno due) in un unico oggetto, oppure scompone un oggetto raggruppato negli oggetti originali.

• Zoom: ingrandisce o riduce la pagina corrente per lavorare con maggiore precisione: Zoom In, Zoom Fit e Zoom Out.

• Grid: mostra o nasconde nella pagina corrente una griglia di passo definito.

• Screen: crea una nuova pagina, apre le proprietà della pagina o la elimina.
