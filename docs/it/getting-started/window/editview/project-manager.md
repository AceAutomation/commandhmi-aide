# Gestione progetto

La finestra Gestione progetto di CommandHMI si trova a sinistra della finestra del software, sotto la barra degli strumenti. Qui si impostano i parametri del touch screen: impostazioni multilingua, collegamenti, impostazioni, pagine, finestre, raccolta dati storici, allarmi, ricette, trasmissione dati e macro. I collegamenti comprendono Connection 1 e Connection 2; le impostazioni comprendono parametri HMI, stato HMI, controllo da PLC, orologio, crittografia dei file, protezione HMI e tabella delle variabili.
