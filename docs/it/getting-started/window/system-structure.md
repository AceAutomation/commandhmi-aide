# Composizione del sistema

CommandHMI è il software di configurazione degli HMI CommandHMI. Permette di creare la configurazione sul PC e di scaricare poi la configurazione finale e i driver di comunicazione necessari nella memoria del touch screen tramite un cavo USB. Una volta collegati a PLC o ad altri dispositivi tramite le porte di comunicazione seriali, gli HMI permettono di controllare e monitorare l'impianto.
