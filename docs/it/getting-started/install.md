# Installazione del software

CommandHMI è un software applicativo per Microsoft Windows. Prima di installarlo, verificare che il computer soddisfi i requisiti minimi hardware e software.

Per installare CommandHMI, eseguire il programma di installazione fornito con il prodotto, come segue:

Scaricare il programma di installazione dal sito ufficiale;

![2018_11_19_19_32_06.jpg](../../getting-started/install.files/setup.png)

Figura 2-1      Pacchetto di installazione di CommandHMI

Facendo doppio clic sul file si apre automaticamente la finestra di installazione di CommandHMI.

La prima finestra è quella del contratto di licenza ("License Agreement"): selezionare "Next" per proseguire con l'installazione oppure "Cancel" per uscire, come mostrato nella Figura 2-2.

Selezionare l'accettazione del contratto, quindi fare clic su Next.

<img src="../../getting-started/../image/2025-10-11/setup-1.png" width="513" alt="ScreenShot00201.jpg" />

Figura 2-2      Finestra del contratto di licenza

Nella finestra delle cartelle di destinazione, selezionare la cartella di installazione. La cartella predefinita è "C:\Program Files (x86)\CommandHMI"; con Browse... si può scegliere un altro percorso, quindi fare clic su Next

  <img src="../../getting-started/../image/2025-10-11/setup-3.png" width="513" alt="ScreenShot00202.jpg" />

Figura 2-5      Scelta del percorso di installazione

Facendo clic su Next nella Figura 2-5 compare la scelta della posizione dei file (predefinita o altra); fare clic su Next, come mostrato nella Figura 2-6:

<img src="../../getting-started/../image/2025-10-11/setup-3.1.png" width="513" alt="ScreenShot00203.jpg" />

Figura 2-6      Scelta dei file di installazione

Nella finestra di creazione del collegamento sul desktop, fare clic su Next, come mostrato nella Figura 2-7:

<img src="../../getting-started/../image/2025-10-11/setup-4.png" width="513" alt="ScreenShot00204.jpg" />

Figura 2-7      Creazione del collegamento sul desktop

La finestra di conferma riepiloga tre elementi: percorso di installazione, file da installare ed eventuale creazione del collegamento.

  <img src="../../getting-started/../image/2025-10-11/setup-5.png" width="513" alt="ScreenShot00205.jpg" />

Figura 2-8      Conferma dell'installazione

Finestra di installazione: fare clic su Cancel per annullare l'installazione, come mostrato nella Figura 2-9:

<img src="../../getting-started/../image/2025-10-11/setup-6.png" width="513" alt="ScreenShot00206.jpg" />

Figura 2-9      Installazione in corso

Al termine dell'installazione compare la finestra di completamento; fare clic su Finish per chiudere la procedura guidata, come mostrato nella Figura 2-10:

<img src="../../getting-started/../image/2025-10-11/setup-8.png" width="513" alt="ScreenShot00207.jpg" />

Figura 2-10    Installazione completata
