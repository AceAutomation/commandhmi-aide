# Guida rapida di CommandHMI

Illustra inoltre in dettaglio la composizione del sistema software e le funzioni di ciascun componente, per aiutare l'utente a comprendere la struttura complessiva del software. Presenta infine i requisiti hardware e software di CommandHMI, la procedura di installazione e l'ambiente di lavoro, per aiutare l'utente a imparare a usare il software e a creare i propri progetti.
