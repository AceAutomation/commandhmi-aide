# Pin

Piedinatura della porta di comunicazione a 9 pin, come nella figura seguente:

<img src="../../../hardware/structure/hmi_db9_port.files/image002.jpg" width="473" alt="pin.jpg" />

Porta di comunicazione a 9 pin

Questa porta serve a collegare PLC o altri controllori con porta di comunicazione RS232 / RS422 / RS485

|     |       |       |       |
|-----|-------|-------|-------|
| Pin | RS232 | RS422 | RS485 |
| 1   |       |       |       |
| 2   | RX    |       |       |
| 3   | TX    |       |       |
| 4   |       |       |       |
| 5   | GND   |       |       |
| 6   |       | RX-   |       |
| 7   |       | RX+   |       |
| 8   |       | TX-   | B     |
| 9   |       | TX+   | A     |
