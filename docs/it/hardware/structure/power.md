# Interfaccia di alimentazione

L'interfaccia di alimentazione degli HMI CommandHMI serie HM si trova sul pannello posteriore. L'alimentazione a 24 VDC (±15%) è protetta efficacemente contro i disturbi, migliorando l'immunità dell'intero sistema.
