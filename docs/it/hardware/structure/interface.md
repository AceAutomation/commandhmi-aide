# Porta di comunicazione

Le porte di comunicazione dell'HMI si trovano sul pannello inferiore.

Con un cavo schermato, la distanza di comunicazione RS232 non deve superare i 15 metri. Per il collegamento al computer è disponibile un'interfaccia USB, usata per scaricare la configurazione (trasmissione dati), con una velocità fino a 10 Mbps. La definizione dell'interfaccia di comunicazione dipende dal PLC collegato (all'ordine, indicare il tipo di PLC per facilitare la fornitura dei cavi di comunicazione).
