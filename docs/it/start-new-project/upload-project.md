# Upload del progetto

Il software CommandHMI consente di caricare il progetto dall'HMI al disco del PC. Collegare l'HMI al PC, selezionare l'opzione "Carica file di progetto" nella finestra che compare: si apre l'interfaccia "Carica file Samdraw".

![](../../start-new-project/upload-project.files/001.png)

• Percorso file: fare clic su "Sfoglia" per scegliere dove salvare il file.

• Nome progetto: imposta il nome del progetto.

• Avvia caricamento: fare clic su Carica file per iniziare.

Al termine del caricamento si può scegliere se aprire il file di progetto.

<img src="../../start-new-project/upload-project.files/upload-project507.png" width="130" />

Il file caricato deve essere estratto prima di poterlo aprire.
