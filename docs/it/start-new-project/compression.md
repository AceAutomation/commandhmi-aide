# Comprimi/Decomprimi

Selezionare "<span id="OLE_LINK272"></span><span id="OLE_LINK273"></span>Comprimi/Decomprimi" (Pack/Unpack) nel menu Download per aprire la finestra.

<img src="../../start-new-project/compression.files/image002.jpg" width="668" />

• Comprimi il file: comprime il file di progetto HM generando un file compresso con estensione .sip. Anche le immagini esterne usate vengono incluse nel file compresso, quindi inviandolo a un altro computer le immagini sono presenti dopo la decompressione. Se invece si invia solo il file di progetto, sull'altro computer le immagini esterne vanno perse perché non si trova il loro percorso originale.

• Percorso di salvataggio: <span id="OLE_LINK276"></span><span id="OLE_LINK277"></span>posizione in cui salvare il file compresso; scelto il percorso, fare clic su "Comprimi" e chiudere quando la barra di avanzamento raggiunge il 100%.

• Decomprimi il file: decomprime un file con estensione .vpr in un file .vpm apribile direttamente in CommandHMI.

• File compresso: scegliere il file da estrarre.

• Percorso di salvataggio: posizione in cui salvare il file decompresso .vpm; scelto il percorso, fare clic su "Decomprimi" e chiudere quando la barra di avanzamento raggiunge il 100%.
