# Upload dei dati storici registrati

Avviare il software di configurazione CommandHMI e fare clic su <img src="../../start-new-project/converter.files/converter46.png" width="29" />.

![](../../start-new-project/converter.files/001.png)

"Carica registro dati storici" significa trasferire i dati storici dall'HMI al disco del PC.

• Percorso file: posizione di salvataggio; scegliere "Sfoglia" per selezionarla.

• Nome file: nome del file caricato; il file non si può aprire direttamente ed è necessario uno strumento di conversione dei dati. Per la procedura vedere "Esportare dati storici e allarmi su chiavetta USB" nell'appendice della guida.

• Fare clic su "Carica file" per avviare il caricamento; il file viene salvato nella posizione impostata.

• CommandHMI supporta ora più gruppi di dati storici: il caricamento salva il file del database storico e, inoltre, ogni gruppo di dati storici come file .CSV. Per esempio, caricando un file chiamato "temp", il database storico si chiama "temp", il CSV del gruppo 0 "temp_hisdata0.csv", quello del gruppo 1 "temp_hisdata1.csv", e così via.

<img src="../../start-new-project/converter.files/converter954.png" width="130" />

Il caricamento del registro dati storici è analogo a quello delle ricette e del file di progetto; la conversione dei file da Samdraw3.3 a CommandHMI è disattivata.
