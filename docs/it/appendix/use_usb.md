# Aggiornare le ricette tramite chiavetta USB

Gli HMI della serie HM supportano l'importazione e l'aggiornamento delle ricette tramite chiavetta USB.

**Come aggiornare il file delle ricette tramite chiavetta USB**

**1. Compilare il progetto**

Avviare CommandHMI, aprire il progetto da aggiornare e fare clic su <img src="../../appendix/use_usb.files/image002.jpg" width="71" /> per generare il file compilato.

**2. Copiare il file compilato sulla chiavetta USB**

Aprire la cartella e copiare u-disk-prj.bin sulla chiavetta USB.

**3. Rinominare recipe.bin**

Rinominare recipe.bin in u-disk-recipe.bin

**4. Inserire la chiavetta USB nell'HMI**

**5. Copiare il file e aggiornare il progetto**

Dopo aver inserito la chiavetta USB nell'HMI, fare clic su YES nella finestra che compare per eseguire l'aggiornamento.

**6. Riavviare l'HMI per completare l'aggiornamento**

Spegnere e riaccendere l'alimentazione oppure riavviare l'HMI con il pulsante "Restart" sullo schermo.

<img src="../../appendix/use_usb.files/image004.gif" width="595" />

Nota

• Non scollegare la chiavetta USB durante l'aggiornamento;

• Mantenere l'HMI acceso durante l'aggiornamento.
