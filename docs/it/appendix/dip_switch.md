# Selettore DIP

Ogni HMI della serie HM dispone di un selettore DIP, i cui interruttori hanno ciascuno una funzione specifica.

<img src="../../appendix/dip_switch.files/image004.gif" width="212" />

**Elenco delle funzioni del selettore DIP**

|                   |                             |
|-------------------|-----------------------------|
| Selettore DIP (5-1) | Funzione |
| Tutti su OFF | Modalità di funzionamento normale |
| ON 1 | Modalità di calibrazione delle coordinate |
| ON 2 | Modalità di visualizzazione dei parametri |
| ON 1 e ON 2 | Modalità terminale |
| ON 1 e ON 3 | Modalità di impostazione dei parametri |

<img src="../../appendix/dip_switch.files/image005.gif" width="595" />

Nota:

Dopo aver modificato il selettore DIP è necessario riavviare l'HMI;

Durante il normale utilizzo dell'HMI, usare la modalità di funzionamento normale;

La modalità di impostazione dei parametri serve a impostare data/ora, luminosità e indirizzo IP.
