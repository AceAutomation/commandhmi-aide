# Script

Lo script è un metodo di controllo avanzato del touch screen che ne amplia notevolmente le funzionalità. Programmando i comandi di script, il touch screen acquisisce le stesse capacità di elaborazione logica e aritmetica di un PLC. Un uso flessibile delle macro permette di realizzare numerose funzioni avanzate non disponibili con gli oggetti standard e di perfezionare ulteriormente l'interfaccia uomo-macchina.

CommandHMI offre un sistema di script completo, diverso dai linguaggi di script di altre interfacce uomo-macchina: questi script sono compatibili con il linguaggio C standard (ANSI C89). Poiché esiste un'ampia letteratura sul linguaggio C, facilmente reperibile, questo capitolo non tratta in dettaglio la sintassi e le nozioni di base, ma si concentra sulla creazione e sull'utilizzo delle macro attraverso esempi.

Questo capitolo illustra brevemente le basi del linguaggio C, l'uso delle istruzioni di script e le relative avvertenze.
