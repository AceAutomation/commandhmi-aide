# Manual de hardware

Este capítulo resume el hardware de los HMI de la serie HM y presenta sus dimensiones, para los modelos de las series HM-XXXAE/AS, HM-BE/BS, HM-XXXCS/CG/CW, HM-XXXGE/GS/GG/GW, HM-XXXHE/HS, HM-XXXNE/MS/MG/MW, HM-XXXQE/QS y HM-XXXUE; el usuario puede montarlos según estas dimensiones. Para el principio y la composición del HMI, las características técnicas del entorno de funcionamiento y el cableado correcto, véanse los parámetros específicos.
