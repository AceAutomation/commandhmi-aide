# Actualizar recetas mediante memoria USB

Los HMI de la serie HM permiten importar y actualizar recetas mediante una memoria USB.

**Cómo actualizar el archivo de recetas mediante memoria USB**

**1. Compilar el proyecto**

Inicie CommandHMI, abra el proyecto a actualizar y haga clic en <img src="../../appendix/use_usb.files/image002.jpg" width="71" /> para generar el archivo compilado.

**2. Copiar el archivo compilado en la memoria USB**

Abra el directorio y copie u-disk-prj.bin en la memoria USB.

**3. Renombrar recipe.bin**

Cambie el nombre de recipe.bin a u-disk-recipe.bin

**4. Insertar la memoria USB en el HMI**

**5. Copiar el archivo y actualizar el proyecto**

Tras insertar la memoria USB en el HMI, haga clic en YES en la ventana emergente para actualizar.

**6. Reiniciar el HMI para terminar la actualización**

Apague y encienda el equipo o reinicie el HMI con el botón «Reiniciar» de la pantalla.

<img src="../../appendix/use_usb.files/image004.gif" width="595" />

Nota

• No retire la memoria USB durante la actualización;

• Mantenga el HMI encendido durante la actualización.
