# Formato de imagen

Los HMI de la serie HM admiten varios formatos de imagen: JPG, BMP, GIF, PNG, etc. Para garantizar la rapidez de visualización, las imágenes se comprimen por defecto y se convierten a JPG (salvo en el objeto de visualización GIF).

  Para conservar el formato original, abra Parámetros del HMI -&gt; ajustes de impresora y descarga, y ajuste la opción de imagen a «Conservar el formato original».

Nota:

 • La conversión a JPG permite usar más imágenes;

 • Usar imágenes cuya resolución no supere la de la pantalla táctil mejora la rapidez de visualización;

 • Una imagen GIF tiene como máximo 32 fotogramas.
