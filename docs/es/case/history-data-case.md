# Ejemplo de recopilador de datos históricos

El ejemplo siguiente muestra el uso combinado del recopilador de datos históricos, la visualización de datos históricos y el gráfico de tendencia histórica.

**1. Crear un recopilador de datos históricos**

Haga clic con el botón derecho en «Recopilador de datos históricos» en el gestor de proyecto para crear uno, como en la figura 1

<img src="../../case/history-data-case.files/image002.jpg" width="362" />

Figura 1 Crear un recopilador de datos históricos

**2. Ajustes del recopilador de datos históricos**

Haga doble clic para abrir el recopilador de datos históricos, como en la figura 2

Figura 2 Ajustes generales del recopilador de datos históricos

Añadimos cinco elementos de datos llamados «Data1», «Data2», «Data3», «Data4» y «Data5», con las direcciones «LW0», «LW1», «LW3», «LW5» y «LW6»; defina el tipo de dato y el nombre de cada uno, como en la figura 3. Como Data2 y Data3 son de 32 bits, en cada muestreo se leen los registros «LW0», «LW1 + LW2», «LW3 + LW4», «LW5» y «LW6». El número total de muestras es 1000: se toman 1000 muestras en total, hasta llenar la memoria.

 <img src="../../case/history-data-case.files/image004.jpg" width="627" />

Figura 3 Elementos de datos del recopilador de datos históricos

Haga clic en «Aceptar»; para ver los datos históricos, use después la «Visualización de datos históricos».
