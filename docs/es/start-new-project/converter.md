# Cargar datos históricos

Inicie el software de configuración CommandHMI y haga clic en <img src="../../start-new-project/converter.files/converter46.png" width="29" />.

![](../../start-new-project/converter.files/001.png)

«Cargar datos históricos» transfiere los datos del HMI al disco duro.

• Ruta del archivo: ubicación de guardado; elíjala con «Examinar».

• Nombre del archivo: nombre del archivo cargado; no puede abrirse directamente, hace falta una herramienta de conversión. Véase «Exportar datos históricos y alarmas a una memoria USB» en el anexo de la ayuda.

• Haga clic en «Cargar archivo»; el archivo se guarda en la ubicación indicada.

• CommandHMI admite ahora varios grupos de datos históricos: al cargarlos, además del archivo de base de datos, cada grupo se guarda como archivo .CSV. Por ejemplo, al cargar un archivo «temp», la base de datos se llama «temp», el CSV del grupo 0 «temp_hisdata0.csv», el del grupo 1 «temp_hisdata1.csv», etc.

<img src="../../start-new-project/converter.files/converter954.png" width="130" />

La carga de datos históricos funciona como la de recetas y archivos de proyecto; la conversión de archivos de Samdraw3.3 a CommandHMI está desactivada.
