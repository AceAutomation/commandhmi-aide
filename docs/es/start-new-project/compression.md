# Comprimir/descomprimir

Elija «<span id="OLE_LINK272"></span><span id="OLE_LINK273"></span>Comprimir/descomprimir» en el menú «Download» para abrir el cuadro de diálogo.

<img src="../../start-new-project/compression.files/image002.jpg" width="668" />

• Comprimir archivo: comprime el archivo de proyecto HM en un archivo con extensión .sip. Las imágenes externas usadas se incluyen en el archivo comprimido. Si se envía el archivo comprimido a otro ordenador, las imágenes están presentes tras descomprimirlo. En cambio, si solo se envía el archivo de proyecto, las imágenes externas se pierden en el otro ordenador porque no se encuentra su ruta original.

• Ruta de guardado: <span id="OLE_LINK276"></span><span id="OLE_LINK277"></span>ubicación del archivo comprimido; elija la ruta, haga clic en «Comprimir» y cierre la ventana cuando la barra de progreso llegue al 100 %.

• Descomprimir archivo: descomprime un archivo .vpr en un archivo .vpm que puede abrirse directamente en CommandHMI.

• Archivo comprimido: elección del archivo a descomprimir.

• Ruta de guardado: ubicación del archivo .vpm descomprimido; elija la ruta, haga clic en «Descomprimir» y cierre la ventana cuando la barra de progreso llegue al 100 %.
