# Cargar el proyecto

CommandHMI permite cargar el proyecto del HMI al disco duro. Conecte el HMI al PC y elija «Cargar archivo de proyecto» en el cuadro de diálogo; se abre la interfaz «Cargar archivo Samdraw».

![](../../start-new-project/upload-project.files/001.png)

• Ruta del archivo: haga clic en «Examinar» para elegir la ruta de guardado.

• Nombre del proyecto: nombre del proyecto.

• Iniciar la carga: haga clic en «Cargar archivo».

Tras la carga, puede elegir abrir directamente el archivo de proyecto.

<img src="../../start-new-project/upload-project.files/upload-project507.png" width="130" />

El archivo cargado debe descomprimirse antes de abrirlo.
