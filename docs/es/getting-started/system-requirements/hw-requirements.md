# Requisitos de hardware

Requisitos mínimos de hardware de CommandHMI:

CPU: Pentium 3 a 800 MHz como mínimo;

Memoria: 128 MB o más con Windows 9X;

<span id="OLE_LINK68"></span><span id="OLE_LINK69"></span><span id="OLE_LINK60"></span><span id="OLE_LINK61"></span>256 MB o más con Windows NT;

256 MB o más con Windows 2000 o XP;

Gráficos: <span id="OLE_LINK71"></span><span id="OLE_LINK70"></span>tarjeta compatible con <span id="OLE_LINK62"></span><span id="OLE_LINK63"></span>Windows, con más de 1 MB de memoria de vídeo, resolución de 1024 \* 768 y modo de 256 colores;

Disco duro: el software de configuración CommandHMI ocupa al menos 200 MB.

Ordenador con puerto USB;

Ratón de dos botones y teclado.

<img src="../../../getting-started/system-requirements/hw-requirements.files/image002.jpg" width="130" />

Con una configuración inferior, CommandHMI puede no instalarse o no funcionar.

**Configuración recomendada:**

CPU: equivalente a Intel Pentium 800 o superior;

Memoria: 256 MB o más con Windows 9X;

512 MB o más con Windows NT;

512 MB o más con Windows 2000 o XP.

Tarjeta gráfica: compatible con Windows, con más de 1 MB de memoria de vídeo, resolución de 1024 \* 768 y modo de 65535 colores.

Disco duro: 200 MB o más.
