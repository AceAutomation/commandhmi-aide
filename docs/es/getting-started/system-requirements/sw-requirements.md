# Requisitos de software

El software de configuración CommandHMI funciona en estos sistemas operativos:

· Microsoft Windows NT Server 4.0 o posterior;

· Microsoft Windows NT Workstation 4.0 o posterior;

· Microsoft Windows 98, Me, 2000, XP, Windows 7 o posterior.

<img src="../../../getting-started/system-requirements/sw-requirements.files/image002.jpg" width="130" />

CommandHMI no se instala en otras versiones de sistema operativo.

<span id="OLE_LINK52"></span><span id="OLE_LINK53"></span>**Sistemas recomendados:**

Windows XP SP3; Windows 7 32 bits; Windows 7

No hay diferencia entre sistemas operativos en chino o en inglés.
