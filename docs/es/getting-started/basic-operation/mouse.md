# Uso del ratón y atajos de teclado

Al crear pantallas en el editor de configuración se usa el ratón, como en la figura 2-45:

<img src="../../../getting-started/basic-operation/mouse.files/image010.jpg" width="318" />

Figura 2-45        Esquema del ratón

Operaciones habituales con el ratón y su uso:

◎ Clic izquierdo

Pulsar y soltar el botón izquierdo<span id="OLE_LINK219"></span><span id="OLE_LINK218"></span>: en este manual se llama \[clic\]; sirve para elegir en los menús, seleccionar objetos, elegir botones de herramientas, editar pantallas y confirmar ajustes.

◎ Doble clic izquierdo

Pulsar dos veces seguidas el botón izquierdo: en este manual se llama \[doble clic\]; sirve para configurar los elementos existentes en la pantalla: propiedades de pantallas y ventanas, propiedades de conexión de la pantalla táctil, ajustes; y para cambiar los ajustes del recopilador de datos históricos, recetas, alarmas y otras opciones.

◎ Clic derecho

Pulsar y soltar el botón derecho: en este manual se llama \[clic derecho\]. Un clic derecho sobre un elemento abre su menú contextual; en un espacio vacío abre el menú contextual de la pantalla. También permite salir del modo de edición y restablecer el cursor.

◎ Arrastrar

Mover el ratón manteniendo pulsado el botón: en este manual se llama \[arrastrar\]; sirve para seleccionar varios elementos, desplazar elementos y mover ventanas de edición emergentes.

### <span id="OLE_LINK225"></span><span id="OLE_LINK224"></span>Atajos de teclado

La tabla 2-2 enumera los atajos de teclado habituales, que permiten configurar más rápido.

|                   |                                                     |
|-------------------|-----------------------------------------------------|
| CTRL+C            | Copy                                                |
| CTRL+V            | Pegar                                               |
| CTRL+X            | Cut                                                 |
| CTRL+F            | Cambio de pantalla                                        |
| Ctrl + arrastrar       | Copiar el objeto seleccionado y moverlo                 |
| Ctrl + clic izquierdo | Seleccionar varios objetos                             |
| ← → ↑ ↓           | Mover el objeto seleccionado a izquierda/derecha/arriba/abajo |
| ESC               | Deshacer la operación                                  |
|                   | Eliminar                                              |
