# Términos habituales

La tabla 2-3 muestra algunos términos habituales de la edición de configuración.

|                   |                                                                                                                                                                                                                                                                                                                                 |
|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Proyecto           | Abreviatura de la aplicación del usuario. El concepto de proyecto hace más accesible a los ingenieros un conocimiento informático complejo. Los archivos creados en CommandHMI tienen la extensión .vpm y pueden guardarse en cualquier ubicación.                                                            |
| Objeto            | Los elementos manipulados y su entorno se denominan en conjunto objeto: ventanas, componentes, datos, gráficos y objetos                                                                                                                                                                                                    |
| Seleccionar el objeto | Hacer operable una ventana u objeto con un clic se llama seleccionar el objeto; el objeto seleccionado (incluidas las ventanas) se llama objeto actual                                                                                                                                                                   |
| Configuración     | Definir, crear y editar objetos en un entorno de ventanas y ajustar sus características de estado (atributos)                                                                                                                                                                                                                         |
| Atributo         | Nombre, tipo, estado, propiedades y uso se denominan en conjunto atributo                                                                                                                                                                                                                                                     |
| Menu              | Conjunto de órdenes. Por ejemplo, el menú del sistema «Archivo» agrupa las órdenes relativas a los archivos de proyecto. Todos los menús de CommandHMI son desplegables y pueden tener varios niveles; cada nivel se llama submenú |
| Botón de orden    | Botones para determinadas órdenes, unos en la barra de herramientas y otros en la barra de menús                                                                                                                                                                                                                             |
| Activar (ON)            | Pone en el estado «ON» un objeto con visualización de estado de bit                                                                                                                                                                                                                                                                          |
| Desactivar (OFF)           | Pone en el estado «OFF» un objeto con visualización de estado de bit                                                                                                                                                                                                                                                                         |
| Estilo             | Efecto de transición de un objeto del color de primer plano al de fondo                                                                                                                                                                                                                                                       |
| Dirección           | Variables de memoria del objeto actual                                                                                                                                                                                                                                                                                  |
| Equipo conectado | Equipos de comunicación conectados en el proyecto actual                                                                                                                                                                                                                                                                              |
| Objeto           | Conjunto de funciones concretas                                                                                                                                                                                                                                         |
