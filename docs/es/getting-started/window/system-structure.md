# Composición del sistema

CommandHMI es el software de configuración de los HMI CommandHMI. Permite editar la configuración en el PC y descargar después el proyecto final y el controlador de comunicación necesario a la memoria de la pantalla táctil mediante un cable USB; los HMI conectados a PLC u otros equipos por puerto serie permiten entonces el mando y la supervisión.
