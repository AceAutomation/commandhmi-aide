# Barra de menús

La barra de menús del software CommandHMI ofrece muchas opciones, que cubren prácticamente todas las herramientas y comandos de edición necesarios: menús Archivo, Edición, Ver, Dibujo, Objeto, Pantalla, Ajustes, Descarga, Ayuda, Idioma, además del menú contextual (clic derecho).

 <img src="../../../../getting-started/window/editview/menu.files/menu355.png" width="742" />

Figura 2-28        Barra de menús

**Menú «Archivo»**

El menú «Archivo» incluye Nuevo proyecto (N), Abrir proyecto (O), Cerrar, Guardar (S), Guardar como y Salir (Q). Un elemento en gris indica que la operación no está disponible en el contexto actual. Para abrir el menú, haga clic en «Archivo (F)» arriba a la izquierda del software; se despliega el menú.

<img src="../../../../getting-started/window/editview/menu.files/menu742.png" width="278" />

Figura 2-29 Menú «Archivo»

• Nuevo proyecto: atajo Ctrl + N; crea un proyecto en blanco.

• Abrir proyecto: atajo Ctrl + O; abre un archivo de proyecto .vpm ya guardado.

• Cerrar: cierra el proyecto actual sin salir del software CommandHMI.

• Guardar: atajo Ctrl + S; guarda el archivo de configuración modificado con su nombre y ruta actuales.

• Guardar como: guarda el archivo de configuración actual con otro nombre o en otra ruta.

• Salir: cierra el software CommandHMI.

**Menú «Edición»**

El menú «Edición» agrupa los comandos de edición de textos, gráficos y otros contenidos de la pantalla: Deshacer, Rehacer, Cortar (T), Copiar (C), Copia múltiple (D), Pegar (P), Eliminar (D), Seleccionar todo (A), Alinear, Capas, Agrupar, Espejo, Zoom, Cuadrícula, Propiedades, Buscar dirección, Tabla de direcciones, Invertir selección, Buscar script y Gestor de scripts. Un comando en gris no está disponible en la operación actual. Para ejecutarlos, seleccione primero el objeto gráfico y elija después el comando en el menú «Edición». Algunos comandos agrupan subcomandos: se indican con un pequeño triángulo a la derecha y abren un submenú; cada comando tiene su atajo.

• Deshacer: atajo Ctrl + Z; anula la última operación.

• Rehacer: atajo Ctrl + Y; restablece la última operación anulada.

• Cortar: atajo Ctrl + X; elimina los objetos gráficos seleccionados y los copia al portapapeles.

• Copiar: atajo Ctrl + C; copia el objeto gráfico seleccionado al portapapeles.

• Copia múltiple: copia varias veces los objetos seleccionados en horizontal y vertical, con direcciones incrementadas de 0 a 255 unidades.

• Pegar: atajo Ctrl + V; pega en la pantalla actual los objetos del portapapeles.

• Eliminar: Supr; elimina de la pantalla el objeto gráfico seleccionado.

<img src="../../../../getting-started/window/editview/menu.files/menu2833.png" width="193" />

Figura 2-30 Menú «Edición»

• Seleccionar todo: atajo Ctrl + A; selecciona todos los objetos de la pantalla actual.

• Alinear: alinea los objetos seleccionados (al menos dos) según el tipo elegido: arriba, abajo, centro vertical, izquierda, derecha, espaciado horizontal igual, espaciado vertical igual, igualar anchura, igualar altura, igualar anchura y altura.

• Capas: cambia el nivel de los objetos seleccionados: traer al frente, traer adelante, enviar al fondo o enviar atrás.

• Agrupar: combina los objetos seleccionados (al menos dos) en un solo objeto, o descompone un objeto agrupado en sus objetos originales. Al agrupar, no incluya objetos táctiles: tras la descarga a la pantalla táctil dejarían de responder. Para superponer objetos táctiles, use las capas.

<img src="../../../../getting-started/window/editview/menu.files/menu3850.png" width="130" />

Al agrupar, no incluya objetos táctiles: tras la descarga a la pantalla táctil dejarían de responder. Para superponer objetos táctiles, use el comando «Capas».

• Espejo: gira el objeto seleccionado según ciertas reglas, en horizontal o en vertical.

• Zoom: amplía o reduce la pantalla actual para un trabajo más preciso: ampliar, ajustar o reducir.

• Cuadrícula: muestra u oculta una cuadrícula de anchura definida en la pantalla actual.

• Propiedades: abre las propiedades de un objeto (si hay uno seleccionado) o de la pantalla (si no hay nada seleccionado).

• Buscar dirección: busca la dirección indicada.

• Tabla de direcciones: abre o cierra la lista de direcciones usadas por los objetos, para buscarlas y sustituirlas fácilmente.

• Invertir selección: selecciona todos los objetos no seleccionados de la pantalla actual y deselecciona los que lo estaban.

• Buscar script: localiza las llamadas a un script en el proyecto; puede elegirse el script o escribir su nombre.

• Gestor de scripts: muestra dónde se usan todos los scripts; puede mostrar los de todas las pantallas o los de una pantalla concreta.

**Menú «Ver»**

Este menú permite adaptar la interfaz a sus costumbres, decidiendo qué ventanas se muestran en el entorno de trabajo. La marca √ a la izquierda de un comando indica que esa ventana o barra se muestra; si no, está oculta.

<img src="../../../../getting-started/window/editview/menu.files/menu5440.png" width="385" />

**Menú «Dibujo»**

Este menú sirve para dibujar gráficos en la pantalla. CommandHMI ofrece línea (L), polilínea (B), curva / arco (A), línea libre, rectángulo (R), rectángulo redondeado, elipse (E), polígono (Y), sector, texto (T), abrir biblioteca (0), crear biblioteca (C), tabla y escala. El color, el texto, el tamaño y la posición de los elementos dibujados pueden modificarse fácilmente.

<img src="../../../../getting-started/window/editview/menu.files/menu5835.png" width="153" />

Figura 2-31        Menú «Dibujo»

• Línea: dibuja una línea recta en cualquier dirección en la pantalla actual.

• Polilínea: dibuja una polilínea en cualquier dirección en la pantalla actual.

• Curva / arco: dibuja una línea en la pantalla actual; tras terminar con el botón derecho, se puede ajustar su curvatura.

• Línea libre: dibuja una línea en cualquier dirección siguiendo el movimiento del ratón.

• Rectángulo: dibuja un rectángulo de cualquier tamaño en la pantalla actual.

• Rectángulo redondeado: dibuja un rectángulo de esquinas redondeadas en la pantalla actual.

• Elipse: dibuja una elipse de cualquier tamaño en la pantalla actual.

• Polígono: dibuja un polígono cualquiera en la pantalla actual.

• Sector: dibuja un sector cualquiera en la pantalla actual.

• Texto: crea un rectángulo transparente en el que se puede escribir cualquier texto.

• Abrir biblioteca: abre la biblioteca de imágenes del sistema.

• Crear biblioteca: convierte el gráfico dibujado por el usuario en un archivo de biblioteca para reutilizarlo.

• Tabla: crea una tabla con las filas y columnas necesarias en la pantalla actual.

• Escala: dibuja la escala deseada.

**Menú «Objeto»**

El menú «Objeto» agrupa las teclas táctiles y de función: botón de bit, botón de palabra, botón de pantalla, botón de función, botón multifunción, botón de pasos, botón de opción, lista desplegable, deslizador, visualización numérica, entrada numérica, visualización ASCII, entrada ASCII, lámpara de bit, botón multiestado, lámpara multiestado, visualización de mensajes, visualización de hora, de fecha y del día de la semana, imagen estática, visualización de imagen, visualización GIF, gráficos dinámicos, círculo dinámico, rectángulo dinámico, bloque de flujo, movimiento de gráfico, animación, gráfico de barras, indicador de aguja, gráfico de arco, gráfico de tendencia, gráfico de tendencia XY, tendencia histórica, grupo de datos, datos históricos, visualización de alarmas, barra de alarmas, alarmas históricas, temporizador, pizarra, selector de recetas, visualización de recetas, teclado y código QR. El menú «Objeto» corresponde a la tercera fila de la barra de herramientas.

• Botón de bit: crea teclas táctiles que actúan sobre bits del equipo conectado: activar, desactivar, pulsador momentáneo e invertir.

• Botón de palabra: crea en la pantalla actual teclas táctiles que actúan sobre palabras del equipo conectado: sumar, restar, incrementar, decrementar, constante, introducir valor, introducir contraseña.

• Más botones: acceso al botón de pantalla, botón de función, botón multifunción, botón de pasos, botón de opción, lista desplegable y deslizador.

• Visualización numérica: dibuja en la pantalla actual un campo que muestra el valor numérico de una dirección monitorizada.

• Entrada numérica: dibuja en la pantalla actual un campo para introducir datos y mostrar el valor de una dirección monitorizada.

• Visualización ASCII: dibuja en la pantalla actual un campo que muestra texto ASCII.

• Entrada ASCII: dibuja en la pantalla actual un campo para introducir y mostrar texto ASCII.

• Lámpara de bit: crea en la pantalla actual una imagen que muestra el estado de un bit del equipo conectado.

• Botón multiestado: crea un botón multiestado que muestra, según su estado, los cambios de valor de una dirección del equipo conectado.

• Lámpara multiestado: coloca en la pantalla actual una imagen que muestra el estado de palabra de una dirección del equipo.

<img src="../../../../getting-started/window/editview/menu.files/menu9590.png" width="174" />

Figura 2-32        Menú «Objeto»

• Visualización de mensajes: crea en la pantalla actual un objeto que muestra mensajes predefinidos.

• Visualización de hora: inserta en la pantalla un objeto que muestra la hora.

• Visualización de fecha: inserta en la pantalla un objeto que muestra la fecha.

• Visualización del día de la semana: inserta en la pantalla actual un objeto que muestra el día de la semana.

• Imagen estática: inserta en la pantalla actual una imagen del disco duro local.

• Visualización de imagen: dibuja en la pantalla actual un campo para mostrar varias imágenes.

• Visualización GIF: dibuja en la pantalla actual un campo para mostrar una imagen .GIF estática o animada.

• Gráficos dinámicos: abre el círculo dinámico, el rectángulo dinámico, el bloque de flujo, el movimiento de gráfico y la animación.

• Gráfico de barras: inserta en la pantalla actual un objeto de barras que muestra los cambios del valor de una dirección monitorizada mediante la subida y bajada o el avance horizontal de la barra.

• Indicador de aguja: crea en la pantalla actual un instrumento que muestra los cambios de valor de una dirección del equipo conectado.

• Gráfico de arco: inserta en la pantalla actual un sector que refleja el valor de una dirección monitorizada; la zona de respuesta se representa con el color de primer plano y de fondo del sector o con la trama.

• Gráfico: abre el gráfico de tendencia, el gráfico de tendencia XY, la tendencia histórica y el grupo de datos.

• Datos históricos: crea en la pantalla actual un objeto que muestra los datos guardados por el recopilador de datos históricos.

• Alarma: abre la visualización de alarmas, la barra de alarmas y las alarmas históricas.

• Temporizador: inserta en la pantalla actual un objeto que dispara una función según condiciones de tiempo.

• Pizarra: inserta en la pantalla actual un objeto sobre el que el usuario puede escribir.

• Selector de recetas: inserta en la pantalla actual un objeto que muestra los nombres de todas las recetas existentes.

• Visualización de recetas: inserta en la pantalla actual un objeto que muestra todos los datos de las recetas creadas.

• Teclado: inserta en la pantalla actual un objeto teclado; cada tecla puede ser cualquiera al personalizar el teclado.

• Código QR: inserta en la pantalla un objeto de código QR definido por el usuario; debe usarse junto con un objeto de entrada; si no, la dirección no es válida y el código QR no aparece.

**Menú «Pantalla»**

El menú «Pantalla (P)» agrupa los comandos sobre pantallas: Nueva pantalla, Propiedades de la pantalla (P) y Eliminar pantalla (D)

<img src="../../../../getting-started/window/editview/menu.files/menu12542.png" width="192" />

Figura 2-33        Menú «Pantalla»

• Nueva pantalla: crea una pantalla en el proyecto actual.

• Propiedades de la pantalla: abre las propiedades de la pantalla actual para definir su nombre y su fondo.

• Eliminar pantalla: elimina la pantalla actual.

<img src="../../../../getting-started/window/editview/menu.files/menu12848.png" width="130" />

Compruebe antes que la pantalla actual es la que quiere eliminar y que no contiene objetos necesarios, porque la operación no puede deshacerse.

**Menú «Ajustes»**

El menú «Ajustes (S)» contiene los comandos: Preferencias (P), Protección de archivo (M), Editor de scripts, Script global, Script de inicialización y Añadir teclado personalizado.

<img src="../../../../getting-started/window/editview/menu.files/menu13188.png" width="217" />

Figura 2-34        Menú «Ajustes»

• Preferencias: abre la ventana de preferencias, donde se modifican el modelo de HMI, el modo de visualización, la pantalla de inicio, el tiempo del salvapantallas, la frecuencia de parpadeo, el sonido de alarma, el sonido táctil, las contraseñas y el nivel inicial.

• Protección de archivo: abre la ventana de contraseña de protección del archivo, que permite proteger con contraseña el archivo del proyecto actual.

• Editor de scripts: abre el editor de scripts, donde se añaden, modifican, compilan o eliminan scripts.

• Script global: abre la pantalla de ajuste de scripts globales para definirlos o modificarlos.

• Script de inicialización: abre la pantalla de ajuste de scripts de inicialización para definirlos o modificarlos.

• Añadir teclado personalizado: abre un teclado definido por el usuario.

<img src="../../../../getting-started/window/editview/menu.files/menu14111.png" width="130" />

Recuerde la contraseña: después será necesaria para abrir el archivo del proyecto. Distingue mayúsculas y minúsculas.

**Menú «Descarga»**

El menú «Descarga» sirve para compilar y descargar el proyecto; contiene ocho comandos: Compilar (C), Simulación sin conexión (M), Simulación en línea, Descarga USB (D), Carga, Comprimir/descomprimir, Extraer proyecto y guardar como, y Extraer proyecto de simulación remota (A). Con el PC conectado a la pantalla táctil por cable USB, el proyecto se descarga mediante «Descarga USB», pero antes hay que compilarlo.

<img src="../../../../getting-started/window/editview/menu.files/menu14738.png" width="346" />

Figura 2-35        Menú «Descarga»

• Compilar: comprueba el proyecto creado por el usuario y lo prepara para la descarga.

• Simulación sin conexión: abre la aplicación de simulación de CommandHMI. El usuario simula en el PC el proyecto actual para ver el resultado y corregir las pantallas. Guarde el proyecto antes de la simulación sin conexión.

• Simulación en línea: abre el panel de simulación de CommandHMI; el usuario simula en el PC el proyecto actual para ver el resultado y corregir las pantallas. En la simulación en línea también se puede comunicar con el equipo conectado por Ethernet o puerto serie del PC y probar la comunicación. Guarde el proyecto antes de la simulación en línea.

• Descarga USB: descarga al HMI el proyecto compilado con CommandHMI mediante el cable USB suministrado con la pantalla táctil. Compile y guarde el proyecto antes de descargarlo.

• Carga: carga del HMI al PC los datos históricos, la configuración, las recetas y las alarmas históricas mediante el cable USB suministrado.

• Comprimir/descomprimir: comprime el proyecto en un archivo XXX.vpr o descomprime un archivo comprimido en un archivo de proyecto .vpm.

• Extraer proyecto y guardar como: compila el proyecto actual en un archivo binario u-disk-prj.bin. Guardado en una memoria USB, actualiza automáticamente el HMI sin cable USB.

**Menú contextual**

El menú contextual (clic derecho) facilita el trabajo y sigue las costumbres de la mayoría de usuarios de Windows. Contiene muchas funciones de configuración: Propiedades, Objetos, Biblioteca, Cortar, Copiar, Copia múltiple, Pegar, Eliminar, Seleccionar todo, Alinear, Capas, Agrupar, Zoom, Cuadrícula y Pantalla.

<img src="../../../../getting-started/window/editview/menu.files/menu17926.png" width="176" />

Figura 2-40        Menú contextual

• Propiedades: abre las propiedades de un objeto (si hay uno seleccionado) o de la pantalla (si no hay ninguno seleccionado).

• Objeto: abre todos los objetos del menú «Objeto».

• Biblioteca: abre la galería o genera imágenes.

• Cortar: atajo Ctrl + X; elimina los objetos gráficos seleccionados y los copia al portapapeles.

• Copiar: atajo Ctrl + C; copia al portapapeles el objeto gráfico elegido.

• Copia múltiple: copia varias veces los objetos seleccionados en horizontal y vertical, con direcciones incrementadas de 0 a 255 unidades.

• Pegar: atajo Ctrl + V; pega en la pantalla actual los objetos del portapapeles.

• Eliminar: Supr; elimina de la pantalla el objeto gráfico seleccionado.

• Seleccionar todo: atajo Ctrl + A; selecciona todos los objetos de la pantalla actual.

• Alinear: alinea los objetos seleccionados (al menos dos) según el tipo elegido: arriba, abajo, centro vertical, izquierda, derecha, espaciado horizontal igual, espaciado vertical igual, igualar anchura, igualar altura, igualar anchura y altura.

• Capas: cambia el nivel de los objetos seleccionados: traer al frente, traer adelante, enviar al fondo o enviar atrás.

• Agrupar: combina los objetos seleccionados (al menos dos) en un solo objeto, o descompone un objeto agrupado en sus objetos originales.

<img src="../../../../getting-started/window/editview/menu.files/menu19697.png" width="130" />

Al agrupar, no incluya objetos táctiles: tras la descarga a la pantalla táctil dejarían de responder. Para superponer objetos táctiles, use las capas.

• Zoom: amplía o reduce la pantalla actual para un trabajo más preciso: ampliar, ajustar o reducir.

• Cuadrícula: muestra u oculta una cuadrícula de anchura definida en la pantalla actual.

• Pantalla: crea una pantalla, abre sus propiedades o elimina una pantalla.

<img src="../../../../getting-started/window/editview/menu.files/menu20284.png" width="130" />

Compruebe antes que la pantalla actual es la que quiere eliminar y que no contiene objetos necesarios, porque la operación no puede deshacerse.
