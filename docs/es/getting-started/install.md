# Instalar el software

CommandHMI es una aplicación para Microsoft Windows. Antes de instalarla, compruebe que el ordenador cumple los requisitos mínimos de software y hardware.

Ejecute el instalador de CommandHMI suministrado con el producto. Pasos:

Descargue el instalador del sitio web oficial;

![2018_11_19_19_32_06.jpg](../../getting-started/install.files/setup.png)

Figura 2-1      Paquete de instalación de CommandHMI

Al hacer doble clic en el instalador se abre la ventana de instalación de CommandHMI.

El primer cuadro de diálogo es el «Contrato de licencia»; elija «Siguiente» para continuar o «Cancelar» para salir del programa de instalación, como en la figura 2-2.

Elija «Acepto el contrato» y haga clic en «Siguiente».

<img src="../../getting-started/../image/2025-10-11/setup-1.png" width="513" alt="ScreenShot00201.jpg" />

Figura 2-2      Cuadro de diálogo Contrato de licencia

En el cuadro de diálogo de carpeta de destino, elija la carpeta de instalación. Por defecto es «C:\Program Files (x86)\CommandHMI»; con «Examinar...» puede elegir otra ruta; después haga clic en «Siguiente»

  <img src="../../getting-started/../image/2025-10-11/setup-3.png" width="513" alt="ScreenShot00202.jpg" />

Figura 2-5      Ruta de instalación

Haga clic en «Siguiente» en la figura 2-5; aparece la elección de la carpeta de los archivos (por defecto u otra); haga clic en «Siguiente», como en la figura 2-6:

<img src="../../getting-started/../image/2025-10-11/setup-3.1.png" width="513" alt="ScreenShot00203.jpg" />

Figura 2-6      Archivos de instalación

Pantalla «Crear acceso directo en el escritorio»; haga clic en «Siguiente», como en la figura 2-7:

<img src="../../getting-started/../image/2025-10-11/setup-4.png" width="513" alt="ScreenShot00204.jpg" />

Figura 2-7      Crear acceso directo en el escritorio

  <img src="../../getting-started/../image/2025-10-11/setup-5.png" width="513" alt="ScreenShot00205.jpg" />
