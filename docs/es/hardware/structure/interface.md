# Puertos de comunicación

Los puertos de comunicación del HMI están en el panel inferior.

Con cable apantallado, la distancia de comunicación RS232 no debe superar los 15 metros. Para la conexión al ordenador hay un puerto USB que sirve para descargar la configuración (transferencia de datos), a una velocidad de hasta 10 Mbps. La asignación del puerto de comunicación varía según el PLC conectado (indique el tipo de PLC al hacer el pedido para facilitar la entrega del cable de comunicación).
