# Biblioteca de direcciones

La biblioteca de direcciones da un alias a un registro: el usuario accede a la variable mediante la etiqueta de dirección o mediante la dirección del registro.

Uso de la biblioteca de direcciones:

<img src="../../setting/addresslibrary.files/image002.jpg" width="270" alt="ScreenShot00776.jpg" />

Ø  Crear una etiqueta de dirección

Haga doble clic en «Biblioteca de direcciones»; se abre el cuadro de diálogo siguiente

Haga clic en «Nuevo»; se abre el cuadro de diálogo siguiente

Descripción: descripción de la etiqueta creada, para identificar fácilmente el significado y el uso de la variable

Comando: la etiqueta personalizada es un alias del registro; al introducir una dirección se elige este alias para usar el registro

Tipo de dirección: tipo de dato del alias; solo dos opciones

Dirección: dirección del registro asociado a la etiqueta

Número: se pueden crear etiquetas por lotes; cada etiqueta se refiere a una sola variable, no a un array

Ø  Usar una etiqueta de dirección

Se toma como ejemplo la etiqueta lw0 definida antes

Las etiquetas de dirección dan un nombre significativo a los registros más usados, que se emplea en el proyecto: la introducción de direcciones es más sencilla y la configuración más rápida
