# Reenvío de datos

**Función de reenvío de datos:**

1、El reenvío de datos transfiere datos entre equipos conectados a dos puertos del HMI.

Ejemplo:

Puerto 1 con protocolo Modbus RTU Slave: el HMI es esclavo; el equipo 1 (maestro) lee la dirección LW0 del HMI.

Puerto 2 con protocolo Modbus RTU Master: el HMI lee la dirección 4x11 del esclavo 2.
