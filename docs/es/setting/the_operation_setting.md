# Ajustes de manejo

Ajustes de manejo de la configuración:

<img src="../../setting/the_operation_setting.files/image002.jpg" width="360" alt="ScreenShot00056.jpg" />

• Modo de selección

Selección por zona: un objeto se selecciona si la zona trazada con el ratón contiene una parte de él

Selección de objeto: un objeto solo se selecciona si la zona trazada con el ratón lo contiene por completo

•  Modo de pegado

Pegar con clic: tras copiar, el objeto se pega en el punto donde se hace clic

Pegar en la misma posición: tras copiar, el objeto se pega junto a la posición del objeto copiado

•  Tipo de archivo de extracción USB (diHM)

Versión 6.0: genera un archivo diHM de versión 6.0

Superior a 6.0: genera un archivo diHM de versión superior a 6.0
