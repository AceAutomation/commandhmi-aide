# Script de disparo

Un script compilado correctamente se define como script de disparo y se ejecuta cuando se produce la condición indicada. Las condiciones de disparo son el cambio de pantalla/ventana y el cambio de valor de una dirección.

Haga clic en «Script de disparo» en el menú «Ajustes»; se abre el cuadro de diálogo siguiente:

<img src="../../setting/trigger_script.files/trigger_script764.png" width="663" />

Figura 7-45 Cuadro de diálogo Script de disparo

Haga clic en «Nuevo» para abrir un nuevo cuadro de diálogo y elija el script que se ejecutará al producirse la condición.

Tipos de disparo: por dirección y por pantalla.

Disparo por dirección: dirección de bit y modo de disparo: OFF-&gt;ON, ON-&gt;OFF, OFF&lt;-&gt;ON, ejecución inmediata mientras el estado es ON.

Disparo por pantalla: nombre de pantalla como condición y modo de disparo: abrir pantalla o cerrar pantalla.
