# Tabla de variables

Una variable se define con una dirección; al usar la variable se accede a esa dirección. Haga doble clic en «Tabla de variables» en el gestor de proyecto; se abre el cuadro de diálogo de la figura 7-15:

<img src="../../setting/variblesetting.files/variblesetting735.png" width="614" />

Figura 7-15    Cuadro de diálogo Tabla de variables

• Nuevo: añade una variable; máximo 1000

• Eliminar: elimina la variable seleccionada.

• Modificar: modifica la variable seleccionada (también con doble clic).

• Eliminar todo: elimina todas las variables.

• Importar: abre un cuadro de apertura para importar una tabla de variables.

• Exportar: abre un cuadro de guardado para exportar la tabla de variables actual.

<img src="../../setting/variblesetting.files/variblesetting1256.png" width="277" />

Figura 7-16    Cuadro de diálogo Nueva variable

• Nombre de variable: nombre de la variable nueva.

• Tipo de dirección: tipo de dato de la dirección.

• Dirección: dirección asociada.
