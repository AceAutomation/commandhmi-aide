# Script de inicialización

Un script compilado correctamente se define como script de inicialización: se ejecuta una sola vez, independientemente de las pantallas. Se pueden añadir hasta 64 scripts de inicialización, que se ejecutan en el orden definido.

Haga clic en «Script de inicialización» en el menú «Ajustes»; se abre el cuadro de diálogo siguiente:

<img src="../../setting/init-macro.files/init-macro309.png" width="436" />

Al hacer clic en el elemento de la lista se muestran todos los scripts compilados correctamente. El script elegido se ejecuta como script de inicialización en tiempo de ejecución.
