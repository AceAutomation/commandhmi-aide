# Script global

Un script compilado correctamente se define como script global: se ejecuta al arrancar el proyecto y durante todo su funcionamiento, independientemente de las pantallas. Se pueden añadir hasta 64 scripts globales, que se ejecutan en el orden definido.

Haga clic en «Script global» en el menú «Ajustes»; se abre el cuadro de diálogo siguiente:

<img src="../../setting/overall-macro.files/overall-macro384.png" width="437" />

Al hacer clic en el elemento de la lista se muestran todos los scripts compilados correctamente; indique después si el script está controlado por un bit y su frecuencia de ejecución. El script elegido se ejecuta como script global en tiempo de ejecución.
