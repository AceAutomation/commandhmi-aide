# Script

El script es un medio de control avanzado que amplía las funciones de la pantalla táctil. Programando scripts, la pantalla táctil obtiene las mismas capacidades lógicas y aritméticas que un PLC. Usados con flexibilidad, los scripts permiten realizar muchas funciones imposibles con los objetos convencionales y perfeccionar la interfaz hombre-máquina.

CommandHMI ofrece scripts completos, distintos de los lenguajes de script de otros HMI, y compatibles con el C estándar (ANSI C89). Como existe abundante documentación sobre el lenguaje C, este capítulo no detalla la sintaxis ni los conceptos básicos, sino que se centra en la creación y el uso de scripts mediante ejemplos.

Este capítulo explica brevemente los fundamentos del lenguaje C, el uso de las instrucciones de script y las precauciones.
