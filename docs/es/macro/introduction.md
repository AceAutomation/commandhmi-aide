**2.**<img src="../../macro/introduction.files/introduction952.png" width="31" />**Importar:** importa un script existente.

**3.  Correctos:** scripts compilados correctamente

**4.  Fallidos:** scripts cuya compilación ha fallado

**5.  No compilados:** scripts aún no compilados

6\. **No guardados:** scripts no guardados

**&lt;2&gt; Ventana de edición:** aquí se edita y compila el script. «ID»: número del script editado; «Script»: nombre del script editado, modificable.

<img src="../../macro/introduction.files/introduction1778.png" width="324" />: menú de edición de scripts, con diez botones:

<img src="../../macro/introduction.files/introduction1990.png" width="32" /> **Deshacer:** anula la última operación.

<img src="../../macro/introduction.files/introduction2177.png" width="31" />  **Rehacer:** rehace la operación siguiente.

<img src="../../macro/introduction.files/introduction2363.png" width="19" />  **Cortar**: corta el código seleccionado.

<img src="../../macro/introduction.files/introduction2547.png" width="32" /> **Pegar**: pega el código.

<img src="../../macro/introduction.files/introduction2722.png" width="21" /> **Copiar**: copia el código.

<img src="../../macro/introduction.files/introduction2895.png" width="23" /> **Guardar**: guarda el script.

<img src="../../macro/introduction.files/introduction3068.png" width="29" />**Exportar**: abre el cuadro de guardado para elegir la ruta y el nombre y guarda el script como archivo \*.csv.

<img src="../../macro/introduction.files/introduction3313.png" width="26" /> **Compilar**: compila el código fuente del script actual y comprueba los errores de sintaxis.

<img src="../../macro/introduction.files/introduction3544.png" width="26" /> **Ocultar/mostrar la ventana de ajustes y salida.**

<img src="../../macro/introduction.files/introduction3740.png" width="22" /> **Ayuda**: muestra el archivo de ayuda.

**&lt;3&gt; Ventana de ajustes y salida:** define las variables y muestra los mensajes de compilación.

**Página «Ajuste de variables»:** haga clic en la celda «Nuevo» de esta página para abrir el cuadro de diálogo «Nueva variable de script», como en la figura 5.6. La variable se asocia a un registro.
