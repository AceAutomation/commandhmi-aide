# Instrucción break

La instrucción break solo se usa en instrucciones switch o en bucles. Sirve para salir del switch o del bucle actual y continuar con el resto del programa. Como el destino del salto está definido, no hace falta etiqueta. Su forma general es break. Como en el ejemplo anterior, break se usa en las instrucciones switch y for para saltar. break ofrece varias salidas de un bucle, lo que en algunos casos hace la programación más flexible y cómoda.
