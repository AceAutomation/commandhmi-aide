# Programar con las funciones de script

Esta sección presenta las funciones básicas de los scripts y describe brevemente los objetos y su uso.

Formas de acceder a los scripts:

Método 1: elija «Setting (S) -&gt; Macro» en el menú, como en la figura 5-1 (menú de scripts); se abre la ventana de la figura 5-1 (editor de scripts).
