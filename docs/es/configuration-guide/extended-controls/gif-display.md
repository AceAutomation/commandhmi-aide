# Visualización GIF

La visualización GIF muestra imágenes en formato GIF de hasta 32 fotogramas. Procedimiento:

Haga clic en el icono GIF<img src="../../../configuration-guide/extended-controls/gif-display.files/image002.jpg" width="29" /> de la barra de herramientas para abrir el cuadro de diálogo de la figura 4-48.

Figura 4-48    Cuadro de diálogo Visualización GIF

Tras ajustar las propiedades, haga clic en «Aceptar»; el cursor se convierte en una cruz en la zona de edición; dibuje un rectángulo con el botón izquierdo para añadir el objeto a la zona de trabajo (la pantalla)

Elija la página «Avanzado» para ver sus propiedades.

![](../../../configuration-guide/extended-controls/gif-display.files/image004.jpg)

Figura 4-49    Página «Avanzado» de la visualización GIF

Controlado por bit: si se marca y el «Estado activo» es 1, la imagen GIF solo se anima cuando el «Bit de control» vale 1; si no, se muestra estática. Si el «Estado activo» es 0, solo se anima cuando el «Bit de control» vale 0; si no, se muestra estática.

<img src="../../../configuration-guide/extended-controls/gif-display.files/image005.jpg" width="130" />

Para la página «Visibilidad», véase el uso del objeto «Botón de bit».
