# Barra de alarmas

<span id="OLE_LINK572"></span><span id="OLE_LINK573"></span>         La barra de alarmas muestra las alarmas actuales. A diferencia del objeto de visualización de alarmas, la barra de alarmas dinámica muestra el contenido de las alarmas actuales (digitales y analógicas) como texto desplazable.

Si hay tres alarmas, la barra de alarmas dinámica muestra la primera, luego la segunda y luego la tercera, y así sucesivamente. El desplazamiento es de derecha a izquierda, aunque también puede ser de izquierda a derecha; la velocidad, el intervalo de movimiento y el sonido de alarma se definen en las propiedades; véase «Ajustes de visualización de alarmas». Antes de usar la barra de alarmas dinámica hay que configurar las alarmas; véase «Ajustes de alarmas».

Añadir la barra de alarmas:

Elija «Barra de alarmas» o el botón<img src="../../../configuration-guide/extended-controls/alarm-bar.files/image002.jpg" width="31" /> en el menú «Herramientas», como en la figura 4-60:

Figura 4-60    Cuadro de diálogo Barra de alarmas

Seleccionar todas las alarmas: si se marca, el objeto muestra toda la información de «Alarmas digitales» y «Alarmas analógicas» del gestor de proyecto; si no, solo las alarmas elegidas por el usuario.

• Idioma: el tamaño de fuente, la fuente, la hora, la fecha y el texto del mensaje pueden variar según el idioma; el color de fondo y el del texto son los del primer idioma.

• Fuente: cambia la fuente del texto de las alarmas

• Tamaño de fuente: cambia el tamaño del texto de las alarmas

• Color del texto: cambia el color del texto de las alarmas

• Velocidad: paso de desplazamiento del texto de las alarmas.

• Dirección: sentido de desplazamiento del texto (izquierda o derecha)

• Orden de alarmas: orden de visualización de las alarmas.

<img src="../../../configuration-guide/extended-controls/alarm-bar.files/image004.jpg" width="130" />

• Para forma, color del borde, color de fondo, color de primer plano y trama, véase el objeto «Botón de bit».

• En la simulación sin conexión, el tamaño de fuente debe ser «16x16»; en los demás casos puede elegir otro.
