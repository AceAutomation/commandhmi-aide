# Tabla

Elija la orden «Tabla» del menú «Dibujo» o haga clic en el botón<img src="../../../configuration-guide/basic-graph/table.files/image002.jpg" width="29" /> de la barra de herramientas; se abre el cuadro de diálogo de tabla, como en la figura 4-39:

Figura 4-39     Cuadro de diálogo Tabla

En este cuadro de diálogo, el software CommandHMI ofrece las opciones Color de fondo, Borde, Cuadrícula y Líneas de cuadrícula. En «Cuadrícula» se decide si se muestran las líneas verticales u horizontales, y su tipo y color pueden cambiarse.

<img src="../../../configuration-guide/basic-graph/table.files/image004.jpg" width="130" />

La tabla es solo un objeto gráfico: no se puede añadir texto, datos ni otros objetos dentro. Solo sirve como imagen de fondo. Para mostrar texto, datos u otros objetos sobre una tabla, superponga objetos de texto o de visualización numérica y colóquelos en la capa superior.
