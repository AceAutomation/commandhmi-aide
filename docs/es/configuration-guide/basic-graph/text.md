# Texto

Elija la orden «Texto» del menú «Dibujo» o haga clic en el botón Texto<img src="../../../configuration-guide/basic-graph/text.files/image002.jpg" width="30" /> de la barra de herramientas para abrir el cuadro de diálogo de texto estático, como en la figura 4-36:

Figura 4-36 Cuadro de diálogo Texto estático

• Escriba el texto a mostrar en el campo TEXTO del cuadro de diálogo.

• El tamaño de la fuente se cambia en la lista desplegable «Tamaño de fuente». El software CommandHMI ofrece tamaños de 7 a 56 puntos.

• El tipo de fuente se cambia en la lista desplegable «Fuente». El software CommandHMI ofrece prácticamente todas las fuentes.

• Idioma: para cada idioma se puede escribir un texto distinto, con fuente y tamaño propios.

• En el cuadro de diálogo, marque las casillas «Negrita» y «Cursiva» para cambiar el estilo de la fuente.

• El software ofrece espaciado entre caracteres e interlineado de 0 a 15, ajustables con los botones de ajuste fino correspondientes

• El software CommandHMI ofrece además 16 tipos de subrayado y permite cambiar la posición del texto dentro del cuadro, así como la trama de relleno y la transparencia.

**Resultado del texto**

• Tras modificar las propiedades de la fuente, haga clic en «Aceptar» para cerrar el cuadro de diálogo. Lleve el ratón al punto de la ventana de edición donde quiere colocar el texto y haga clic con el botón izquierdo; el sistema dibuja automáticamente un rectángulo.

• Para modificar o volver a escribir el texto, haga doble clic en él con el botón izquierdo y escriba el nuevo contenido con el teclado. La tecla Intro permite cambiar de línea.

• Para cambiar el tamaño del recuadro de fondo del texto, selecciónelo y lleve el ratón a su borde; cuando el cursor se convierta en<img src="../../../configuration-guide/basic-graph/text.files/image004.jpg" width="22" /> o <img src="../../../configuration-guide/basic-graph/text.files/image005.jpg" width="23" /> o<img src="../../../configuration-guide/basic-graph/text.files/image006.jpg" width="21" />, mantenga pulsado el botón izquierdo, arrastre el recuadro a la posición adecuada y suelte el botón.
