# Visualización de recetas

La visualización de recetas muestra los datos de todas las recetas creadas. Su icono en la barra de herramientas es<img src="../../../configuration-guide/new_add_control/recipedisplay.files/recipedisplay150.png" width="31" />. Haga clic en él; se abre el cuadro de diálogo siguiente:

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image001.jpg" width="481" alt="ScreenShot00674.jpg" />

Figura 4-129   Página «General» de la visualización de recetas

La página «General» contiene los ajustes de texto y las propiedades de la lista.

Página «Datos», como abajo

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image002.jpg" width="481" alt="ScreenShot00675.jpg" />

Figura 4-130   Página «Datos» de la visualización de recetas

• Idioma: elija un idioma para mostrar los nombres de receta en ese idioma.

• Nombre: lista de todos los nombres de receta

• Mostrar: indica si se muestra cada receta.

• TODO: marca todos los elementos de «Mostrar».

CommandHMI admite varios grupos de recetas; al usar este objeto se elige qué grupo mostrar, como abajo:
