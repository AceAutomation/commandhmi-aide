# Selector de recetas

El selector de recetas muestra los nombres de todas las recetas creadas. Al elegir un nombre en la lista, su número se escribe en el registro de número de receta RWI0. A la inversa, si cambia el valor de RWI0, el selector apunta a la receta correspondiente. Su icono en la barra de herramientas es: <img src="../../../configuration-guide/new_add_control/recipeselect.files/recipeselect411.png" width="28" />; haga clic en él para abrir el cuadro de diálogo siguiente:

• Estilo de visualización

Estilo de visualización del selector de recetas

Lista: el selector de recetas se muestra como una lista.

Lista desplegable: el selector de recetas se muestra como una lista desplegable.

• Fuente, tamaño de fuente, color del texto y color de fondo: propiedades de la lista y de su texto

• Filas: solo disponible si el estilo de visualización es «Lista».
