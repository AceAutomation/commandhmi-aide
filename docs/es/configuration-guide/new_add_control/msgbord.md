# Pizarra

Pizarra: objeto sobre el que el usuario puede escribir. Su icono en la barra de herramientas es: <img src="../../../configuration-guide/new_add_control/msgbord.files/image002.jpg" width="26" />. Haga clic en él para abrir el cuadro de diálogo de la figura 4-121.

Figura 4-121   Página «General» de la pizarra

• Color de línea: color del trazo escrito en el objeto

• Grosor de línea: grosor del trazo

• Modo de funcionamiento:

Dirección del modo de funcionamiento: dirección de palabra, válida solo si vale 0 o 1. 0 indica escritura; 1 indica borrado.

La dirección de palabra ocupa 3 direcciones consecutivas: la primera controla el modo (0 escritura, 1 borrado), la segunda el grosor de línea y la tercera el color RGB del trazo.

• Borrar pantalla

Dirección de borrado: cuando su valor es igual al estado de borrado definido (0 o 1), se borra automáticamente todo lo escrito en el objeto

Para la página «Visibilidad», véase el «Botón de bit».
