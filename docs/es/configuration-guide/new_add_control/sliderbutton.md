# Deslizador

Deslizador analógico: al arrastrar el cursor cambia el valor de la dirección de registro de palabra correspondiente.

Elija el icono <img src="../../../configuration-guide/new_add_control/sliderbutton.files/sliderbutton144.png" width="43" /> en la barra de herramientas; se abre el cuadro de propiedades del «Deslizador», como en la figura 4-117:

<img src="../../../configuration-guide/new_add_control/sliderbutton.files/sliderbutton241.png" width="726" />

Figura 4-117 Cuadro de diálogo Deslizador

• Posición de la escala: posición de la escala.

• Dirección de la escala: orientación de la escala.

• Dirección de escritura: al arrastrar el deslizador, el valor se escribe y se muestra en tiempo real.

• Rango dinámico: controla el deslizador con direcciones de palabra. Si la casilla no está marcada, los valores máximo y mínimo dependen del tipo de dato y el usuario puede cambiarlos libremente; el valor del deslizador es entonces el definido aquí. Si está marcada, los valores máximo y mínimo se leen de direcciones de palabra y se controlan mediante esas direcciones.

Para la página «Escala», véase el «Indicador de aguja».

Para las páginas «Avanzado» y «Visibilidad», véase el «Botón de bit».
