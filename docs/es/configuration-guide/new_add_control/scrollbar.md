# Barra de desplazamiento

La barra de desplazamiento permite recorrer los datos de los objetos de tipo tabla y facilita su consulta rápida. Solo es compatible con estos objetos: visualización de alarmas, visualización de alarmas históricas, visualización de recetas, visualización de datos históricos y registro de operaciones

Se usa cuando el objeto asociado tiene demasiados datos para mostrarlos todos a la vez, para ver el resto de los datos

Cuadro de diálogo Barra de desplazamiento

A continuación se describen sus funciones (el objeto tiene dos variantes: botones de desplazamiento y barra de desplazamiento)

Ø  Barra de desplazamiento: desplaza los datos de la tabla mediante una barra

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image005.jpg" width="859" alt="ScreenShot00820.jpg" />

l  Color de fondo: color de fondo del objeto

l  Color de los símbolos: color de los símbolos del objeto

l  Dirección: dirección en la que la barra desplaza los datos de la tabla

n  Horizontal: desplaza horizontalmente los datos de la tabla

n  Vertical: desplaza verticalmente los datos de la tabla

l  Número de objeto asociado: si la pantalla actual contiene alguno de los objetos citados, puede asociarse a él para controlarlo. Si no contiene ninguno, aparece el mensaje de error «el objeto asociado no puede estar vacío». El número de objeto es el número que aparece en la esquina superior izquierda del objeto.

Ø  Botones de desplazamiento: desplazan los datos de la tabla mediante botones

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image006.jpg" width="859" alt="ScreenShot00821.jpg" />

l Color del borde: color del borde del objeto

l  Color de fondo: color de fondo del objeto

l  Color de los símbolos: color de los símbolos del objeto

l  Dirección

n  Horizontal: desplaza horizontalmente los datos de la tabla

n  Vertical: desplaza verticalmente los datos de la tabla

l  Número de objeto asociado: véase la descripción anterior

l Teclas de función

n  Intervalo entre botones: separación entre los botones

n  Al principio / al final: lleva los datos de la tabla al principio o al final; con los dos botones siguientes, si los datos ya están al principio o al final, al pulsar aparece un mensaje indicando que la operación no es válida

n  Página anterior / siguiente o izquierda / derecha: desplaza una página cada vez

n  Arriba / abajo o izquierda / derecha: desplaza un dato cada vez en esa dirección

n  Pausa: si los datos de la tabla están cambiando, este botón detiene los cambios y un segundo clic los reanuda. Si la tabla no cambia, al pulsar el botón se indica que la función no es válida.
