# Gráfico de arco

El gráfico de arco (también llamado gráfico de sector) funciona como el indicador de aguja: lee y refleja el valor de la dirección de monitorización. La zona de respuesta se representa con el «color de primer plano del sector», el «color de fondo del sector» y la «trama». Su icono en la barra de herramientas es <img src="../../../configuration-guide/new_add_control/arc.files/image002.jpg" width="33" />; haga clic en él para abrir el cuadro de diálogo de la figura 4-111:

Figura 4-111   Página «General» del gráfico de arco

La página «Escala» se muestra en la figura 4-112:

<img src="../../../configuration-guide/new_add_control/arc.files/image004.jpg" width="694" />

Figura 4-112 Página «Escala»

Para la escala, véase la página «Escala» del «Indicador de aguja».

Para los parámetros de «Avanzado», véase la «Visualización numérica».
