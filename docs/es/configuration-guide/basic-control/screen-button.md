# Botón de pantalla

El botón de pantalla sirve para cambiar de pantalla, cambiar el nivel de usuario, abrir ventanas emergentes, etc. Permite pasar de una pantalla/ventana a otra y, opcionalmente, cambiar a la vez el nivel de usuario.

• Haga clic en el icono <img src="../../../configuration-guide/basic-control/screen-button.files/screen-button293.png" width="30" /> de la barra de herramientas para abrir el cuadro de diálogo, como en la figura 4-80.

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button364.png" width="671" />

Figura 4-80 Cuadro de diálogo Botón de pantalla

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button404.png" width="130" />

Para forma, color del borde, color de primer plano, color de fondo y trama, véase el «Botón de bit».

**Funciones:**

• Abrir pantalla: al pulsar el botón se pasa a la pantalla elegida. Puede usarse en una pantalla o en una ventana.

• Abrir pantalla anterior: al pulsar el botón se vuelve a la pantalla anterior. Solo puede usarse en una pantalla.

• Cerrar y abrir pantalla: solo puede usarse en una ventana. Cierra la ventana actual y abre otra ventana o pantalla.

• Cerrar pantalla: solo puede usarse en una ventana. Cierra la ventana actual.

**Cambiar nivel de usuario:**

• Cerrar sesión: el nivel de usuario actual vuelve al nivel por defecto

• Nivel de usuario indicado: el nivel de usuario actual pasa al nivel indicado

**Momento de apertura:**

• Pulsar: el cambio de pantalla se ejecuta al pulsar.

• Soltar: el cambio de pantalla se ejecuta al soltar.

**Inicio de sesión si el nivel es insuficiente:**

Si en la página «Avanzado» del botón de pantalla está marcada la opción «Controlado por nivel de usuario» y se ha cambiado el «Nivel mínimo efectivo», el objeto solo funciona si el nivel del usuario actual es igual o superior a ese nivel. Si es inferior, al tocar el objeto en la pantalla táctil aparece el campo de contraseña, como en la figura 4-81:

![](../../../configuration-guide/basic-control/screen-button.files/001.png)

Figura 4-81 Teclado de contraseña

La pantalla solo se abre si la contraseña introducida corresponde a un nivel superior al definido; el nivel de usuario actual pasa a ser el de la contraseña introducida.

**Scripts:**

«Usar script» muestra la lista de scripts. El usuario elige uno que se ejecuta al pulsar el botón. La lista solo muestra los scripts compilados.

<img src="../../../configuration-guide/basic-control/screen-button.files/screen-button2377.png" width="130" />

La página «Etiqueta» del botón de pantalla es similar a la del objeto «Botón de bit». Como el botón de pantalla solo tiene un estado, su página «Etiqueta» solo tiene Texto estado 1 e Imagen estado 1. Por lo demás, las funciones son las mismas.

Las páginas «Avanzado» y «Visibilidad» del botón de pantalla son iguales a las del objeto «Botón de bit».

Tras ajustar todas las propiedades, haga clic en «Aceptar»; el cursor se convierte en una cruz. Haga clic con el botón izquierdo en la zona de trabajo para añadir el objeto a la pantalla.
