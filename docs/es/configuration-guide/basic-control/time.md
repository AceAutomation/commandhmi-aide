# Visualización de hora

El objeto de visualización de hora muestra la hora del sistema. Haga clic en el icono del objeto<img src="../../../configuration-guide/basic-control/time.files/image002.jpg" width="31" />; se abre el cuadro de diálogo de la figura 4-105.

Figura 4-105    Cuadro de diálogo Visualización de hora

<img src="../../../configuration-guide/basic-control/time.files/image004.jpg" width="130" />

Nota: para forma, color del borde, color de primer plano, color de fondo y trama, véase el objeto Botón de bit.

• Formato: cuatro formatos de hora disponibles.

HH:MM                Hora: minuto

HH:MM:SS           Hora: minuto: segundo

HH-MM-SS           Hora- minuto- segundo

HH-MM                Hora- minuto

• Fuente: tipo de letra del texto

• Tamaño de fuente: tamaño de la visualización

• Color: color del texto

• Alineación: posición de la visualización: izquierda, centro o derecha.

Tras los ajustes, haga clic en «Aceptar» para añadir el objeto a la zona de trabajo (la pantalla)
