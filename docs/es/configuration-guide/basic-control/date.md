# Visualización de fecha

El objeto de visualización de fecha muestra la fecha del sistema. Haga clic en el icono <img src="../../../configuration-guide/basic-control/date.files/image002.jpg" width="31" /> de la barra de herramientas; se abre el cuadro de diálogo de la figura 4-106:

<img src="../../../configuration-guide/basic-control/date.files/image005.jpg" width="675" />

Figura 4-106   Cuadro de diálogo Visualización de fecha

• Formato: hay nueve formatos de fecha disponibles.

YYYY-MM-DD

MM-DD-YYYY

DD-MM-YYYY

YYYY/MM/DD

MM/DD/YYYY

DD/MM/YYYY

YYYY.MM.DD

MM.DD.YYYY

DD.MM.YYYY

• Fuente: tipo de letra del texto

• Tamaño de fuente: tamaño de la visualización

• Color: color del texto

• Alineación: posición de la visualización: izquierda, centro o derecha.

<span id="OLE_LINK738"></span><span id="OLE_LINK739"></span><span id="OLE_LINK749"></span>Tras los ajustes, haga clic en «Aceptar» para añadir el objeto a la zona de trabajo (la pantalla)

<img src="../../../configuration-guide/basic-control/date.files/image004.jpg" width="130" />

Nota: para forma, color del borde, color de primer plano, color de fondo y trama, véase el objeto Botón de bit.
