# Imagen estática

El objeto de imagen estática muestra una imagen de distintos formatos, procedente de un archivo o de la biblioteca. Puede servir de fondo de pantalla para mejorar el aspecto del proyecto.

1\. Haga clic en el icono de imagen estática<img src="../../../configuration-guide/basic-control/picture.files/image002.jpg" width="30" /> de la barra de herramientas; se abre el cuadro de diálogo de la figura 4-109:

<img src="../../../configuration-guide/basic-control/picture.files/image004.jpg" width="675" />

Figura 4-109   Cuadro de diálogo Imagen estática

2\. Elija una imagen y haga clic en «Aceptar»; el cursor se convierte en una cruz. Haga clic con el botón izquierdo en la pantalla para añadir el objeto de imagen.

3\. El tamaño de la imagen insertada puede modificarse con el ratón. El software de configuración CommandHMI admite los formatos JPG, BMP, PNG, WMF, EMF y GIF.
