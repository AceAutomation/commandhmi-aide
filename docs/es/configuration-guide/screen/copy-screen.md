# Copiar una pantalla

Este comando copia una pantalla del proyecto actual; procedimiento:

En el gestor de proyecto, haga clic con el botón izquierdo en la pantalla a copiar, después clic derecho y «Copiar», y de nuevo clic derecho y «Pegar» (figura 4-5).

Se crea una pantalla nueva copia de la indicada.
