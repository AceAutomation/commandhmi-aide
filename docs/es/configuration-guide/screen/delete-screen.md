# Eliminar una pantalla

Este comando elimina una pantalla del proyecto actual; procedimiento:

Elija «Eliminar pantalla» en el menú «Pantalla»; o seleccione la pantalla en el gestor de proyecto y elija «Eliminar» con el botón derecho; o haga clic derecho en un espacio vacío de la pantalla sin ningún objeto seleccionado para abrir el menú contextual con el comando «Eliminar».

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen407.png" width="382" />

Figura 4-4 Eliminar una pantalla

Haga clic en «Aceptar» para confirmar la eliminación.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen483.png" width="130" />

Una pantalla eliminada no puede recuperarse. Use este comando con precaución.
