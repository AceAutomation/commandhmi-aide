# Modificar las propiedades de la pantalla

Para modificar las propiedades de la pantalla, como el nombre o el color de fondo:

Sin ningún objeto seleccionado (haga clic en un espacio vacío de la pantalla), elija el comando <img src="../../../configuration-guide/screen/edit-screen.files/edit-screen760.png" width="26" /> de la barra de herramientas, o seleccione la pantalla en el gestor de proyecto y haga clic derecho, o haga clic derecho en la pantalla sin ningún objeto seleccionado para abrir el menú contextual con el comando «Propiedades».

<img src="../../../configuration-guide/screen/edit-screen.files/edit-screen1019.png" width="522" />

Figura 4-3      Propiedades de la pantalla

 En el cuadro de diálogo «Nueva pantalla», defina el nombre, el color de fondo y los ajustes de pantalla común, y haga clic en «Aceptar». El nombre por defecto de una pantalla nueva es su número.

Por defecto: color de fondo, color de primer plano y estilo de la pantalla.

Imagen: se puede usar una imagen como fondo.

Ajustes de pantalla común

Pantalla estándar: crea una pantalla estándar.

Definir como pantalla común: crea una pantalla común cuyos objetos pueden usarse en otras pantallas, pero cuyas propiedades solo pueden modificarse en esta pantalla.

Usar la pantalla común: usa una pantalla común ya creada, sin poder modificar las propiedades de sus objetos.
