# Ordenación automática

El comando «Ordenación automática» actúa sobre las pantallas del proyecto actual. Procedimiento:

El comando de ordenación automática ordena los números de las pantallas. Procedimiento:

En el gestor de proyecto, haga clic con el botón izquierdo en «Pantallas», después clic derecho y «Ordenación automática»; aparece la ventana de ajuste; marque la ordenación automática y haga clic en «Aceptar» para ordenar las pantallas (de menor a mayor).
