# Agrupar y desagrupar

El comando «Agrupar» actúa sobre grupos: reúne 2 o más objetos gráficos y objetos de la pantalla actual en un único objeto. Los elementos agrupados pueden ser gráficos dibujados por el diseñador, gráficos de la biblioteca del sistema u otros objetos, como alarmas, tendencias, etc. Tras agrupar, cada objeto conserva sus propiedades, que siguen siendo modificables. «Desagrupar» descompone un grupo en sus elementos originales: es la operación inversa de «Agrupar».
