# Alinear

Este comando actúa sobre grupos, igual que «Tamaño». El software CommandHMI permite alinear y redimensionar varios objetos gráficos, pero solo si hay varios seleccionados. Para seleccionarlos, mantenga pulsada la tecla Ctrl o trace un recuadro con el botón izquierdo del ratón. Las operaciones de alineación incluyen muchos comandos: izquierda, derecha, centro vertical, centro horizontal, arriba, abajo, espaciado horizontal igual, espaciado vertical igual, igualar anchura, igualar altura, igualar altura y anchura, etc.

• <img src="../../../configuration-guide/edit-graph/align.files/align610.png" width="33" />**Arriba**

La alineación «Arriba» alinea por arriba varios objetos gráficos (al menos dos) mediante «Arriba» en «Alinear» del menú «Edición» o en el menú contextual. Los objetos toman como referencia el borde superior más alto y quedan al mismo nivel. La comparación antes/después de la alineación arriba se muestra en la figura 4-16:

• <img src="../../../configuration-guide/edit-graph/align.files/align3248.png" width="32" />**Igualar anchura**

Este comando da la misma anchura a varios objetos gráficos (al menos dos) mediante «Igualar anchura» en «Tamaño» del menú «Edición» o en el menú contextual. Los objetos se reducen o amplían desde su esquina superior izquierda sin cambiar su altura, para que su anchura sea la del objeto seleccionado primero (rodeado de puntos negros; los demás tienen puntos verdes).

• <img src="../../../configuration-guide/edit-graph/align.files/align5257.png" width="28" />**Espaciado horizontal igual**

Este comando reparte con espaciado horizontal igual varios objetos gráficos (al menos dos), mediante «Espaciado horizontal igual» en «Alinear» del menú «Edición» o en el menú contextual.

• <img src="../../../configuration-guide/edit-graph/align.files/align5543.png" width="28" />**Espaciado vertical igual**

Este comando reparte con espaciado vertical igual varios objetos gráficos (al menos dos), mediante «Espaciado vertical igual» en «Alinear» del menú «Edición» o en el menú contextual.

<img src="../../../configuration-guide/edit-graph/align.files/align5825.png" width="130" />

Antes de igualar anchura, altura o ambas, compruebe si los objetos seleccionados están girados: la altura y la anchura de un objeto girado giran con él.
