# Programmer avec les fonctions de script

Cette section présente les fonctions de base des scripts et décrit brièvement les fonctions de contrôle et leur utilisation.

Il y a deux façons d'accéder aux scripts :

Méthode 1 : choisissez « Paramètres (S) -&gt; Macro » dans le menu, comme sur la figure 5-1 (menu des scripts) ; la fenêtre de la figure 5-1 (éditeur de scripts) s'ouvre.

<img src="../../macro/start-macro.files/start-macro327.png" width="199" />

Figure 5-1 (Menu des scripts)

Méthode 2 : cliquez sur le bouton « script » de la figure 5-2 (bouton script) ; la fenêtre de la figure 5-3 (éditeur de scripts) s'ouvre.

<img src="../../macro/start-macro.files/start-macro498.png" width="220" />

Figure 5-2 (Bouton script)
