# Boutons de fonction de l'éditeur de scripts

Les objets fonctionnels sont disposés dans la fenêtre de l'éditeur de scripts, comme sur la figure 5-3 (Éditeur de scripts).

<img src="../../macro/introduction.files/introduction563.png" width="1086" />

Figure 5-3 (Éditeur de scripts)

**&lt;1&gt; Liste des scripts :**

**1.**<img src="../../macro/introduction.files/introduction768.png" width="26" />**Nouveau (New) :** crée un script

**2.**<img src="../../macro/introduction.files/introduction952.png" width="31" />**Importer (Import) :** importe un script existant.

**3.  Réussis (Success) :** scripts compilés avec succès

**4.  Échoués (Fail) :** scripts dont la compilation a échoué

**5.  Non terminés (Not complited) :** scripts pas encore terminés

6\. **Non enregistrés (Not save) :** scripts pas encore enregistrés

7\. **Supprimer (Delete) : ‘**sélectionnez le script par un clic gauche, puis un clic droit affiche « Supprimer le script » ; cliquez pour supprimer

**&lt;2&gt; Fenêtre d'édition des scripts :** on y écrit et compile les scripts. « ID » : numéro du script édité ; « Script » : nom du script édité, modifiable.

<img src="../../macro/introduction.files/introduction1778.png" width="324" /> : menu d'édition des scripts, composé de dix boutons :

<img src="../../macro/introduction.files/introduction1990.png" width="32" /> **Annuler (Undo) :** annule la dernière opération.

<img src="../../macro/introduction.files/introduction2177.png" width="31" />  **Rétablir (Redo) :** rétablit l'opération annulée.

<img src="../../macro/introduction.files/introduction2363.png" width="19" />  **Couper (Cut)** : coupe la partie de script sélectionnée.

<img src="../../macro/introduction.files/introduction2547.png" width="32" /> **Coller (Paste)** : colle le script.

<img src="../../macro/introduction.files/introduction2722.png" width="21" /> **Copier (copy)** : copie le script.

<img src="../../macro/introduction.files/introduction2895.png" width="23" /> **Enregistrer (Save)** : enregistre le script.

<img src="../../macro/introduction.files/introduction3068.png" width="29" />**Exporter (Export)** : ouvre la boîte d'enregistrement ; choisissez le chemin et le nom pour enregistrer le script en fichier \*.csv.

<img src="../../macro/introduction.files/introduction3313.png" width="26" /> **Compiler (Compile)** : compile le code source du script courant et vérifie les erreurs de syntaxe.

<img src="../../macro/introduction.files/introduction3544.png" width="26" /> **Réduit/affiche la fenêtre de réglages et de sortie.**

<img src="../../macro/introduction.files/introduction3740.png" width="22" /> **Aide (Help)** : affiche le fichier d'aide.

**&lt;3&gt; Fenêtre de réglages et de sortie :** on y règle les variables et elle affiche les informations de compilation.

**Page « Variables » (Variable Setting) :** cliquez sur la case « Nouveau » de cette page pour ouvrir la boîte « Nouvelles variables de script », comme sur la figure 5.6. La variable est associée à un registre.

  <img src="../../macro/introduction.files/introduction4182.png" width="500" />

Figure 5-5 Nouvelles variables de script

**Page « Sortie de compilation » (Compile information output) :** affiche les informations de compilation et d'édition de liens du programme. L'utilisateur peut déboguer et corriger d'après ces messages.

<img src="../../macro/introduction.files/introduction4565.png" width="773" />

Figure 5-6 Sortie de compilation
