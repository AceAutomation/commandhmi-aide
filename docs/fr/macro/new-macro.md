# Créer un script

Cliquez sur le bouton <img src="../../macro/new-macro.files/new-macro12.png" width="25" /> pour créer un script dans la liste « Non enregistrés », comme sur la figure 5-4 (Compilateur de scripts)

<img src="../../macro/new-macro.files/new-macro112.png" width="1086" />

Figure 5-4 (Compilateur de scripts)

**Instructions :**

**Instruction 1 : conventions de compilation des programmes**

Écrivez dans la fenêtre d'édition un programme source en langage C conforme à la norme ANSI C.

**Instruction 2 : fenêtre de sortie**

Cette fenêtre affiche les informations de compilation et d'édition de liens du programme. L'utilisateur peut déboguer et corriger d'après ces messages.

**Instruction 3 : réglage des variables**

Nom de variable : saisissez le nom de variable utilisé dans le programme.

Type de données : choisissez le type de la variable, qui détermine la taille mémoire réservée.

Octets : taille mémoire de la variable, définie automatiquement selon le type.

Lecture/écriture : droits de lecture/écriture de la variable dans la mémoire de l'écran tactile.

Adresse : adresse mémoire physique de la variable dans l'écran tactile.

Rôle du réglage des variables : lorsque l'extérieur doit interagir avec l'écran tactile (échange ou acquisition de données), il fournit l'interface qui modifie dynamiquement le comportement de l'écran tactile.

Conseil : les variables utilisées dans le programme doivent être placées dans la partie déclaration des variables (au début du code).
