# Insérer une fonction de bibliothèque dans le programme

Cliquez sur le bouton « Fonction » : la boîte de dialogue de la figure 5-5 s'ouvre. Choisissez la fonction de bibliothèque dans la liste et cliquez sur « Confirmer » : la fonction est insérée à la position du curseur dans la fenêtre d'édition.

Pour les fonctions, types de paramètres et autres détails des fonctions de bibliothèque, voir l'annexe 1.
