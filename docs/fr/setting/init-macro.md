# Script d'initialisation

Définit un script compilé avec succès comme script d'initialisation : il est exécuté une seule fois, indépendamment des écrans. On peut ajouter jusqu'à 64 scripts d'initialisation, exécutés dans l'ordre défini.

Cliquez sur « Script d'initialisation » dans le menu « Paramètres » : la boîte de dialogue s'ouvre :

<img src="../../setting/init-macro.files/init-macro309.png" width="436" />

Cliquez sur la liste pour afficher tous les scripts compilés avec succès. Le script choisi est exécuté comme script d'initialisation au lancement du projet.
