# Réglages d'utilisation

Réglages d'utilisation de la configuration :

<img src="../../setting/the_operation_setting.files/image002.jpg" width="360" alt="ScreenShot00056.jpg" />

• mode de sélection

sélection partielle : un objet est sélectionné dès que le rectangle de sélection en couvre une partie

sélection complète : un objet n'est sélectionné que si le rectangle de sélection le contient entièrement

•  mode de collage

collage au clic : après copie, l'objet est collé à l'endroit où l'utilisateur clique

collage à la même position : après copie, l'objet est collé près de l'emplacement de l'objet copié

•  type de fichier de clé USB généré

6.Version 0 : génère un fichier de clé USB version 6.0

supérieure à 6.0 : génère un fichier de clé USB de version supérieure à 6.0
