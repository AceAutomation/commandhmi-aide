# Réglages des alarmes

Les alarmes de CommandHMI comprennent les alarmes numériques et les alarmes analogiques. Une fois les alarmes définies, l'objet « Alarmes » ou le bandeau d'alarmes affiche le type d'alarme et l'heure d'apparition.
