# Chiffrement du fichier

Indique si un mot de passe est nécessaire pour ouvrir le fichier de projet.

Double-cliquez sur l'option « Chiffrement du fichier » dans le gestionnaire de projet : la boîte de la figure 7-12 s'ouvre :

<img src="../../setting/file-protect.files/image004.jpg" width="286" />

Figure 7-12    Boîte de chiffrement du fichier

Cochez « Protéger le fichier par mot de passe » dans cette boîte ; saisissez le mot de passe et sa confirmation ; cliquez sur « OK ».

À la réouverture du projet, une boîte de saisie du mot de passe s'affiche, comme sur la figure 7-13 :

<img src="../../setting/file-protect.files/image002.jpg" width="331" alt="ScreenShot00055.jpg" />

Figure 7-13    Boîte de saisie du mot de passe

Il faut saisir le mot de passe pour ouvrir le projet.
