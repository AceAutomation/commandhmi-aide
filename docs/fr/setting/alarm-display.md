# Objets d'affichage des alarmes

Une fois les alarmes réglées, on peut ajouter les objets d'affichage : affichage des alarmes, bandeau d'alarmes et affichage des alarmes historiques.

Choisissez <img src="../../setting/alarm-display.files/alarm-display120.png" width="31" /> dans la barre d'outils pour régler les paramètres du bandeau d'alarmes dans la boîte de dialogue, comme sur la figure 7-30 :

<img src="../../setting/alarm-display.files/alarm-display225.png" width="675" />

Figure 7-30 Boîte de dialogue du bandeau d'alarmes

• Vitesse : vitesse de défilement des alarmes ;

• Direction : le bandeau défile de droite à gauche ou de gauche à droite ;

• Tri des alarmes : ordre d'affichage chronologique ou antichronologique.

Choisissez l'objet « Alarmes » dans la barre d'outils pour régler le texte et les paramètres d'affichage dans la boîte de dialogue, comme sur la figure 7-31 :

<img src="../../setting/alarm-display.files/alarm-display615.png" width="634" />

Figure 7-31 Boîte de dialogue de l'affichage des alarmes
