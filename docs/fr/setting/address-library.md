# Bibliothèque d'adresses

La bibliothèque d'adresses permet de donner un alias à un registre : l'utilisateur accède à la variable soit par l'étiquette d'adresse, soit par l'adresse du registre.

Utilisation de la bibliothèque d'adresses :

<img src="../../setting/addresslibrary.files/image002.jpg" width="270" alt="ScreenShot00776.jpg" />

Ø  Définir une étiquette d'adresse

Double-cliquez sur l'option « Bibliothèque d'adresses » : la boîte de dialogue suivante s'ouvre

Cliquez sur le bouton « Nouveau » : la boîte de dialogue suivante s'ouvre

Description : description de l'étiquette d'adresse ajoutée, pour retrouver facilement l'information et l'usage de la variable

Commande : l'étiquette d'adresse personnalisée revient à donner un alias au registre ; on choisit ensuite cet alias dans la saisie d'adresse pour utiliser le registre

Type d'adresse : type de données de l'alias ; deux choix seulement

Adresse : adresse du registre associé à l'étiquette

Nombre d'adresses : permet d'ajouter des étiquettes en série ; une étiquette ne porte que sur une seule variable, pas sur un tableau

Ø  Utiliser une étiquette d'adresse

Dans la saisie d'adresse de l'objet, choisissez la bibliothèque d'étiquettes d'adresse, puis l'étiquette voulue ; un clic sur « Bibliothèque d'adresses » affiche toutes les étiquettes définies par l'utilisateur.

Téléchargez dans l'écran tactile ou utilisez la simulation en ligne pour vérifier le fonctionnement ; dans cet exemple en simulation en ligne, la saisie de 40 modifie la valeur du registre lw0

Les étiquettes d'adresse permettent de donner un nom parlant aux registres les plus utilisés et de s'en servir dans le projet : la saisie des adresses est moins fastidieuse et la configuration plus rapide
