# Écran

Créer un écran, comme sur la figure 7-17 :

<img src="../../setting/screen-setting.files/image001.jpg" width="275" alt="ScreenShot00059.jpg" />

Figure 7-17    Menu contextuel des écrans

• Faites un clic droit sur « Écran » dans le gestionnaire de projet, puis choisissez « Ajouter un écran ». Dans la boîte qui s'ouvre, réglez les propriétés comme le « Nom de l'écran » ; cliquez sur « OK ».

• Deux façons d'ouvrir d'autres écrans : double-cliquez sur le nom de l'écran dans le gestionnaire de projet, ou faites un clic droit sur le nom et choisissez « Ouvrir ».

• Supprimer : clic droit sur le nom de l'écran, puis « Supprimer ».

• Propriétés : clic droit sur le nom de l'écran, puis « Propriétés » ; ou choisissez « Propriétés de l'écran » dans la barre de menus.

• Copier : clic droit sur le nom de l'écran, puis « Copier » ; indiquez le nom du nouvel écran et cliquez sur OK.
