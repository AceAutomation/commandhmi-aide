# Alarmes discrètes

Dans les options d'alarme, double-cliquez sur « Nouvelle alarme discrète » pour ouvrir la boîte de réglage des alarmes discrètes

<img src="../../setting/lisanbaojing.files/image001.jpg" width="766" />

• Nouveau : nouvelle alarme ; la catégorie de données se choisit librement

<img src="../../setting/lisanbaojing.files/image002.jpg" width="178" />

• Supprimer : supprime une alarme

• Supprimer tout : supprime toutes les alarmes

• Exporter : exporte les alarmes définies

• Importer : importe des alarmes

Écran de réglage d'une nouvelle alarme :

• Catégorie de données : choisissez la catégorie adaptée, qui détermine les conditions d'alarme

• Adresse : adresse à surveiller pour l'alarme

• Nombre consécutif : indique s'il faut surveiller N adresses consécutives

• Texte d'alarme : message affiché quand la valeur de l'adresse remplit la condition d'alarme

• Condition d'alarme : condition d'alarme sur la valeur de l'adresse ; conditions possibles :

<img src="../../setting/lisanbaojing.files/image004.jpg" width="179" /><img src="../../setting/lisanbaojing.files/image005.jpg" width="184" />

• L alarme bit ON : catégorie bool, l'alarme se déclenche quand l'adresse est à ON

• L alarme bit OFF : catégorie bool, l'alarme se déclenche quand l'adresse est à OFF

• L alarme sur valeur fixe : l'alarme se déclenche quand l'adresse vaut la valeur réglée

• L alarme dans plage : l'alarme se déclenche quand la valeur de l'adresse est dans la plage réglée

• L alarme hors plage : l'alarme se déclenche quand la valeur de l'adresse est hors de la plage réglée

• Couleur d'alarme : couleur du message quand l'alarme est déclenchée
