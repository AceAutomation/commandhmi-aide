# Langue

Langue : cette fonction permet le multilingue ; les polices des langues utilisées dans le projet doivent être installées sur le PC.

Double-cliquez sur l'option « Langue », ou faites un clic droit, pour ouvrir la boîte de réglage des langues.

<img src="../../setting/language.files/language675.png" width="277" />

Nombre de langues : nombre total de langues du système, cinquante au maximum.

Nom de la langue : nom de chaque langue.

Exemple :

1\. Comme ci-dessus, réglez le nombre de langues sur 3, en gardant les noms par défaut ; créez un objet avec texte, par exemple un bouton d'écran : choisissez Langue 1 dans la liste des langues et saisissez « lang1 » dans la zone de texte, puis réglez la taille, la couleur de la police, etc. ; choisissez Langue 2 et saisissez « lang2 » ; choisissez Langue 3 et saisissez « lang3 », comme ci-dessous :

<img src="../../setting/language.files/language1423.png" width="661" />

2\. Cliquez sur « OK », puis, quand le curseur prend la forme d'une croix, cliquez dans l'écran pour placer le bouton ; ajustez sa taille. L'option « Fonction » de l'onglet « Général » est la même pour chaque bouton : « Changer de langue » ; seule l'option « Langue » diffère : Langue 1, Langue 2 et Langue 3.

<img src="../../setting/language.files/language2086.png" width="662" />

<img src="../../setting/language.files/language2238.png" width="663" />

3\. Enregistrez le projet, comme ci-dessous :

<img src="../../setting/language.files/image001.jpg" width="896" />

4\. Simulez (ou téléchargez dans l'IHM)

Un appui sur le bouton de fonction 1, 2 ou 3 affiche tous les objets avec texte dans la langue correspondante.

Pour un projet entièrement multilingue, il faut saisir les textes de chaque langue pour chaque objet avec texte (comme au point 1). Tout le projet passe alors dans la langue choisie lors de la commande « Changer de langue ».
