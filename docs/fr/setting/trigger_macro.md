# Script déclenché

Définit un script compilé avec succès comme script déclenché : il est exécuté quand la condition indiquée se produit. Conditions possibles : changement d'écran/fenêtre ou changement de valeur d'une adresse.

Cliquez sur « Script déclenché » dans le menu « Paramètres » : la boîte de dialogue s'ouvre :

<img src="../../setting/trigger_script.files/trigger_script764.png" width="663" />

Figure7-45 Boîte des scripts déclenchés

Cliquez sur le bouton « Nouveau » pour ouvrir une nouvelle boîte, puis choisissez le script à exécuter quand la condition se produit.

Deux modes de déclenchement : par adresse et par écran.

Déclenchement par adresse : indiquez une adresse de bit et un mode : OFF-&gt;ON, ON-&gt;OFF, OFF&lt;-&gt;ON, ou exécution immédiate tant que l'état est ON.

Déclenchement par écran : indiquez le nom d'un écran et un mode : ouverture ou fermeture de l'écran.
