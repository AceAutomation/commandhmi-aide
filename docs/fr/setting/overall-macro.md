# Script global

Définit un script compilé avec succès comme script global : il est exécuté dès le lancement du projet, puis pendant tout le fonctionnement, indépendamment des écrans. On peut ajouter jusqu'à 64 scripts globaux, exécutés dans l'ordre défini.

Cliquez sur « Script global » dans le menu « Paramètres » : la boîte de dialogue s'ouvre :

<img src="../../setting/overall-macro.files/overall-macro384.png" width="437" />

Cliquez sur la liste pour afficher tous les scripts compilés avec succès, puis indiquez si le script est commandé par un bit et sa fréquence d'exécution. Le script choisi est exécuté comme script global pendant le fonctionnement.
