# Transfert de données

**Fonction de transfert de données :**

1、Le transfert de données permet d'échanger des données entre des équipements reliés à deux ports de l'IHM.

Exemple :

Port 1 en protocole Modbus RTU Slave : l'IHM est esclave ; l'équipement 1, maître, lit l'adresse LW0 de l'IHM.

Port 2 en protocole Modbus RTU Master : l'IHM lit l'adresse 4x11 de la station esclave 2.
