# État de l'IHM

Le réglage d'état de l'IHM écrit les informations d'état courantes de l'IHM dans les registres de l'automate.

Double-cliquez sur « État de l'IHM » dans le gestionnaire de projet : la boîte de la figure 7-7 s'ouvre :

<img src="../../setting/status.files/status215.png" width="334" />

Figure 7-7      Réglage de l'état de l'IHM

• N° d'écran courant : écrit le numéro de l'écran courant de l'IHM dans l'automate.

• N° de recette courante : écrit le numéro de la recette courante dans l'automate.

• Niveau utilisateur courant : écrit le niveau utilisateur courant dans l'automate.

• Langue courante : écrit le numéro de la langue utilisée dans l'automate

Cliquez sur « OK » pour terminer le réglage.
