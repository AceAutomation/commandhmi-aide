# Table des variables

Associe une étiquette à une adresse : utiliser l'étiquette revient à utiliser l'adresse correspondante. Pour régler les variables, double-cliquez sur « Table des variables » dans le gestionnaire de projet : la boîte de la figure 7-15 s'ouvre :

<img src="../../setting/variblesetting.files/variblesetting735.png" width="614" />

Figure 7-15    Boîte de la table des variables

• Nouveau : ajoute une étiquette ; 1000 au maximum

• Supprimer : supprime l'étiquette sélectionnée.

• Modifier : modifie l'étiquette sélectionnée (ou double-cliquez dessus).

• Supprimer tout : supprime toutes les étiquettes.

• Importer : ouvre une boîte d'ouverture pour importer un fichier de table des variables.

• Exporter : ouvre une boîte « Enregistrer sous » pour exporter la table des variables courante.

<img src="../../setting/variblesetting.files/variblesetting1256.png" width="277" />

Figure 7-16    Boîte de création d'une variable

• Nom de variable : nom de la nouvelle variable.

• Type d'adresse : type de données de l'adresse.

• Adresse : adresse associée.
