# Bibliothèque de textes

La bibliothèque de textes regroupe des textes communs, pour éviter de ressaisir les mêmes textes.

<img src="../../setting/textlibrary.files/image009.jpg" width="826" alt="ScreenShot00769.jpg" />

Présentation rapide de son utilisation.

1.      Créer les données de la bibliothèque de textes

<img src="../../setting/textlibrary.files/image010.jpg" width="315" alt="ScreenShot00768.jpg" />

Créez les données de la bibliothèque de textes et réglez le nombre d'états

<img src="../../setting/textlibrary.files/image011.jpg" width="826" alt="ScreenShot00770.jpg" />

Double-cliquez sur la zone de saisie de chaque langue pour saisir les textes

2.      Utiliser la bibliothèque de textes dans un objet

Exemple avec un interrupteur : cochez « Bibliothèque de textes », choisissez la langue puis le texte voulu

<img src="../../setting/textlibrary.files/image012.jpg" width="675" alt="ScreenShot00771.jpg" />

<img src="../../setting/textlibrary.files/image014.jpg" width="675" alt="ScreenShot00773.jpg" />

3.      Plusieurs textes de la bibliothèque pour une même variable

     Quand l'objet a plusieurs états, le texte de la bibliothèque change automatiquement selon l'état : par exemple, quand l'interrupteur passe à ON, le texte de l'état 1 s'affiche automatiquement
