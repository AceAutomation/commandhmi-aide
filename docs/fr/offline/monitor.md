# Simulation hors ligne

La simulation hors ligne de CommandHMI permet de vérifier le projet avant de le transférer dans l'IHM et de relier l'IHM aux équipements.

**Procédure :**

Enregistrez le projet courant et lancez la commande de simulation hors ligne : une fenêtre de simulation s'ouvre, dans laquelle on utilise le projet à la souris au lieu de toucher l'IHM, pour une partie des fonctions de l'IHM, comme sur la figure 6-1 :

<img src="../../offline/monitor.files/image002.jpg" width="640" />

Figure 6-1 Simulation hors ligne d'un HM-070BE

Dans la fenêtre de simulation, un clic droit affiche le menu suivant :

<img src="../../offline/monitor.files/image003.gif" width="80" />

• Quitter (Exit) : ferme la fenêtre de simulation hors ligne ; la touche Échap du clavier permet aussi de quitter.

• À propos (About) : boîte « À propos ».

<img src="../../offline/monitor.files/image004.jpg" width="130" />

On peut aussi fermer la simulation hors ligne depuis la barre des tâches : clic droit, « Fermer ».

**Exemple de simulation hors ligne**

Comme sur la figure 6-2, le projet édité peut être simulé hors ligne pour repérer les erreurs dans les écrans, par exemple une adresse de surveillance incorrecte. Une précaution utile.

<img src="../../offline/monitor.files/image005.jpg" width="640" />

Figure 6-2 Exemple de simulation hors ligne d'un HM-070BE

**Étapes de la simulation hors ligne :**

Installez d'abord le logiciel CommandHMI ;

Exécutez CommandHMI en tant qu'administrateur.

<img src="../../offline/monitor.files/image004.jpg" width="130" />

Remarque : en simulation hors ligne, seules ces fonctions du bouton de fonction sont disponibles : « Recette précédente », « Recette suivante », « Enregistrer la recette courante », « Changer de niveau utilisateur », « Déconnexion » et « Son tactile ON / OFF ». Les alarmes historiques, l'affichage des données historiques, les courbes de tendance historiques, le temporisateur et les scripts de la barre d'outils ne peuvent pas être simulés.

Les autres objets fonctionnent de la même façon. Après avoir réglé les propriétés de chaque objet, cliquez sur « Enregistrer », puis choisissez la simulation hors ligne, comme sur la figure 6-3 :
