# Créer un écran

La commande « Nouvel écran » crée un écran dans le projet courant. Procédure :

1\. Choisissez la commande « Nouvel écran » dans le menu Écran, cliquez sur le bouton <img src="../../../configuration-guide/screen/new-screen.files/new-screen210.png" width="39" />, ou faites un clic droit sur Écran dans le gestionnaire de projet et choisissez « Ajouter un écran », comme sur la figure 4-1 ci-dessous :

<img src="../../../configuration-guide/screen/new-screen.files/new-screen328.png" width="260" />

Figure 4-1 Nouvel écran

2\. Dans la boîte « Nouvel écran », définissez le nom et la couleur de fond du nouvel écran, puis cliquez sur OK. Par défaut, le nom est le numéro de l'écran et la couleur de fond est bleue, comme sur la figure 4-2 :

<img src="../../../configuration-guide/screen/new-screen.files/new-screen581.png" width="517" />

Figure 4-2 Boîte de dialogue Ajouter un écran

Standard : écran standard

Commun : écran réutilisable plusieurs fois ; les propriétés de ses objets ne se modifient que dans cet écran

Utiliser l'écran commun : utilise un écran commun existant, sans pouvoir modifier les propriétés de ses objets

La couleur de fond, la couleur de premier plan et le motif du nouvel écran sont réglables.

Image : une image peut servir de fond au nouvel écran.
