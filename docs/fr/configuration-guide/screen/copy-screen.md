# Copier un écran

Cette commande copie un écran du projet courant ; procédure :

Dans le gestionnaire de projet, cliquez avec le bouton gauche sur l'écran à copier, puis faites un clic droit et choisissez « Copier », puis à nouveau un clic droit et « Coller » (figure 4-5).

Un nouvel écran est créé, copie de l'écran choisi.
