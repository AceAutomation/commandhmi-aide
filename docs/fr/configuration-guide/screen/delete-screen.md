# Supprimer un écran

Cette commande supprime un écran du projet courant ; procédure :

Choisissez « Supprimer l'écran » dans le menu Écran ; ou sélectionnez l'écran à supprimer dans le gestionnaire de projet, faites un clic droit et choisissez « Supprimer » ; ou, sans aucun objet sélectionné, faites un clic droit dans une zone vide de l'écran pour ouvrir le menu contextuel qui contient la commande « Supprimer ».

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen407.png" width="382" />

Figure 4-4 Supprimer un écran

Cliquez sur OK pour confirmer la suppression.

<img src="../../../configuration-guide/screen/delete-screen.files/delete-screen483.png" width="130" />

Un écran supprimé ne peut pas être récupéré ! Utilisez cette commande avec prudence.
