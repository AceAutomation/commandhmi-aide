# Modifier les propriétés d'un écran

Pour modifier les propriétés d'un écran, comme son nom ou sa couleur de fond :

Sans aucun objet sélectionné (cliquez dans une zone vide de l'écran courant), choisissez la commande <img src="../../../configuration-guide/screen/edit-screen.files/edit-screen760.png" width="26" /> de la barre d'outils, ou sélectionnez l'écran dans le gestionnaire de projet et faites un clic droit, ou faites un clic droit dans l'écran pour ouvrir le menu contextuel qui contient la commande « Propriétés ».

<img src="../../../configuration-guide/screen/edit-screen.files/edit-screen1019.png" width="522" />

Figure 4-3      Propriétés de l'écran

 Dans la boîte « Nouvel écran », définissez le nom, la couleur de fond et le réglage d'écran commun, puis cliquez sur OK. Par défaut, le nom d'un nouvel écran est son numéro.

Par défaut : couleur de fond, couleur de premier plan et style de l'écran.

Image : une image peut servir de fond.

Réglage de l'écran commun

Écran standard : crée un écran standard.

Définir comme écran commun : crée un écran commun dont les objets peuvent être utilisés dans d'autres écrans, mais dont les propriétés ne se modifient que dans cet écran.

Utiliser l'écran commun : utilise un écran commun existant, sans pouvoir modifier les propriétés de ses objets.
