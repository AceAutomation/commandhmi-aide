# Affichage des recettes

L'affichage des recettes liste les données de toutes les recettes définies. Son icône dans la barre d'outils est<img src="../../../configuration-guide/new_add_control/recipedisplay.files/recipedisplay150.png" width="31" />. Cliquez dessus pour ouvrir la boîte de dialogue suivante :

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image001.jpg" width="481" alt="ScreenShot00674.jpg" />

Figure 4-129   Page Général de l'affichage des recettes

La page Général comporte les réglages du texte et des propriétés de la liste.

Page Données, comme ci-dessous

<img src="../../../configuration-guide/new_add_control/recipedisplay.files/image002.jpg" width="481" alt="ScreenShot00675.jpg" />

Figure 4-130   Page Données de l'affichage des recettes

• Langue : choisissez une langue pour lister les noms de recettes dans cette langue.

• Nom : liste de tous les noms de recettes

• Affichage : affiche ou non chaque recette, selon les besoins.

• TOUT : coche toutes les recettes dans Affichage.
