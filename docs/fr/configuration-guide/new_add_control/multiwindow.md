# Multi-fenêtres

L'objet Multi-fenêtres fournit une zone rectangulaire où s'affiche la fenêtre désignée.

 Cliquez sur l'icône <img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow619.png" width="54" /> dans la boîte à outils : la boîte de dialogue Multi-fenêtres s'ouvre, comme sur la figure 4-136.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow881.png" width="662" />

Figure 4-136 Boîte de dialogue Multi-fenêtres

• Type de données : type de la donnée qui commande la fenêtre affichée, bool ou mot.

« bool » : la fenêtre désignée s'ouvre dans la zone quand la condition est remplie.

« Mot » : choisissez l'adresse de contrôle et cochez « Lié à la fenêtre » ou « Non lié à la fenêtre », comme sur la figure 4-138.

• Adresse : sa valeur commande l'ouverture de la fenêtre ;

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1265.png" width="664" />

Figure 4-138 Boîte de dialogue Multi-fenêtres

« Lié à la fenêtre » : la valeur de l'adresse est le numéro de la fenêtre affichée.

« Non lié à la fenêtre » : cochez une fonction ; quand sa condition est remplie, la fenêtre désignée s'ouvre. Les fonctions sont les suivantes.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1507.png" width="349" />

Figure 4-139

<span id="OLE_LINK677"></span><span id="OLE_LINK676"></span>      Pour la page « Visibilité », voir le « Bouton de bit ».

Après avoir réglé les paramètres, cliquez sur « OK » et tracez un rectangle à la souris dans la zone de l'écran. Cette zone affichera la fenêtre, comme sur la figure 4-140.

<img src="../../../configuration-guide/new_add_control/multiwindow.files/multiwindow1958.png" width="307" />

Figure 4-140
