# Curseur

Curseur analogique : faites glisser le curseur pour modifier la valeur du registre de mot associé.

Sélectionnez l'icône <img src="../../../configuration-guide/new_add_control/sliderbutton.files/sliderbutton144.png" width="43" /> dans la barre d'outils : la boîte de propriétés du « Curseur » s'ouvre, comme sur la figure 4-117 :

<img src="../../../configuration-guide/new_add_control/sliderbutton.files/sliderbutton241.png" width="726" />

Figure 4-117 Boîte de dialogue Curseur

• Position de l'échelle : position de l'échelle graduée.

• Sens de l'échelle : sens de l'échelle graduée.

• Adresse d'écriture : quand le curseur est déplacé, la valeur est écrite et affichée en temps réel.

• Plage dynamique : commande le curseur par une adresse de mot. Si la case n'est pas cochée, le maximum et le minimum sont définis selon le type de données et modifiables librement : la course du curseur correspond alors à ces valeurs. Si la case est cochée, le maximum et le minimum sont lus dans des adresses de mot et commandés par ces adresses.

Pour la page Échelle, voir l'« Indicateur à aiguille ».

Pour les pages « Avancé » et « Visibilité », voir le « Bouton de bit ».
