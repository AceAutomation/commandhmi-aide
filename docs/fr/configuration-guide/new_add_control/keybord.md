# Clavier

**1. Clavier :** cet objet sert à créer un clavier personnalisé, composé de chacune de ses touches. Son icône dans la barre d'outils est :<img src="../../../configuration-guide/new_add_control/keybord.files/image002.jpg" width="31" /> ; cliquez dessus pour ouvrir la boîte de dialogue de la figure 4-123.

Figure 4-123   Page Général du clavier

• État : cliquez sur « Avant » et « Après » pour régler la couleur de bordure, de premier plan, de fond et le motif de chaque état.

• ENTER : touche de fonction qui valide la saisie

• BACKSPACE : touche de fonction qui efface le caractère précédent

• CLEAR : touche de fonction qui efface toute la saisie

• ESC : touche de fonction qui ferme le clavier sans rien saisir

• ASCII : valeur saisie par la touche

Pour la page « Visibilité », voir le « Bouton de bit ».

**2. Ajouter un clavier personnalisé**

Lancez l'assistant d'ajout de clavier avec Ajouter un clavier personnalisé dans le menu Paramètres. Cet assistant permet d'ajouter rapidement un clavier prédéfini, comme ci-dessous :

<img src="../../../configuration-guide/new_add_control/keybord.files/image004.jpg" width="487" />

Figure 4-124   Page 1 de l'assistant de clavier personnalisé

Cliquez sur Suivant : une page de choix du type de clavier s'affiche, comme ci-dessous :

<img src="../../../configuration-guide/new_add_control/keybord.files/image005.jpg" width="487" />

Figure 4-125   Page 2 de l'assistant de clavier personnalisé

Après avoir choisi le type de clavier, cliquez sur Suivant pour charger le clavier prédéfini. Neuf claviers prédéfinis sont disponibles ; ajoutez ceux dont vous avez besoin, jusqu'à 32, comme sur la figure 4-126

<img src="../../../configuration-guide/new_add_control/keybord.files/image006.jpg" width="487" />

Figure 4-126   Page 3 de l'assistant de clavier personnalisé

Cliquez sur OK pour ajouter le clavier choisi au projet.
