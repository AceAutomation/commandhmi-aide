# Barre de défilement

La barre de défilement permet de parcourir les données des objets de type tableau, pour consulter rapidement leurs données. Seuls les objets suivants sont pris en charge : affichage des alarmes, affichage de l'historique des alarmes, affichage des recettes, affichage des données historiques, journal des opérations

Elle sert lorsque l'objet associé a trop de données pour les afficher en une fois : elle permet d'afficher le reste des données

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image004.jpg" width="859" alt="ScreenShot00819.jpg" />

Boîte de dialogue Barre de défilement

Les fonctions de l'objet sont détaillées ci-dessous (il existe deux types : boutons de défilement et barre de défilement)

Ø  Barre de défilement : fait défiler les données du tableau au moyen d'une barre

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image005.jpg" width="859" alt="ScreenShot00820.jpg" />

l  Couleur de fond : couleur de fond de l'objet

l  Couleur des symboles : couleur des symboles de l'objet

l  Direction : sens de défilement des données du tableau

n  Horizontal : défilement horizontal des données

n  Vertical : défilement vertical des données

l  Numéro de l'objet associé : si l'écran courant contient l'un des objets cités plus haut, on peut l'associer à la barre. S'il n'en contient aucun, un message d'erreur s'affiche : « l'objet associé ne peut pas être vide ». Le numéro de l'objet est celui affiché en haut à gauche de l'objet.

Ø  Boutons de défilement : font défiler les données du tableau au moyen de boutons

<img src="../../../configuration-guide/new_add_control/scrollbar.files/image006.jpg" width="859" alt="ScreenShot00821.jpg" />

l Couleur de bordure : couleur de bordure de l'objet

l  Couleur de fond : couleur de fond de l'objet

l  Couleur des symboles : couleur des symboles de l'objet

l  direction

n  Horizontal : défilement horizontal des données

n  Vertical : défilement vertical des données

l  Numéro de l'objet associé : voir la description précédente

l Touches de fonction

n  Espacement : espacement entre les boutons

n  Début / fin : place les données au début ou à la fin ; si les données y sont déjà, un appui affiche un message indiquant que l'opération est sans effet

n  Page précédente / suivante (ou gauche / droite) : déplace d'une page à chaque appui

n  Haut / bas (ou gauche / droite) : déplace d'une donnée à chaque appui dans la direction correspondante

n  Pause : si les données du tableau changent, un appui fige l'affichage, un second appui le rétablit. Si l'affichage est déjà figé, un message indique que la fonction est sans effet. Exemple avec l'affichage des données historiques et des boutons de défilement
