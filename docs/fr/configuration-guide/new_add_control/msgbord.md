# Tableau d'écriture

Tableau d'écriture : objet sur lequel l'utilisateur peut écrire. Son icône dans la barre d'outils est : <img src="../../../configuration-guide/new_add_control/msgbord.files/image002.jpg" width="26" />. Cliquez dessus pour ouvrir la boîte de dialogue de la figure 4-121.

Figure 4-121   Page Général du tableau d'écriture

• Couleur du trait : couleur de l'écriture sur l'objet

• Épaisseur du trait : épaisseur du trait d'écriture

• Mode de fonctionnement :

Adresse du mode de fonctionnement : adresse de mot, valide seulement si elle vaut 0 ou 1. 0 indique l'écriture, 1 l'effacement.

Cette adresse de mot occupe 3 adresses consécutives : la première commande le mode (0 écriture, 1 effacement), la deuxième l'épaisseur du trait, la troisième la couleur RVB du pinceau.

• Effacer l'écran

Adresse d'effacement : quand sa valeur est égale à l'état d'effacement défini (0 ou 1), tout ce qui est écrit sur l'objet est effacé automatiquement

Pour la page « Visibilité », voir le « Bouton de bit ».
