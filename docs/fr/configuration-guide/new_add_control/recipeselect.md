# Sélecteur de recette

Le sélecteur de recette liste tous les noms de recettes créées. Sélectionner un nom dans la liste écrit le numéro de la recette dans le registre de numéro de recette RWI0. Inversement, si la valeur de RWI0 change, le sélecteur pointe sur le nom de recette correspondant. Son icône dans la barre d'outils est : <img src="../../../configuration-guide/new_add_control/recipeselect.files/recipeselect411.png" width="28" /> ; cliquez dessus pour ouvrir la boîte de dialogue ci-dessous :

• Style d'affichage

Style d'affichage du sélecteur de recette

Liste : le sélecteur s'affiche sous forme de liste.

Liste déroulante : le sélecteur s'affiche sous forme de liste déroulante.

• Police, Taille de police, Couleur du texte et Couleur de fond : propriétés de la liste et du texte

• Lignes : option disponible uniquement avec le style « Liste ».
