# Tri automatique

La commande « Tri automatique » s'applique aux écrans du projet courant. Procédure :

La commande de tri automatique trie les numéros des écrans du projet. Procédure :

Dans le gestionnaire de projet, cliquez avec le bouton gauche sur l'option Écrans, puis choisissez « Tri automatique » dans le menu contextuel : une fenêtre de réglage s'affiche ; cochez le tri automatique et cliquez sur OK pour trier les écrans (par ordre croissant).
