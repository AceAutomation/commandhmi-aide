# Secteur

Choisissez la commande Secteur dans le menu Dessin ou cliquez sur le bouton Secteur <img src="../../../configuration-guide/basic-graph/arcbase.files/image002.jpg" width="30" /> dans la barre d'outils ; dans la fenêtre d'édition de l'écran, le curseur prend la forme d'une croix : vous pouvez alors dessiner un secteur. Voir la figure 4-35 :

<img src="../../../configuration-guide/basic-graph/arcbase.files/image003.gif" width="143" />

Figure 4-35   Dessin d'un secteur

Placez la souris sur l'un des points verts au milieu du rectangle : le curseur change de forme ; déplacez la souris pour modifier l'arc du secteur.
