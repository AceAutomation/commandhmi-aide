# Ligne

Choisissez la commande « Ligne » dans le menu Dessin ou cliquez sur le bouton Ligne <img src="../../../configuration-guide/basic-graph/line.files/line74.png" width="30" /> dans la barre d'outils ; dans la fenêtre d'édition, le curseur prend la forme d'une croix ; cliquez dans la vue (l'écran) pour ajouter une ligne.

La transparence, le type, l'épaisseur, la couleur, la flèche et la forme d'extrémité de la ligne sont alors réglés par défaut ; vous pouvez les modifier selon les besoins du projet. Double-cliquez sur la ligne, ou sélectionnez-la puis cliquez sur le bouton Propriétés<img src="../../../configuration-guide/basic-graph/line.files/line516.png" width="30" /> de la barre d'outils. La boîte Propriétés de ligne s'ouvre, comme sur la figure 4-24 :

<img src="../../../configuration-guide/basic-graph/line.files/line615.png" width="399" />

Figure 4-24 Boîte de dialogue Propriétés de ligne

Le logiciel CommandHMI propose jusqu'à 6 types de trait, 30 épaisseurs et 6 flèches d'extrémité, réglables avec les listes déroulantes et les boutons de réglage fin. Pour modifier la longueur, la direction ou la position de la ligne, sélectionnez-la, placez la souris sur une extrémité, maintenez le bouton gauche enfoncé, faites glisser jusqu'à la position voulue puis relâchez.
