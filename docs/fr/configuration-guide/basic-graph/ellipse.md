# Cercle/Ellipse

Choisissez la commande <span id="OLE_LINK451"></span><span id="OLE_LINK452"></span>Cercle/Ellipse dans le menu Dessin ou cliquez sur le bouton Cercle/Ellipse<img src="../../../configuration-guide/basic-graph/ellipse.files/image002.jpg" width="36" /> dans la barre d'outils. Dans la fenêtre d'édition de l'écran, le curseur prend la forme d'une croix ; cliquez avec le bouton gauche pour ajouter un cercle à l'écran.

<img src="../../../configuration-guide/basic-graph/ellipse.files/image004.jpg" width="23" /> : modifie la hauteur de l'ellipse / du cercle

 <img src="../../../configuration-guide/basic-graph/ellipse.files/image005.jpg" width="21" /> : modifie la largeur et la hauteur de l'ellipse / du cercle

La transparence, le type, l'épaisseur et la couleur du trait ainsi que le motif de remplissage de l'ellipse / du cercle sont alors réglés par défaut. Vous pouvez modifier ces attributs selon les besoins du projet : double-cliquez sur l'ellipse / le cercle, ou sélectionnez-le puis cliquez sur le bouton Propriétés <img src="../../../configuration-guide/basic-graph/ellipse.files/image006.jpg" width="30" /> de la barre d'outils ; une boîte de dialogue s'ouvre.

Le logiciel CommandHMI propose jusqu'à 15 types de traits de bordure, 10 épaisseurs de trait et 21 motifs de remplissage pour l'ellipse / le cercle. Voir la figure 4-32 :
