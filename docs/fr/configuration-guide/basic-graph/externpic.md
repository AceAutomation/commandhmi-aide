# Image externe

Dans CommandHMI, des images peuvent être insérées dans de nombreux objets ; prenons l'exemple de l'image statique :

<img src="../../../configuration-guide/basic-graph/externpic.files/image002.gif" width="675" />

Image :

Bibliothèque : bibliothèque intégrée au système, comme ci-dessous :

<img src="../../../configuration-guide/basic-graph/externpic.files/image003.gif" width="732" />

Fichier : fichier externe ou fichier système. Les images externes sont celles de l'ordinateur ; les images système sont téléchargeables sur le site officiel et enregistrées dans le dossier Extern_Pic du répertoire d'installation.

Avec « Système », la boîte de dialogue suivante s'ouvre :

<img src="../../../configuration-guide/basic-graph/externpic.files/image004.gif" width="804" />

Ces images sont stockées dans le dossier Extern_Pic du répertoire d'installation, comme ci-dessous :

<img src="../../../configuration-guide/basic-graph/externpic.files/image005.jpg" width="852" />

Le dossier Extern_Pic contient deux dossiers, share_picture et system_picture, qui correspondent respectivement aux images partagées et aux images système de la [liste des images de la bibliothèque](#图库图片列表). Les images de system_picture sont des images système qui ne peuvent être ni ajoutées ni modifiées ; celles de share_picture le peuvent, comme sur la figure suivante :

<img src="../../../configuration-guide/basic-graph/externpic.files/image006.jpg" width="852" />

Vous pouvez ajouter vos propres dossiers dans share_picture ou renommer un dossier existant (par exemple Motor) ; le nom du dossier share_picture, lui, ne peut pas être modifié. Vous pouvez aussi ajouter ou supprimer des images dans le dossier Motor.

<img src="../../../configuration-guide/basic-graph/externpic.files/image007.jpg" width="130" />

L'archive share_picture.rar est téléchargeable sur le site officiel ; décompressez-la sur le PC et ajoutez son contenu au dossier share_picture comme indiqué ci-dessus : les images seront alors disponibles dans la [liste des images de la bibliothèque](#图库图片列表).
