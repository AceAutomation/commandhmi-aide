# Échelle graduée

Choisissez la commande Échelle dans le menu Dessin ou cliquez sur le bouton<img src="../../../configuration-guide/basic-graph/ruler.files/image002.jpg" width="24" /> dans la barre d'outils : la boîte de dialogue Échelle s'ouvre, comme sur la figure 4-41 :

Figure 4-41     Boîte de dialogue Échelle

Dans cette boîte de dialogue, CommandHMI propose les réglages Couleur, Axe et Texte. Couleur permet de choisir la couleur des traits et du texte. Axe permet d'afficher ou non l'axe et de régler le nombre de graduations principales et secondaires, avec les boutons de réglage fin ou par saisie directe. Texte permet d'afficher ou non le texte, de modifier les valeurs maximale et minimale de l'échelle, la taille du texte et le nombre de décimales des valeurs.

Après avoir modifié les propriétés de l'échelle, cliquez sur OK pour fermer la boîte de dialogue, puis placez la souris à l'endroit où afficher l'échelle. Cliquez avec le bouton gauche : le système dessine automatiquement l'échelle. Voir la figure 4-42 :

<img src="../../../configuration-guide/basic-graph/samdra47.gif" width="460" />

Figure 4-42     Exemple d'échelle

On obtient alors une échelle comme la première à gauche de la figure ci-dessus. Pour obtenir la deuxième forme, sélectionnez l'échelle, placez la souris sur l'un des côtés de hauteur, maintenez le bouton gauche enfoncé quand le curseur devient<img src="../../../configuration-guide/basic-graph/ruler.files/image004.jpg" width="22" /> et faites glisser au-delà de l'autre côté. Pour obtenir les formes de droite, appliquez une rotation libre.
