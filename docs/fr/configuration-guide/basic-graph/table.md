# Tableau

Choisissez la commande Tableau dans le menu Dessin ou cliquez sur le bouton<img src="../../../configuration-guide/basic-graph/table.files/image002.jpg" width="29" /> dans la barre d'outils : la boîte de dialogue Tableau s'ouvre, comme sur la figure 4-39 :

Figure 4-39     Boîte de dialogue Tableau

Dans cette boîte de dialogue, CommandHMI propose les réglages Couleur de fond, Bordure, Grille et Lignes de grille. L'option Grille permet d'afficher ou non les lignes verticales ou horizontales, dont le type et la couleur sont modifiables.

<img src="../../../configuration-guide/basic-graph/table.files/image004.jpg" width="130" />

Le tableau est un simple objet graphique : on ne peut pas y ajouter de texte, de données ou d'autres objets. Il ne sert que d'image de fond. Pour afficher du texte, des données, etc. sur un tableau, superposez-y des objets Texte et Affichage numérique placés au premier plan.
