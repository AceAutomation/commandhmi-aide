# Enregistrer dans la bibliothèque

Choisissez la commande Enregistrer dans la bibliothèque dans le menu Dessin ou cliquez sur le bouton<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" /> dans la barre d'outils pour ouvrir la boîte de dialogue de la figure 4-46 :

Figure 4-46       Boîte de dialogue Enregistrer dans la bibliothèque

• Le logiciel CommandHMI permet d'enregistrer des éléments d'écran terminés pour les réutiliser. Après avoir cliqué sur Enregistrer dans la bibliothèque, les objets graphiques de l'écran courant s'affichent dans la zone blanche au centre de la boîte de dialogue.

• La sélection propose trois options :

Sélectionner la zone comme élément de bibliothèque : l'objet sélectionné dans l'écran devient un élément de bibliothèque

Importer une bibliothèque : importe un fichier de bibliothèque externe d'extension HM (généralement fourni par CommandHMI).

Importer une image depuis un fichier : importe une image externe comme élément de bibliothèque.

• Cliquez sur « Enregistrer sous... » et choisissez « Bibliothèque II », comme sur la figure 4-47 :

<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image004.jpg" width="753" />

Figure 4-47     Choix de l'emplacement d'enregistrement

Choisissez l'emplacement dans la zone de gauche. CommandHMI propose 8 bibliothèques d'objets personnalisés et 8 bibliothèques de graphiques personnalisés. Après avoir choisi l'emplacement, cliquez sur « Enregistrer » en bas pour enregistrer l'objet graphique, qui s'affiche dans la zone blanche à droite. Cliquez ensuite sur OK pour terminer. Pour voir les graphiques enregistrés, cliquez sur le bouton Ouvrir la bibliothèque<img src="../../../configuration-guide/basic-graph/creat-gallery.files/image002.jpg" width="33" />, faites défiler la liste de gauche jusqu'en bas et choisissez « Bibliothèque personnalisée » dans « Bibliothèque II ».
