# Courbe / Arc

Choisissez la commande Courbe / Arc dans le menu Dessin ou cliquez sur le bouton Courbe / Arc <img src="../../../configuration-guide/basic-graph/spline.files/image002.jpg" width="36" /> dans la barre d'outils ; dans la fenêtre d'édition, le curseur prend la forme d'une croix : vous pouvez dessiner une courbe / un arc.

Placez la souris à l'endroit où commencer la courbe. Cliquez avec le bouton gauche : un petit point vert apparaît, c'est le point de départ de la courbe / de l'arc.

Déplacez la souris dans l'écran : le système trace automatiquement une ligne droite ; cliquez avec le bouton gauche puis relâchez.

Le curseur garde la forme d'une croix. Déplacez la souris jusqu'au point d'arrivée de la courbe / de l'arc. Maintenez le bouton gauche enfoncé et déplacez la souris pour tracer l'arc ; relâchez puis faites un clic droit pour terminer. Voir la figure 4-26 :

<img src="../../../configuration-guide/basic-graph/samdra16.gif" width="533" />

Figure 4-26         Dessin d'une courbe

Comme ci-dessus, le point de départ est un point vert et le point d'arrivée un losange : la courbe / l'arc initial est tracé. Placez la souris sur un point : le curseur prend la forme <img src="../../../configuration-guide/basic-graph/samdra17.gif" width="17" /> ; maintenez le bouton gauche enfoncé, déplacez la souris jusqu'à l'endroit voulu et relâchez pour obtenir la courbe souhaitée. Vous pouvez aussi déplacer le point de départ ou d'arrivée. Voir la figure 4-27 :

<img src="../../../configuration-guide/basic-graph/samdra18.gif" width="411" />

Figure 4-27         Dessin d'une courbe

Vous pouvez régler les propriétés de la courbe / de l'arc avec les listes déroulantes et les boutons de réglage fin. Le logiciel CommandHMI propose jusqu'à 15 types de trait, 10 épaisseurs et 6 flèches d'extrémité pour les courbes / arcs.
