# Polygone

Choisissez la commande Polygone dans le menu Dessin ou cliquez sur le bouton Polygone <img src="../../../configuration-guide/basic-graph/polygon.files/image002.jpg" width="31" /> dans la barre d'outils. Dans la fenêtre d'édition, le curseur prend la forme d'une croix : vous pouvez dessiner un polygone dans l'écran.

Placez la souris à l'endroit où commencer le polygone et cliquez avec le bouton gauche (ou maintenez-le enfoncé) : un petit point vert apparaît dans la fenêtre d'édition, c'est le point de départ du polygone.

Déplacez la souris : le système trace automatiquement une ligne droite. À chaque clic gauche, un nouveau côté du polygone est tracé ; un clic droit termine le dessin. Voir la figure 4-33 :

<img src="../../../configuration-guide/basic-graph/samdra30.gif" width="233" />

Figure 4-33   Dessin d'un polygone

Pour modifier la forme d'un polygone, cliquez dessus : plusieurs points verts apparaissent (autant que de sommets), indiquant que le polygone est sélectionné. Placez le curseur sur l'un d'eux : il change de forme ; faites-le glisser avec le bouton gauche jusqu'à la position voulue pour modifier la longueur et la position des deux côtés reliés à ce sommet. Relâchez le bouton pour terminer.

Vous pouvez régler les propriétés du polygone avec les listes déroulantes et les boutons de réglage fin. Le logiciel CommandHMI propose jusqu'à 15 types de trait de bordure, 10 épaisseurs de bordure et 21 motifs de remplissage pour le polygone. Voir la figure 4-34 :
