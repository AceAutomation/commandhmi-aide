# Texte

Choisissez la commande Texte dans le menu Dessin ou cliquez sur le bouton Texte<img src="../../../configuration-guide/basic-graph/text.files/image002.jpg" width="30" /> dans la barre d'outils pour ouvrir la boîte Texte statique, comme sur la figure 4-36 :

Figure 4-36 Boîte de dialogue Texte statique

• Saisissez le texte à afficher dans le champ TEXT de la boîte de dialogue ci-dessus.

• La taille de police se choisit dans la liste déroulante Taille de police. CommandHMI propose des tailles de 7 à 56 points.

• Le concepteur peut changer de police dans la liste déroulante Police. CommandHMI propose pratiquement toutes les polices.

• Langue : pour chaque langue, vous pouvez saisir un texte différent dans la zone de texte, avec une police et une taille différentes.

• Dans la boîte de dialogue, cochez Gras et Italique pour changer le style.

• Le logiciel permet de régler l'espacement des caractères et l'interligne de 0 à 15 avec les boutons de réglage fin correspondants

• CommandHMI propose aussi jusqu'à 16 styles de soulignement et permet de modifier la position du texte dans la zone de texte, ainsi que le motif de remplissage et la transparence.

**Exemples de rendu du texte**

• Après avoir modifié les propriétés de police, cliquez sur OK pour fermer la boîte de dialogue. Placez la souris à l'endroit voulu dans la fenêtre d'édition et cliquez avec le bouton gauche : le système trace automatiquement un rectangle.

• Pour modifier ou ressaisir le texte, double-cliquez sur l'élément de texte et saisissez le nouveau contenu au clavier. La touche Entrée permet de passer à la ligne.

• Pour modifier la taille du cadre de fond du texte, sélectionnez l'élément de texte et placez la souris sur son bord ; quand le curseur devient<img src="../../../configuration-guide/basic-graph/text.files/image004.jpg" width="22" />ou <img src="../../../configuration-guide/basic-graph/text.files/image005.jpg" width="23" />ou<img src="../../../configuration-guide/basic-graph/text.files/image006.jpg" width="21" />, maintenez le bouton gauche enfoncé, faites glisser jusqu'à la taille voulue, puis relâchez.
