# Rectangle

Choisissez la commande Rectangle dans le menu Dessin ou cliquez sur le bouton Rectangle<img src="../../../configuration-guide/basic-graph/rect.files/image002.jpg" width="31" /> dans la barre d'outils. Dans la fenêtre d'édition, le curseur prend la forme d'une croix ; cliquez dans l'écran pour ajouter un rectangle.

<img src="../../../configuration-guide/basic-graph/rect.files/image004.jpg" width="23" /> : modifie la hauteur du rectangle

 <img src="../../../configuration-guide/basic-graph/rect.files/image005.jpg" width="21" /> : modifie la largeur et la hauteur du rectangle

La transparence, le type, l'épaisseur et la couleur du trait ainsi que le motif de remplissage du rectangle sont alors réglés par défaut. Vous pouvez les modifier selon les besoins du projet : double-cliquez sur le rectangle, ou sélectionnez-le puis cliquez sur le bouton Propriétés<img src="../../../configuration-guide/basic-graph/rect.files/image006.jpg" width="30" /> de la barre d'outils. Les propriétés du rectangle s'affichent, comme sur la figure 4-29 :

<img src="../../../configuration-guide/basic-graph/rect.files/image007.jpg" width="358" />

Figure 4-29     Boîte de dialogue Propriétés du rectangle

Vous pouvez régler les propriétés du rectangle avec les listes déroulantes et les boutons de réglage fin. Le logiciel CommandHMI propose jusqu'à 15 types de trait de bordure, 10 épaisseurs de bordure et 21 motifs de remplissage. Voir la figure 4-30 :
