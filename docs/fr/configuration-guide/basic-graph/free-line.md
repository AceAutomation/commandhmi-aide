# Ligne libre

Choisissez la commande Ligne libre dans le menu Dessin ou cliquez sur le bouton Ligne libre <img src="../../../configuration-guide/basic-graph/free-line.files/image002.jpg" width="40" /> dans la barre d'outils. Dans la fenêtre d'édition, le curseur prend la forme d'une croix : vous pouvez dessiner une ligne libre.

Placez la souris à l'endroit où commencer la ligne et cliquez avec le bouton gauche : un petit point vert apparaît dans la fenêtre d'édition, c'est le point de départ de la ligne libre.

Déplacez la souris dans l'écran : le système trace automatiquement une ligne qui suit la trajectoire de la souris ; cliquez avec le bouton gauche ou droit pour terminer. Voir la figure 4-28 :

<img src="../../../configuration-guide/basic-graph/samdra19.gif" width="436" />

Figure 4-28         Dessin d'une ligne libre

Vous pouvez alors régler les propriétés de la courbe libre avec les listes déroulantes et les boutons de réglage fin. Le logiciel CommandHMI propose jusqu'à 6 types de trait, 30 épaisseurs et 6 types de flèches d'extrémité pour les courbes / arcs.
