# Polyligne

Choisissez la commande Polyligne dans le menu Dessin ou cliquez sur le bouton Polyligne<img src="../../../configuration-guide/basic-graph/polylines.files/image002.jpg" width="32" /> dans la barre d'outils, puis placez la souris dans la fenêtre d'édition. Le curseur prend la forme d'une croix : vous pouvez dessiner une polyligne.

Placez la souris à l'endroit où commencer la polyligne et cliquez une fois avec le bouton gauche : un petit point vert apparaît dans la fenêtre d'édition, c'est une extrémité de la polyligne.

Déplacez la souris : le système trace automatiquement une ligne droite ; déplacez la souris pour changer de direction et cliquez une fois avec le bouton gauche : un petit carré vert apparaît à l'endroit du clic. Le segment entre la première extrémité et ce carré ne suit plus la souris. Continuez de la même façon pour chaque changement de direction. Pour terminer la polyligne, faites un clic droit, comme sur la figure 4-25 :

<img src="../../../configuration-guide/basic-graph/samdra14.gif" width="190" />

Figure 4-25        Dessin d'une polyligne

Vous pouvez régler les propriétés de la polyligne avec les listes déroulantes et les boutons de réglage fin. Le logiciel CommandHMI propose jusqu'à 6 types de trait, 30 épaisseurs et 6 types de flèches d'extrémité pour les polylignes. Pour modifier la longueur, la direction ou la position, sélectionnez la polyligne, placez la souris dessus, maintenez le bouton gauche enfoncé, faites glisser jusqu'à la position voulue puis relâchez.
