# Affichage de messages

L'affichage de messages fonctionne comme le <span id="OLE_LINK465"></span>voyant multi-états, mais avec davantage d'états : jusqu'à 128. Son icône dans la barre d'outils est<img src="../../../configuration-guide/extended-controls/message.files/image002.jpg" width="32" /> ; cliquez dessus pour ouvrir la boîte de dialogue de la figure 4-66 :

<img src="../../../configuration-guide/extended-controls/message.files/image006.jpg" width="675" />

Figure 4-66       Page Général de l'affichage de messages

La page Texte de l'affichage de messages est présentée sur la figure 4-67 :

<img src="../../../configuration-guide/extended-controls/message.files/image007.jpg" width="675" />

Figure 4-67     Page Texte de l'affichage de messages

Pour les réglages de langue, police, taille et couleur, voir l'objet Voyant multi-états.

• Défilement : trois options : Fixe, Gauche et Droite.

• Fixe : le texte de l'état courant est immobile.

• Gauche : <span id="OLE_LINK483"></span>le texte de l'état courant défile vers la gauche de n pixels, n étant la vitesse définie par l'utilisateur.

• Droite : le texte de l'état courant défile vers la droite de n pixels, n étant la vitesse définie par l'utilisateur.

<img src="../../../configuration-guide/extended-controls/message.files/image005.jpg" width="130" />

Pour les autres propriétés, voir l'objet « Voyant multi-états ».
