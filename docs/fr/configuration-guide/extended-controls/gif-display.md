# Affichage GIF

L'affichage GIF permet d'afficher des images au format GIF, jusqu'à 32 trames. Procédure :

Cliquez sur l'icône GIF<img src="../../../configuration-guide/extended-controls/gif-display.files/image002.jpg" width="29" /> dans la barre d'outils pour ouvrir la boîte de dialogue de la figure 4-48.

Figure 4-48    Boîte de dialogue Affichage GIF

Une fois les propriétés réglées, cliquez sur « OK » : le curseur prend la forme d'une croix dans la zone d'édition ; tracez un rectangle avec le bouton gauche pour ajouter l'objet à la zone de vue (l'écran)

Sélectionnez la page « Avancé » pour afficher ses propriétés.

![](../../../configuration-guide/extended-controls/gif-display.files/image004.jpg)

Figure 4-49    Page « Avancé » de l'affichage GIF

Contrôlé par bit : si cette option est cochée et que l'« État actif » est 1, l'image GIF n'est animée que lorsque le « Bit de contrôle » vaut 1, sinon elle est figée ; si l'« État actif » est 0, elle n'est animée que lorsque le bit de contrôle vaut 0, sinon elle est figée.

<img src="../../../configuration-guide/extended-controls/gif-display.files/image005.jpg" width="130" />

Pour la page « Visibilité », voir l'utilisation de l'objet « Bouton de bit ».
