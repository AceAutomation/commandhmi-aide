# Bouton multifonction

Le bouton multifonction permet d'enchaîner plusieurs opérations personnalisées avec un seul objet, ce qui simplifie l'utilisation. Cliquez sur<img src="../../../configuration-guide/extended-controls/multi-function.files/multi-function153.png" width="28" /> dans la barre d'outils ou double-cliquez sur un bouton multifonction existant pour ouvrir ses propriétés.

![](../../../configuration-guide/extended-controls/multi-function.files/multi-function249.png)

• Général :

**1. Apparence du bouton : forme, couleur, style, etc.**

**2. Fonctions disponibles**

Plusieurs fonctions sont proposées au choix.

• Mise à 1 de bobine : met à 1 l'adresse indiquée.

• Mise à 0 de bobine : met à 0 l'adresse indiquée.

• Inversion de bobine : inverse la valeur de l'adresse : 0 devient 1, 1 devient 0 ;

• Bobine impulsionnelle : l'adresse est mise à 1 à l'appui et à 0 au relâchement ;

• Changement d'écran : affiche l'écran choisi. Modifiez la fonction pour choisir l'écran cible.

<img src="../../../configuration-guide/extended-controls/multi-function.files/multi-function746.png" width="201" />

• Écrire une donnée : écrit la valeur définie à l'adresse définie. Vous choisissez le type, l'adresse et la donnée.

<img src="../../../configuration-guide/extended-controls/multi-function.files/multi-function885.png" width="231" />

• Saisie utilisateur : saisit une valeur et l'écrit à l'adresse définie. Vous choisissez le type de données et l'adresse ; à l'exécution, une fenêtre de saisie s'affiche.

<img src="../../../configuration-guide/extended-controls/multi-function.files/multi-function1141.png" width="231" />

Sélectionnez une fonction disponible et cliquez sur Ajouter pour l'ajouter à la liste des fonctions choisies.

Changement de niveau utilisateur : déconnecte l'utilisateur courant et permet de se connecter avec un autre niveau. Les autres utilisateurs se définissent dans l'écran de réglage.

Fermer la fenêtre : ferme la fenêtre courante ; utilisable uniquement dans une fenêtre.

Lire et enregistrer la recette : lit et enregistre la recette courante dans l'IHM.

Effacer les alarmes : efface les messages d'alarme existants. Sélectionnez une ligne dans l'affichage de l'historique des alarmes, puis appuyez sur ce bouton pour l'effacer.

Téléchargement de recette : écrit dans l'IHM les données de recette contenues dans les adresses RWI, puis remet à zéro à la fin de l'opération.

Upload de recette : lit le contenu de la recette de l'IHM dans la zone de registres RWI, puis remet à zéro à la fin de l'opération.

Quatre opérations : réalise des calculs de base sur des valeurs numériques ; double-cliquez sur la fonction pour la paramétrer : type d'opération, type de données, type d'opérande, etc.

Si « Saisie utilisateur » et « Bobine impulsionnelle » sont toutes deux choisies, seule la saisie utilisateur est exécutée.

**3. Fonctions ajoutées**

Les fonctions choisies sont listées ici. Double-cliquez dessus ou cliquez sur « Modifier » pour les régler. Cliquez sur « Supprimer » pour en retirer une.

Un appui sur le bouton multifonction pendant l'exécution du projet exécute toutes les fonctions choisies.

**4. Macro**

Cochez « Exécuter une macro » pour afficher la liste des macros. Choisissez une macro : elle sera exécutée à l'appui sur le bouton pendant l'exécution du projet.

<img src="../../../configuration-guide/extended-controls/multi-function.files/multi-function1803.png" width="130" />
