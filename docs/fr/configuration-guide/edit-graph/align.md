# Alignement

Cette commande, comme Taille, s'applique à un groupe d'objets. CommandHMI permet d'aligner et de dimensionner plusieurs objets graphiques, uniquement lorsque plusieurs objets sont sélectionnés. Maintenez la touche Ctrl pour sélectionner les objets à aligner, ou tracez un cadre de sélection avec le bouton gauche. Les commandes d'alignement sont nombreuses : Gauche, Droite, Centre vertical, Centre horizontal, Haut, Bas, Espacement horizontal égal, Espacement vertical égal, Même largeur, Même hauteur, Même largeur et hauteur, etc.

• <img src="../../../configuration-guide/edit-graph/align.files/align610.png" width="33" />**Haut**

La commande Aligner en haut permet d'aligner le bord supérieur de plusieurs objets graphiques (au moins deux) via « Haut » dans Alignement du menu Édition ou dans le menu contextuel. Les objets prennent comme référence le bord le plus haut et sont alignés au même niveau. Comparaison avant/après de l'alignement en haut, figure 4-16 :

• <img src="../../../configuration-guide/edit-graph/align.files/align1619.png" width="29" />**Centre vertical**

La commande Centre vertical permet de placer les centres de plusieurs objets graphiques (au moins deux) sur une même ligne verticale, via « Centre vertical » dans Alignement du menu Édition ou dans le menu contextuel. Cette ligne est l'axe vertical situé au milieu des bords extrêmes gauche et droit.

• <img src="../../../configuration-guide/edit-graph/align.files/align2148.png" width="29" />**Gauche**

La commande Aligner à gauche permet d'aligner le bord gauche de plusieurs objets graphiques (au moins deux) via « Gauche » dans Alignement du menu Édition ou dans le menu contextuel. Les objets prennent comme référence le bord le plus à gauche et leurs côtés gauches sont alignés sur la même verticale.

• <img src="../../../configuration-guide/edit-graph/align.files/align3248.png" width="32" />**Même largeur**

Cette commande donne la même largeur à plusieurs objets graphiques (au moins deux), via « Même largeur » dans Taille du menu Édition ou dans le menu contextuel. Les objets sont réduits ou agrandis à partir de leur coin supérieur gauche, à hauteur constante, pour prendre la largeur de l'objet sélectionné en premier (entouré de points noirs, les autres de points verts).

• <img src="../../../configuration-guide/edit-graph/align.files/align4568.png" width="23" />**Même largeur et hauteur**

Cette commande donne la même largeur et la même hauteur à plusieurs objets graphiques (au moins deux), via « Même largeur et hauteur » dans Taille du menu Édition ou dans le menu contextuel. Les objets sont réduits ou agrandis à partir de leur coin supérieur gauche pour prendre les dimensions de l'objet sélectionné en premier (entouré de points noirs, les autres de points verts).

• <img src="../../../configuration-guide/edit-graph/align.files/align5257.png" width="28" />**Espacement horizontal égal**

Cette commande répartit plusieurs objets graphiques (au moins deux) avec un espacement horizontal égal, via « Espacement horizontal égal » dans Alignement du menu Édition ou dans le menu contextuel.

• <img src="../../../configuration-guide/edit-graph/align.files/align5543.png" width="28" />**Espacement vertical égal**

Cette commande répartit plusieurs objets graphiques (au moins deux) avec un espacement vertical égal, via « Espacement vertical égal » dans Alignement du menu Édition ou dans le menu contextuel.

<img src="../../../configuration-guide/edit-graph/align.files/align5825.png" width="130" />

Avant d'utiliser Même largeur, Même hauteur ou Même largeur et hauteur, vérifiez si les objets sélectionnés ont subi une rotation : la largeur et la hauteur d'un objet tourné tournent avec lui.
