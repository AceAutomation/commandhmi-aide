# Affichage ASCII

L'affichage ASCII sert à afficher des caractères ASCII contenus dans l'équipement.

Cliquez sur l'icône Affichage ASCII<img src="../../../configuration-guide/basic-control/asc-display.files/image002.jpg" width="29" /> : la boîte de dialogue de la figure 4-99 s'ouvre :

Figure 4-99    Boîte de dialogue Affichage ASCII

Dans cette boîte de dialogue, vous pouvez définir l'adresse de surveillance de l'équipement connecté à afficher, la taille de police du texte et d'autres propriétés.

• Adresse de surveillance (Monitor Address) : les données contenues à cette adresse sont affichées en temps réel, ou des données peuvent y être saisies.

• Total : nombre maximal de caractères affichables.

• Taille de police : taille des caractères affichés

<span id="OLE_LINK711"></span><span id="OLE_LINK710"></span>• Inverser les octets haut et bas de la saisie : l'octet haut de la valeur saisie est échangé avec l'octet bas, puis la donnée ainsi obtenue est enregistrée à l'adresse de mot surveillée.

<span id="OLE_LINK713"></span><span id="OLE_LINK712"></span>• Mot de passe : si cette option est cochée, l'objet n'affiche pas les caractères mais des astérisques (\*)

• Utiliser UNICODE : la valeur de l'adresse de surveillance est affichée en codage Unicode

Alignement :

• Gauche : le <span id="OLE_LINK703"></span><span id="OLE_LINK702"></span>texte est affiché dans la partie gauche de la zone d'affichage.

• Centre : le texte est affiché au centre de la zone d'affichage.

• Droite : le texte est affiché dans la partie droite de la zone d'affichage.
