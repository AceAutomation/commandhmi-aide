# Affichage de l'heure

L'objet Affichage de l'heure sert à afficher l'heure système. Cliquez sur l'icône<img src="../../../configuration-guide/basic-control/time.files/image002.jpg" width="31" /> : la boîte de dialogue de la figure 4-105 s'ouvre.

Figure 4-105    Boîte de dialogue Affichage de l'heure

<img src="../../../configuration-guide/basic-control/time.files/image004.jpg" width="130" />

Remarque : pour Forme, Couleur de bordure, Couleur de premier plan, Couleur de fond et Motif, voir l'objet Bouton de bit.

• Format : quatre formats d'affichage de l'heure au choix.

HH:MM                Heure: Minute

HH:MM:SS           Heure: Minute: Seconde

HH-MM-SS           Heure- Minute-Seconde

HH-MM                Heure- Minute

• Police : type de police du texte

• Taille de police : taille du texte affiché

• Couleur : couleur du texte affiché

• Alignement : position du texte affiché : gauche, centre ou droite.

Une fois les réglages faits, cliquez sur « OK » pour ajouter l'objet à la zone de vue (l'écran)
