# Image statique

L'image statique sert à afficher une image de différents formats, depuis un fichier ou la bibliothèque. Elle peut servir de fond d'écran pour embellir l'interface du projet.

1\. Cliquez sur l'icône Image statique<img src="../../../configuration-guide/basic-control/picture.files/image002.jpg" width="30" /> dans la barre d'outils : la boîte de dialogue de la figure 4-109 s'ouvre :

<img src="../../../configuration-guide/basic-control/picture.files/image004.jpg" width="675" />

Figure 4-109   Boîte de dialogue Image statique

2\. Après avoir choisi une image, cliquez sur OK : le curseur prend la forme d'une croix ; cliquez avec le bouton gauche n'importe où dans l'écran pour ajouter l'image.

3\. La taille de l'image insérée se modifie à la souris. Le logiciel CommandHMI accepte de nombreux formats : JPG, BMP, PNG, WMF, EMF, GIF.
