# Affichage de la date

L'objet Affichage de la date sert à afficher la date système. Cliquez sur l'icône <img src="../../../configuration-guide/basic-control/date.files/image002.jpg" width="31" /> dans la barre d'outils : la boîte de dialogue de la figure 4-106 s'ouvre :

<img src="../../../configuration-guide/basic-control/date.files/image005.jpg" width="675" />

Figure 4-106   Boîte de dialogue Affichage de la date

• Format : neuf formats d'affichage de la date au choix.

YYYY-MM-DD

MM-DD-YYYY

DD-MM-YYYY

YYYY/MM/DD

MM/DD/YYYY

DD/MM/YYYY

YYYY.MM.DD

MM.DD.YYYY

DD.MM.YYYY

• Police : type de police du texte

• Taille de police : taille du texte affiché

• Couleur : couleur du texte affiché

• Alignement : position du texte affiché : gauche, centre ou droite.

<img src="../../../configuration-guide/basic-control/date.files/image004.jpg" width="130" />
