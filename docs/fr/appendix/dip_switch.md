# Commutateur DIP

Chaque IHM de la série HM possède un commutateur DIP dont chaque interrupteur a sa fonction.

<img src="../../appendix/dip_switch.files/image004.gif" width="212" />

**Liste des fonctions du commutateur DIP**

|                   |                             |
|-------------------|-----------------------------|
| Commutateur DIP (5-1) | Fonction                    |
| Tous sur OFF      | Mode de fonctionnement normal |
| 1 sur ON          | Mode d'étalonnage des coordonnées |
| 2 sur ON          | Mode d'affichage des paramètres |
| 1 et 2 sur ON     | Mode terminal               |
| 1 et 3 sur ON     | Mode de réglage des paramètres |

<img src="../../appendix/dip_switch.files/image005.gif" width="595" />

Remarque :

Après avoir modifié le commutateur DIP, il faut redémarrer l'IHM ;

En utilisation normale de l'IHM, utilisez le mode de fonctionnement normal ;

Le mode de réglage des paramètres sert à régler l'heure, la luminosité et l'adresse IP.
