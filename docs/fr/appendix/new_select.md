**Recherche**

Il existe deux types de recherche : la recherche simple et la recherche composée :
**1. Recherche simple**
        Par exemple, si vous recherchez la lettre « C », seuls les éléments contenant « C » sous le nœud courant « GVL_Load » sont affichés dans la liste, y compris ses enfants et petits-enfants ; le contenu des autres nœuds n'est pas recherché.

![](../../appendix/new_select.files/007.png)
     Cliquer sur un élément ne le sélectionne pas immédiatement : on descend dans ses sous-éléments jusqu'à sélectionner l'élément de plus bas niveau.

**2. Recherche composée**
        La recherche composée permet de rechercher des chaînes dans des variables de structure, en partant du début de l'étiquette et en terminant par un point complet.
        Pour rechercher dans une structure, saisissez le chemin complet de la structure dans la zone de recherche. Par exemple, pour rechercher dans le répertoire OSFB sous Main, saisissez « Application.Main.OSFB » pour vous placer dans ce répertoire, puis le nom de l'élément recherché. Double-cliquez pour sélectionner l'étiquette.
