# Mettre à jour le projet via clé USB

Les IHM de la série HM permettent d'importer et de mettre à jour le projet via clé USB.

**Mettre à jour le fichier de projet via clé USB**

**1. Compiler le projet**

Lancez CommandHMI, ouvrez le projet à mettre à jour et cliquez sur <img src="../../appendix/use_usd.files/image002.jpg" width="71" /> pour générer le fichier compilé.

**2. Cliquez sur « Save Project As » dans « Download », puis choisissez le répertoire d'enregistrement**

Le fichier u-disk-prj.bin est enregistré dans le répertoire choisi.

**3. Copier le fichier compilé sur la clé USB**

Ouvrez le répertoire et copiez u-disk-prj.bin sur la clé USB.

**4. Insérer la clé USB dans l'IHM**

**5. Copier le fichier et mettre à jour le projet**

Après insertion de la clé USB dans l'IHM, cliquez sur YES dans la fenêtre qui s'affiche pour lancer la mise à jour.

**6. Redémarrer l'IHM pour terminer la mise à jour**

Coupez et rétablissez l'alimentation ou redémarrez l'IHM avec le bouton « Restart » à l'écran.

<img src="../../appendix/use_usd.files/image006.gif" width="595" />

Remarque

 • Ne retirez pas la clé USB pendant la mise à jour ;

• Maintenez l'IHM sous tension pendant la mise à jour.
