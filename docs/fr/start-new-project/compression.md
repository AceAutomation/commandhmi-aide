# Compresser/Décompresser

Choisissez « <span id="OLE_LINK272"></span><span id="OLE_LINK273"></span>Compresser/Décompresser » dans le menu « Téléchargement » pour ouvrir la boîte de dialogue.

<img src="../../start-new-project/compression.files/image002.jpg" width="668" />

• Compresser le fichier : compresse le projet HM en un fichier d'extension .sip. Les images externes utilisées sont incluses dans l'archive : envoyée sur un autre ordinateur, l'archive conserve les images après décompression. Si l'on n'envoie que le fichier de projet, les images externes sont perdues sur l'autre ordinateur, car leur chemin d'origine est introuvable.

• Chemin d'enregistrement : <span id="OLE_LINK276"></span><span id="OLE_LINK277"></span>emplacement du fichier compressé ; après l'avoir choisi, cliquez sur « Compresser », puis fermez la boîte quand la barre de progression atteint 100 %.

• Décompresser le fichier : décompresse un fichier .vpr en fichier .vpm, qui s'ouvre directement dans CommandHMI.

• Fichier compressé : choisissez le fichier à décompresser.

• Chemin d'enregistrement : emplacement du fichier .vpm décompressé ; après l'avoir choisi, cliquez sur « Décompresser », puis fermez la boîte quand la barre de progression atteint 100 %.
