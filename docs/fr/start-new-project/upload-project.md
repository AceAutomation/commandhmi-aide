# Charger le projet

Le logiciel CommandHMI permet de charger le projet de l'IHM vers le disque dur. Reliez l'IHM au PC ; choisissez « Charger le fichier de projet » dans la boîte qui s'ouvre : l'écran « Charger le fichier Samdraw » apparaît.

![](../../start-new-project/upload-project.files/001.png)

• Chemin du fichier : cliquez sur « Parcourir » pour choisir l'emplacement d'enregistrement.

• Nom du projet : nom du projet.

• Lancer le chargement : cliquez sur « Charger le fichier ».

Une fois le chargement réussi, vous pouvez ouvrir ou non le fichier de projet.

<img src="../../start-new-project/upload-project.files/upload-project507.png" width="130" />

Le fichier chargé doit être décompressé avant ouverture.
