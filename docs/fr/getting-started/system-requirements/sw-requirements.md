# Configuration logicielle requise

Le logiciel CommandHMI fonctionne sous les systèmes d'exploitation suivants :

· Microsoft Windows NT Server 4.0 ou ultérieur ;

· Microsoft Windows NT Workstation 4.0 ou ultérieur ;

· Microsoft Windows 98, Me, 2000, XP, Windows 7 ou ultérieur.

<img src="../../../getting-started/system-requirements/sw-requirements.files/image002.jpg" width="130" />

CommandHMI refuse de s'installer sur un autre système d'exploitation.

<span id="OLE_LINK52"></span><span id="OLE_LINK53"></span>**Systèmes recommandés :**

Windows XP SP3 ; Windows 7 32 bits ; Windows 7

Les versions chinoise et anglaise du système d'exploitation conviennent indifféremment.
