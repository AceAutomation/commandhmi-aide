# Configuration matérielle requise

Configuration matérielle minimale pour CommandHMI :

Processeur : Pentium 3 800 MHz minimum ;

Mémoire : 128 Mo ou plus sous Windows 9X ;

<span id="OLE_LINK68"></span><span id="OLE_LINK69"></span><span id="OLE_LINK60"></span><span id="OLE_LINK61"></span>256 Mo ou plus sous Windows NT ;

256 Mo ou plus sous Windows 2000 ou XP ;

Carte graphique : <span id="OLE_LINK71"></span><span id="OLE_LINK70"></span>compatible <span id="OLE_LINK62"></span><span id="OLE_LINK63"></span>Windows, plus de 1 Mo de mémoire vidéo, résolution 1024 \* 768 en 256 couleurs ;

Disque dur : au moins 200 Mo d'espace libre pour le logiciel CommandHMI.

Ordinateur équipé d'un port USB ;

Souris à deux boutons et clavier.

<img src="../../../getting-started/system-requirements/hw-requirements.files/image002.jpg" width="130" />

Avec une configuration inférieure, CommandHMI risque de ne pas s'installer ou de ne pas fonctionner.

**Configuration recommandée :**

Processeur : équivalent Intel Pentium 800 ou supérieur ;

Mémoire : 256 Mo ou plus sous Windows 9X ;

512 Mo ou plus sous Windows NT ;

512 Mo ou plus sous Windows 2000 ou XP.

Carte graphique : compatible Windows, plus de 1 Mo de mémoire vidéo, résolution 1024 \* 768 en 65535 couleurs.

Disque dur : 200 Mo ou plus d'espace libre.
