# Barre de menus

La barre de menus du logiciel CommandHMI offre de nombreuses options couvrant pratiquement tous les outils et commandes d'édition nécessaires. Elle comprend les menus Fichier, Édition, Affichage, Dessin, Objet, Écran, Paramètres, Téléchargement, Aide, Langue, ainsi qu'un menu contextuel (clic droit).

 <img src="../../../../getting-started/window/editview/menu.files/menu355.png" width="742" />

Figure 2-28        Barre de menus

**Menu Fichier**

Le menu « Fichier » propose Nouveau projet (N), Ouvrir un projet (O), Fermer, Enregistrer (S), Enregistrer sous et Quitter (Q). Un élément grisé indique que l'opération n'est pas disponible dans le contexte courant. Pour ouvrir ce menu, cliquez sur « Fichier (F) » en haut à gauche du logiciel.

<img src="../../../../getting-started/window/editview/menu.files/menu742.png" width="278" />

Figure 2-29 Menu « Fichier »

• Nouveau projet : raccourci Ctrl + N ; crée un projet vide.

• Ouvrir un projet : raccourci Ctrl + O ; ouvre un fichier de projet existant d'extension .vpm.

• Fermer : ferme le projet courant sans quitter le logiciel CommandHMI.

• Enregistrer : raccourci Ctrl + S ; enregistre le projet modifié sous le même nom et au même emplacement.

• Enregistrer sous : enregistre le projet courant en permettant de changer son nom et son emplacement.

• Quitter : quitte le logiciel CommandHMI.

**Menu Édition**

Le menu « Édition » regroupe les commandes d'édition du texte, des graphiques et des autres éléments de l'écran : Annuler, Rétablir, Couper (T), Copier (C), Copie multiple (D), Coller (P), Supprimer (D), Tout sélectionner (A), Alignement, Plans, Grouper, Miroir, Zoom, Grille, Propriétés, Rechercher une adresse, Table des adresses, Inverser la sélection, Recherche de macro, Gestionnaire de macros. Une commande grisée n'est pas disponible dans le contexte courant. Sélectionnez d'abord l'objet graphique à éditer, puis la commande voulue dans le menu « Édition ». Certaines commandes sont des groupes : un petit triangle à droite indique un sous-menu, et chaque commande a un raccourci.

• Annuler : raccourci Ctrl + Z ; annule la dernière opération.

• Rétablir : raccourci Ctrl + Y ; rétablit la dernière opération annulée.

• Couper : raccourci Ctrl + X ; supprime les objets sélectionnés et les copie dans le presse-papiers.

• Copier : raccourci Ctrl + C ; copie les objets sélectionnés dans le presse-papiers.

• Copie multiple : copie plusieurs fois les objets sélectionnés horizontalement et verticalement, avec des adresses incrémentées de 0 à 255 unités.

• Coller : raccourci Ctrl + V ; colle les objets du presse-papiers dans l'écran courant.

• Supprimer : touche Suppr ; retire les objets sélectionnés de l'écran.

<img src="../../../../getting-started/window/editview/menu.files/menu2833.png" width="193" />

Figure 2-30 Menu « Édition »

• Tout sélectionner : raccourci Ctrl + A ; sélectionne tous les objets de l'écran courant.

• Alignement : aligne les objets sélectionnés (au moins deux) selon le type choisi : Haut, Bas, Centre vertical, Gauche, Droite, Espacement horizontal égal, Espacement vertical égal, Même largeur, Même hauteur, Même largeur et hauteur.

• Plans : place les objets sélectionnés sur un autre plan : Premier plan, Avancer d'un plan, Arrière-plan ou Reculer d'un plan.

• Grouper : réunit plusieurs objets sélectionnés (au moins deux) en un seul objet, ou décompose un objet groupé en ses éléments d'origine. Ne groupez pas d'objets tactiles : une fois chargés dans l'écran tactile, ils ne réagiraient plus au toucher. Pour superposer des objets tactiles, utilisez plutôt les plans.

<img src="../../../../getting-started/window/editview/menu.files/menu3850.png" width="130" />

N'utilisez pas Grouper sur des objets tactiles : ils ne réagiraient plus au toucher une fois chargés dans l'écran tactile. Utilisez la commande Plans pour superposer des objets tactiles.

• Miroir : retourne l'objet sélectionné horizontalement ou verticalement.

• Zoom : agrandit ou réduit l'affichage de l'écran courant pour un travail plus précis : Zoom avant, Ajuster, Zoom arrière.

• Grille : affiche ou masque une grille de pas défini dans l'écran courant.

• Propriétés : ouvre les propriétés de l'objet sélectionné (si un seul objet est sélectionné) ou de l'écran (si rien n'est sélectionné).

• Rechercher une adresse : recherche une adresse utilisée.

• Table des adresses : ouvre ou ferme la liste des adresses utilisées par les objets, pour les retrouver et les remplacer facilement.

• Inverser la sélection : sélectionne tous les objets non sélectionnés de l'écran courant et désélectionne les autres.

• Recherche de macro : localise les appels d'une macro dans le projet ; la recherche peut être ciblée ou saisie manuellement.

• Gestionnaire de macros : affiche l'emplacement de toutes les macros utilisées, pour tous les écrans ou pour un écran donné.

**Menu Affichage**

Ce menu permet d'adapter l'interface à vos habitudes en affichant ou masquant certaines fenêtres. La coche √ à gauche d'une commande indique que l'élément est affiché ; sinon, il est masqué.

**Menu Dessin**

Ce menu sert à dessiner des formes dans l'écran. CommandHMI propose Ligne (L), Polyligne (B), Courbe / Arc (A), Ligne libre, Rectangle (R), Rectangle arrondi, Ellipse (E), Polygone (Y), Secteur, Texte (T), Ouvrir la bibliothèque (0), Créer une bibliothèque (C), Tableau et Échelle. Le concepteur peut facilement modifier la couleur, le texte, la taille et la position des éléments créés.

<img src="../../../../getting-started/window/editview/menu.files/menu5835.png" width="153" />

Figure 2-31        Menu « Dessin »

• Ligne : dessine une ligne droite dans n'importe quelle direction dans l'écran courant.

• Polyligne : dessine une polyligne dans n'importe quelle direction dans l'écran courant.

• Courbe / Arc : dessine une ligne dans l'écran courant ; après l'avoir terminée par un clic droit, on peut en ajuster la courbure.

• Ligne libre : dessine une ligne qui suit les mouvements de la souris.

• Rectangle : dessine un rectangle de taille quelconque dans l'écran courant.

• Rectangle arrondi : dessine un rectangle à coins arrondis dans l'écran courant.

• Ellipse : dessine une ellipse de taille quelconque dans l'écran courant.

• Polygone : dessine un polygone quelconque dans l'écran courant.

• Secteur : dessine un secteur quelconque dans l'écran courant.

• Texte : crée un rectangle transparent dans lequel saisir du texte.

• Ouvrir la bibliothèque : ouvre la bibliothèque d'images du système.

• Créer une bibliothèque : enregistre les graphiques dessinés par l'utilisateur dans un fichier de bibliothèque, pour les réutiliser.

• Tableau : crée un tableau avec le nombre de lignes et de colonnes voulu dans l'écran courant.

• Échelle : dessine une échelle graduée.

**Menu Objet**

Le menu « Objet » regroupe les touches tactiles et touches de fonction : Bouton de bit, Bouton de mot, Bouton d'écran, Bouton de fonction, Touche multifonction, Bouton pas à pas, Bouton radio, Liste déroulante, Curseur, Affichage numérique, Saisie numérique, Affichage ASCII, Saisie ASCII, Voyant de bit, Bouton multi-états, Voyant multi-états, Affichage de messages, Affichage de l'heure, Affichage de la date, Affichage du jour, Image statique, Affichage d'images, Affichage GIF, Graphiques dynamiques, Cercle dynamique, Rectangle dynamique, Bloc de flux, Déplacement graphique, Animation, Bargraphe, Indicateur à aiguille, Graphique en arc, Courbe de tendance, Courbe de tendance XY, Tendance historique, Groupe de données, Données historiques, Alarmes, Bandeau d'alarmes, Historique des alarmes, Temporisateur, Tableau d'écriture, Sélecteur de recette, Affichage des recettes, Clavier et Code QR. Le menu « Objet » correspond à la troisième ligne de la barre d'outils.

• Bouton de bit : crée une touche qui agit sur un bit de l'équipement connecté : mise à ON, mise à OFF, impulsion et inversion.

• Bouton de mot : crée une touche qui agit sur un mot de l'équipement connecté : addition, soustraction, incrémentation, décrémentation, constante, saisie de valeur, saisie de mot de passe.

• Autres boutons : donne accès au bouton d'écran, bouton de fonction, touche multifonction, bouton pas à pas, bouton radio, liste déroulante et curseur.

• Affichage numérique : dessine dans l'écran courant un cadre qui affiche la valeur numérique d'une adresse surveillée.

• Saisie numérique : dessine dans l'écran courant un cadre de saisie et d'affichage de la valeur numérique d'une adresse surveillée.

• Affichage ASCII : dessine dans l'écran courant un cadre d'affichage de code ASCII.

• Saisie ASCII : dessine dans l'écran courant un cadre de saisie et d'affichage de code ASCII.

• Voyant de bit : crée dans l'écran courant une image qui surveille l'état d'un bit de l'équipement connecté.

• Bouton multi-états : crée un bouton multi-états qui surveille les variations de valeur d'une adresse de l'équipement connecté selon l'état.

• Voyant multi-états : place dans l'écran courant une image qui surveille l'état d'un mot de l'équipement.

<img src="../../../../getting-started/window/editview/menu.files/menu9590.png" width="174" />

Figure 2-32        Menu « Objet »

• Affichage de messages : crée un objet qui affiche des messages prédéfinis dans l'écran courant.

• Affichage de l'heure : insère un objet qui affiche l'heure.

• Affichage de la date : insère un objet qui affiche la date.

• Affichage du jour : insère un objet qui affiche le jour de la semaine.

• Image statique : insère une image fixe du disque local dans l'écran courant.

• Affichage d'images : dessine un cadre qui affiche plusieurs images.

• Affichage GIF : dessine un cadre qui affiche une image fixe ou animée au format .GIF.

• Graphiques dynamiques : ouvre les fenêtres Cercle dynamique, Rectangle dynamique, Bloc de flux, Déplacement graphique et Animation.

• Bargraphe : insère un objet en barres pour observer les variations de la valeur surveillée par la montée/descente ou le déplacement gauche/droite de la barre.

• Indicateur à aiguille : crée un indicateur qui surveille les variations de la valeur d'une adresse de l'équipement connecté.

• Graphique en arc : insère un secteur qui représente la valeur de l'adresse surveillée ; la zone correspondante est représentée par la couleur de premier plan, la couleur de fond ou la couleur inférieure du secteur.

• Graphique : ouvre les fenêtres Courbe de tendance, Courbe de tendance XY, Tendance historique et Groupe de données.

• Données historiques : crée un objet qui affiche les données enregistrées par le collecteur de données historiques.

• Alarmes : ouvre les fenêtres Alarmes, Bandeau d'alarmes et Historique des alarmes.

• Temporisateur : insère un objet qui déclenche une fonction selon des conditions de temps.

• Tableau d'écriture : insère un objet sur lequel l'utilisateur peut écrire.

• Sélecteur de recette : insère un objet qui affiche les noms de toutes les recettes existantes.

• Affichage des recettes : insère un objet qui affiche toutes les données des recettes définies.

• Clavier : insère un objet clavier ; chaque touche est personnalisable.

• Code QR : insère un objet code QR défini par l'utilisateur ; il doit être utilisé avec un objet de saisie, sinon l'adresse n'est pas valide et le code QR ne s'affiche pas.

**Menu Écran**

Le menu « Écran (P) » regroupe les commandes sur les écrans : Nouvel écran, Propriétés de l'écran (P) et Supprimer l'écran (D)

<img src="../../../../getting-started/window/editview/menu.files/menu12542.png" width="192" />

Figure 2-33        Menu « Écran »

• Nouvel écran : crée un écran dans le projet courant.

• Propriétés de l'écran : ouvre les propriétés de l'écran courant pour régler son nom et son fond.

• Supprimer l'écran : supprime l'écran courant.

<img src="../../../../getting-started/window/editview/menu.files/menu12848.png" width="130" />

Vérifiez que l'écran courant est bien celui à supprimer et qu'il ne contient pas d'objets utiles : l'opération est irréversible.

**Menu Paramètres**

Le menu « Paramètres (s) » contient les commandes suivantes : Préférences (P), Protection du fichier (M), Éditeur de macros, Macro globale, Macro d'initialisation et Ajouter un clavier personnalisé.

<img src="../../../../getting-started/window/editview/menu.files/menu13188.png" width="217" />

Figure 2-34        Menu « Paramètres »

• Préférences : ouvre la fenêtre des préférences, où l'on modifie le modèle d'IHM, l'orientation, l'écran de démarrage, le délai de l'économiseur d'écran, la fréquence de clignotement, le son d'alarme, le son au toucher, les mots de passe et le niveau initial.

• Protection du fichier : ouvre la fenêtre de mot de passe pour protéger le fichier du projet courant.

• Éditeur de macros : ouvre l'éditeur de macros, où l'on ajoute, modifie, compile ou supprime des macros.

• Macro globale : ouvre la fenêtre de réglage des macros globales.

• Macro d'initialisation : ouvre la fenêtre de réglage des macros d'initialisation.

• Ajouter un clavier personnalisé : ouvre un clavier défini par l'utilisateur.

<img src="../../../../getting-started/window/editview/menu.files/menu14111.png" width="130" />

Retenez bien le mot de passe : il est nécessaire pour ouvrir le fichier de projet une fois défini. Il est sensible à la casse.

**Menu Téléchargement**

Le menu « Téléchargement » sert à compiler et télécharger le projet ; il contient huit commandes : Compiler (C), Simulation hors ligne (M), Simulation en ligne, Téléchargement USB (D), Upload, Compresser/Décompresser, Extraire le projet et enregistrer sous, et Extraire le projet de simulation à distance (A). Une fois le PC relié à l'écran tactile par câble USB, le projet peut être téléchargé dans l'écran tactile par USB, après avoir été compilé.

<img src="../../../../getting-started/window/editview/menu.files/menu14738.png" width="346" />

Figure 2-35        Menu « Téléchargement »

• Compiler : vérifie le projet créé par l'utilisateur et le prépare au téléchargement.

• Simulation hors ligne : lance l'application de configuration CommandHMI et ouvre la fenêtre de simulation. L'utilisateur peut simuler sur le PC le projet en cours pour en observer le comportement et corriger les écrans. Enregistrez le projet avant la simulation hors ligne.

• Simulation en ligne : lance l'application de configuration CommandHMI et ouvre le panneau de simulation ; l'utilisateur peut simuler sur le PC le projet en cours pour en observer le comportement et corriger les écrans. En simulation en ligne, on peut aussi utiliser le port Ethernet ou série du PC pour communiquer avec les équipements connectés et tester la communication. Enregistrez le projet avant la simulation en ligne.

• Téléchargement USB : télécharge dans l'IHM, par le câble USB fourni avec l'écran tactile, le projet compilé par CommandHMI. Compilez et enregistrez le projet avant le téléchargement.

• Upload : transfère de l'IHM vers le PC, par le câble USB fourni, les données historiques, la configuration, les recettes et l'historique des alarmes.

• Compresser/Décompresser : compresse le projet en un fichier XXX.vpr, ou décompresse un fichier compressé en fichier de projet .vpm.

• Extraire le projet et enregistrer sous : compile le projet courant en un fichier binaire nommé u-disk-prj.bin. Enregistré sur une clé USB, il permet de mettre à jour l'IHM automatiquement, sans câble USB.

**Menu contextuel (clic droit)**

Le menu contextuel facilite le travail, conformément aux habitudes de la plupart des utilisateurs de Windows. De nombreuses fonctions de configuration y figurent : Propriétés, Objets, Bibliothèque, Couper, Copier, Copie multiple, Coller, Supprimer, Tout sélectionner, Alignement, Plans, Grouper, Zoom, Grille, Écran.

<img src="../../../../getting-started/window/editview/menu.files/menu17926.png" width="176" />

Figure 2-40        Menu contextuel

• Propriétés : ouvre la fenêtre de propriétés d'un objet (si un seul objet est sélectionné) ou de l'écran (si aucun objet n'est sélectionné).

• Objet : donne accès à tous les objets du menu Objet.

• Bibliothèque : ouvre la bibliothèque ou crée des images.

• Couper : raccourci Ctrl + X ; supprime les objets sélectionnés et les copie dans le presse-papiers.

• Copier : raccourci Ctrl + C ; copie l'objet choisi dans le presse-papiers.

• Copie multiple : copie plusieurs fois les objets sélectionnés horizontalement et verticalement, avec des adresses incrémentées de 0 à 255 unités.

• Coller : raccourci Ctrl + V ; colle les objets du presse-papiers dans l'écran courant.

• Supprimer : touche Suppr ; retire les objets sélectionnés de l'écran.

• Tout sélectionner : raccourci Ctrl + A ; sélectionne tous les objets de l'écran courant.

• Alignement : aligne les objets sélectionnés (au moins deux) selon le type choisi : Haut, Bas, Centre vertical, Gauche, Droite, Espacement horizontal égal, Espacement vertical égal, Même largeur, Même hauteur, Même largeur et hauteur.

• Plans : place les objets sélectionnés sur un autre plan : Premier plan, Avancer d'un plan, Arrière-plan ou Reculer d'un plan.

• Grouper : réunit plusieurs objets sélectionnés (au moins deux) en un seul objet, ou décompose un objet groupé en ses éléments d'origine.

<img src="../../../../getting-started/window/editview/menu.files/menu19697.png" width="130" />

Ne groupez pas d'objets tactiles : une fois chargés dans l'écran tactile, ils ne réagiraient plus au toucher. Pour superposer des objets tactiles, utilisez plutôt les plans.

• Zoom : agrandit ou réduit l'affichage de l'écran courant pour un travail plus précis : Zoom avant, Ajuster, Zoom arrière.

• Grille : affiche ou masque une grille de pas défini dans l'écran courant.

• Écran : crée un écran, ouvre les propriétés de l'écran ou supprime un écran.

<img src="../../../../getting-started/window/editview/menu.files/menu20284.png" width="130" />

Vérifiez que l'écran courant est bien celui à supprimer et qu'il ne contient pas d'objets utiles : l'opération est irréversible.
