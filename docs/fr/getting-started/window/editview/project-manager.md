# Gestionnaire de projet

La fenêtre Gestionnaire de projet de CommandHMI se trouve à gauche de la fenêtre du logiciel, sous la barre d'outils. On y règle les paramètres de l'écran tactile : multilingue, Connexion, Paramètres, Écran, Fenêtre, Collecteur de données historiques, Alarmes, Recettes, Transmission de données et Macros ; Connexion comprend les réglages Connexion 1 et Connexion 2, et Paramètres comprend Paramètres IHM, État IHM, Contrôle par automate, Horloge, Chiffrement du fichier, Protection IHM et Table des variables.
