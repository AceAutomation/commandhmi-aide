# Barre d'outils standard

CommandHMI propose une série de boutons d'outils, certains pour les commandes d'outils, d'autres pour l'édition. Une fois familiarisé avec ces boutons, vous accédez directement aux commandes sans passer par la barre de menus. Une info-bulle s'affiche quand la souris survole un bouton. CommandHMI propose 55 boutons d'outils, grisés lorsque l'opération n'est pas disponible dans le contexte courant.

Chaque commande de la barre d'outils correspond à une commande des menus ; leurs fonctions sont les suivantes :

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar654.png" width="35" /> Ouvrir un projet : raccourci Ctrl + O ; ouvre un fichier de projet existant d'extension .vpm.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar781.png" width="27" /> Nouvel écran : crée un écran dans le projet courant.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar863.png" width="34" />Enregistrer : raccourci Ctrl + S ; enregistre la configuration modifiée sous le même nom et dans le même répertoire.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1027.png" width="38" /> Annuler : raccourci Ctrl + Z ; annule la dernière opération.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1119.png" width="36" /> Rétablir : raccourci Ctrl + Y ; rétablit la dernière opération annulée.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1212.png" width="29" /> Couper : raccourci Ctrl + X ; supprime les objets sélectionnés et les copie dans le presse-papiers.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1325.png" width="33" /> Copier : raccourci Ctrl + C ; copie les objets sélectionnés dans le presse-papiers.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1514.png" width="30" /> Supprimer : touche Suppr ; retire les objets sélectionnés de l'écran.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1582.png" width="32" /> Grouper : réunit plusieurs objets sélectionnés en un seul objet.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1675.png" width="31" /> Dissocier : décompose un objet groupé en ses objets d'origine ; c'est l'opération inverse de Grouper.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1836.png" width="34" /> Retournement horizontal : retourne horizontalement un ou plusieurs graphiques.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar1942.png" width="38" /> Retournement vertical : retourne verticalement un ou plusieurs graphiques.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2044.png" width="29" /> Grille : affiche ou masque une grille de pas défini dans l'écran courant.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2142.png" width="37" /> Zoom avant : agrandit deux fois l'écran courant ; répétez la commande pour agrandir davantage.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2279.png" width="34" /> Ajuster : ramène l'écran courant à sa taille normale.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2364.png" width="30" /> Zoom arrière : réduit de moitié l'écran courant ; répétez la commande pour réduire davantage.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2498.png" width="94" /> Langue : choisit la langue voulue.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2564.png" width="88" /> Liste des états : si un objet à états est sélectionné, la liste affiche son numéro d'état ; en changeant le numéro, l'objet passe à l'état correspondant.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2787.png" width="90" />Liste des écrans : passe à l'écran que vous voulez voir.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2862.png" width="32" /> Propriétés : affiche les propriétés de l'objet sélectionné.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar2947.png" width="30" /> Verrouiller : verrouille l'objet sélectionné dans l'écran ; il ne peut plus être déplacé.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3055.png" width="35" /> Déverrouiller : supprime le verrouillage des objets de l'écran.

<img src="../../../../getting-started/window/editview/toolbar.files/image001.jpg" width="33" alt="ScreenShot00089.jpg" />Rechercher/remplacer : cliquez sur ce bouton pour trouver toutes les utilisations d'un registre donné et les remplacer par un autre

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3127.png" width="31" /> Rechercher une adresse : vérifie si une adresse est utilisée ; les résultats s'affichent dans la « fenêtre de sortie ».

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3280.png" width="38" /> Affichage des adresses : parcourt les adresses utilisées par tous les objets d'un écran ou de tous les écrans.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3537.png" width="33" /> Gestionnaire de macros : affiche l'utilisation des macros par tous les objets d'un écran ou de tous les écrans.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3862.png" width="32" /> Simulation en ligne : lance directement la simulation en ligne.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar3947.png" width="35" /> Compiler : vérifie le projet de l'utilisateur et le prépare au téléchargement.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar4052.png" width="28" /> Télécharger : ouvre la fenêtre de téléchargement ; une fois l'IHM série HM reliée au PC, le projet peut être téléchargé dans l'écran tactile.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar4215.png" width="39" /> Upload : transfère d'une IHM en fonctionnement vers le PC, par le câble USB fourni, les données historiques, la configuration, les recettes et l'historique des alarmes.

Plans : liste déroulante de quatre commandes : Premier plan, Arrière-plan, Avancer d'un plan et Reculer d'un plan

• Premier plan (F) : place l'objet sélectionné au premier plan de l'écran.

• Arrière-plan : place l'objet sélectionné à l'arrière-plan de l'écran.

• Avancer d'un plan : avance l'objet sélectionné d'un plan.

• Reculer d'un plan (B) : recule l'objet sélectionné d'un plan.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar4908.png" width="109" />

Taille : liste déroulante de trois commandes : Même largeur et hauteur, Même hauteur, Même largeur.

• Même largeur : donne à un groupe d'objets sélectionnés la largeur de l'objet marqué de points noirs.

• Même hauteur : donne à un groupe d'objets sélectionnés la hauteur de l'objet marqué de points noirs.

• Même largeur et hauteur : donne à un groupe d'objets sélectionnés la largeur et la hauteur de l'objet marqué de points noirs.

<img src="../../../../getting-started/window/editview/toolbar.files/toolbar5406.png" width="292" />

Alignement : liste déroulante de huit commandes : Gauche, Droite, Centre vertical, Centre horizontal, Haut, Bas, Espacement horizontal égal et Espacement vertical égal.

• Gauche : raccourci Ctrl + Gauche ; aligne les bords gauches des objets sélectionnés.

• Droite : raccourci Ctrl + Droite ; aligne les bords droits des objets sélectionnés.

• Haut : raccourci Ctrl + Haut ; aligne les bords supérieurs des objets sélectionnés.

• Bas : raccourci Ctrl + Bas ; aligne les bords inférieurs des objets sélectionnés.

• Centre horizontal : aligne les objets sélectionnés sur leur centre horizontal.

• Centre vertical : aligne les objets sélectionnés sur leur centre vertical.

• Espacement horizontal égal : répartit deux objets ou plus avec un espacement horizontal égal.

• Espacement vertical égal : répartit deux objets ou plus avec un espacement vertical égal.
