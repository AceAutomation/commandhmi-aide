# Composition du système

CommandHMI est le logiciel d'édition de configuration des IHM CommandHMI. Le concepteur édite la configuration sur le PC, puis la télécharge, avec le pilote de communication nécessaire, dans la mémoire de l'écran tactile par câble USB ; reliée à des automates ou autres équipements par ses ports de communication, l'IHM permet alors la commande et la surveillance.
