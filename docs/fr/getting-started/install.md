# Installation du logiciel

CommandHMI est une application conçue pour Microsoft Windows. Avant l'installation, vérifiez que l'ordinateur répond à la configuration matérielle et logicielle minimale.

Lancez le programme d'installation de CommandHMI fourni avec le produit. Procédure :

Téléchargez le programme d'installation sur le site officiel ;

![2018_11_19_19_32_06.jpg](../../getting-started/install.files/setup.png)

Figure 2-1      Programme d'installation de CommandHMI

Double-cliquez sur le programme : la fenêtre d'installation de CommandHMI s'ouvre.

La première boîte de dialogue est « Contrat de licence » ; choisissez « Suivant » pour poursuivre l'installation ou « Annuler » pour quitter, comme sur la figure 2-2.

Choisissez « J'accepte le contrat », puis cliquez sur Suivant.

<img src="../../getting-started/../image/2025-10-11/setup-1.png" width="513" alt="ScreenShot00201.jpg" />

Figure 2-2      Boîte de dialogue Contrat de licence

Dans la boîte « Dossier de destination », choisissez le dossier d'installation. Par défaut : « C:\Program Files (x86)\CommandHMI » ; cliquez sur Parcourir... pour choisir un autre chemin, puis sur Suivant

  <img src="../../getting-started/../image/2025-10-11/setup-3.png" width="513" alt="ScreenShot00202.jpg" />

Figure 2-5      Choix du chemin d'installation

Cliquez sur Suivant (figure 2-5) : une page permet de choisir l'emplacement des fichiers, par défaut ou autre ; cliquez sur Suivant, comme sur la figure 2-6 :

<img src="../../getting-started/../image/2025-10-11/setup-3.1.png" width="513" alt="ScreenShot00203.jpg" />

Figure 2-6      Page des fichiers d'installation

Page de création du raccourci sur le bureau ; cliquez sur Suivant, comme sur la figure 2-7 :

<img src="../../getting-started/../image/2025-10-11/setup-4.png" width="513" alt="ScreenShot00204.jpg" />

Figure 2-7      Création d'un raccourci sur le bureau

La page de confirmation récapitule trois éléments : le chemin d'installation, les fichiers installés et la création ou non d'un raccourci.

  <img src="../../getting-started/../image/2025-10-11/setup-5.png" width="513" alt="ScreenShot00205.jpg" />

Figure 2-8      Page de confirmation de l'installation

Page d'installation ; cliquez sur Annuler pour annuler l'installation, comme sur la figure 2-9 :

<img src="../../getting-started/../image/2025-10-11/setup-6.png" width="513" alt="ScreenShot00206.jpg" />

Figure 2-9      Page d'installation

Une fois le pilote installé, la page de fin d'installation s'affiche ; cliquez sur Terminer pour fermer l'assistant, comme sur la figure 2-10 :

<img src="../../getting-started/../image/2025-10-11/setup-8.png" width="513" alt="ScreenShot00207.jpg" />

Figure 2-10    Fin de l'installation

Après l'installation, l'icône HMITOOL6.2 apparaît sur le bureau, comme sur la figure 2-11 :
