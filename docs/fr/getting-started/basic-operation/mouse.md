# Utilisation de la souris et raccourcis clavier

Pour créer des écrans dans l'éditeur de configuration, la souris est utilisée comme sur la figure 2-45 :

<img src="../../../getting-started/basic-operation/mouse.files/image010.jpg" width="318" />

Figure 2-45        Schéma de la souris

Voici les principales actions de la souris et leur usage :

◎ Clic gauche

Appuyez sur le bouton gauche puis relâchez<span id="OLE_LINK219"></span><span id="OLE_LINK218"></span> — appelé \[cliquer\] dans ce manuel ; sert à choisir dans un menu, sélectionner un objet, choisir un bouton d'outil, éditer un écran, valider un réglage.

◎ Double-clic gauche

Appuyez deux fois rapidement sur le bouton gauche — appelé \[double-cliquer\] dans ce manuel ; sert à régler les propriétés des éléments de l'écran : propriétés de l'écran et des fenêtres, de la connexion de l'écran tactile, réglages ; et à modifier le collecteur de données historiques, les recettes, les alarmes et d'autres options.

◎ Clic droit

Appuyez sur le bouton droit puis relâchez — appelé \[clic droit\] dans ce manuel. Un clic droit sur un élément ouvre son menu contextuel, un clic droit dans une zone vide ouvre le menu contextuel général. Il permet aussi de quitter le mode d'édition en cours et de rétablir le curseur.

◎ Glisser

Déplacez la souris en maintenant le bouton enfoncé — appelé \[glisser\] dans ce manuel ; permet de sélectionner plusieurs éléments, de déplacer des éléments ou des fenêtres d'édition.

### <span id="OLE_LINK225"></span><span id="OLE_LINK224"></span>Raccourcis clavier

Le tableau 2-2 ci-dessous liste les raccourcis clavier courants, qui permettent d'accélérer la configuration.

|                   |                                                     |
|-------------------|-----------------------------------------------------|
| CTRL+C            | Copier                                              |
| CTRL+V            | Coller                                              |
| CTRL+X            | Couper                                              |
| CTRL+F            | Aller à un écran                                    |
| CTRL + glisser    | Copier l'objet sélectionné et le déplacer           |
| CTRL + clic gauche | Sélectionner plusieurs objets                      |
| ← → ↑ ↓           | Déplacer l'objet sélectionné à gauche, à droite, en haut, en bas |
| ESC               | Annuler l'opération                                 |
|                   | Supprimer                                           |
