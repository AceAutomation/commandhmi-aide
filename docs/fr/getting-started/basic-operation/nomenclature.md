# Termes courants

Le tableau 2-3 ci-dessous présente quelques termes courants de l'édition de configuration.

|                   |                                                                                                                                                                                                                                                                                                                                 |
|-------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Projet            | Désigne l'application de l'utilisateur. La notion de projet rend l'informatique complexe plus accessible aux ingénieurs. Les fichiers créés dans CommandHMI ont l'extension .vpm et peuvent être enregistrés à n'importe quel emplacement.                                                                                       |
| Objet             | Ensemble des éléments manipulés et de leur environnement : fenêtres, composants, données, graphiques, etc.                                                                                                                                                                                                                      |
| Sélectionner l'objet | Rendre une fenêtre ou un objet manipulable par un clic de souris ; l'objet sélectionné (y compris une fenêtre) est appelé objet courant                                                                                                                                                                                       |
| Configuration     | Définir, créer et éditer des objets dans une fenêtre et régler leurs paramètres d'état (attributs)                                                                                                                                                                                                                              |
| Attribut          | Nom, type, état, propriétés et usage d'un objet, désignés collectivement par le terme attribut                                                                                                                                                                                                                                  |
| Menu              | <span id="OLE_LINK237"></span><span id="OLE_LINK236"></span>Ensemble de commandes. Par exemple, le menu « Fichier » regroupe les commandes liées aux fichiers de projet. Les menus de CommandHMI sont tous déroulants et peuvent comporter plusieurs niveaux de sous-menus |
| Bouton de commande | Bouton qui exécute une commande, situé dans la barre d'outils ou la barre de menus                                                                                                                                                                                                                                             |
| Mise à ON         | Fait passer un objet à affichage d'état de bit à l'état « ON »                                                                                                                                                                                                                                                                  |
| Mise à OFF        | Fait passer un objet à affichage d'état de bit à l'état « OFF »                                                                                                                                                                                                                                                                 |
| Style             | Effet de dégradé de l'objet, de la couleur de premier plan à la couleur de fond                                                                                                                                                                                                                                                 |
| Adresse           | Variables mémoire associées à l'objet courant                                                                                                                                                                                                                                                                                   |
| Équipement connecté | Équipements communicants connectés au projet courant                                                                                                                                                                                                                                                                          |
| Objet (contrôle)  | <span id="OLE_LINK231"></span><span id="OLE_LINK230"></span>Ensemble de fonctions particulières                                                                                                                                                                                                                                 |
