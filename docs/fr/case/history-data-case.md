# Exemple de collecte de données historiques

L'exemple suivant illustre l'utilisation combinée du collecteur de données historiques, de l'affichage des données historiques et de la courbe de tendance historique.

**1. Créer un collecteur de données historiques**

Faites un clic droit sur « Collecteur de données historiques » dans le « Gestionnaire de projet » pour en créer un, comme sur la figure 1 ci-dessous

<img src="../../case/history-data-case.files/image002.jpg" width="362" />

Figure 1 Créer un collecteur de données historiques

**2. Paramétrage du collecteur de données historiques**

Double-cliquez pour ouvrir le collecteur de données historiques, comme sur la figure 2

Figure 2 Paramètres généraux du collecteur de données historiques

Nous ajoutons ici cinq éléments de collecte nommés « Data1 », « Data2 », « Data3 », « Data4 » et « Data5 », aux adresses « LW0 », « LW1 », « LW3 », « LW5 », « LW6 » ; le type de données et le nom de chacun sont définis comme sur la figure 3. Data2 et Data3 étant sur 32 bits, chaque échantillon lit les registres « LW0 », « LW1 + LW2 », « LW3 + LW4 », « LW5 » et « LW6 ». Le nombre total d'échantillons est ici de 1000 : 1000 échantillons sont pris jusqu'à ce que la mémoire soit pleine.

 <img src="../../case/history-data-case.files/image004.jpg" width="627" />

Figure 3 Paramétrage des données du collecteur de données historiques

Cliquez sur « OK » ; pour visualiser les données historiques, utilisez ensuite l'« Affichage des données historiques ».

**3. Paramétrage de l'affichage des données historiques :**

<img src="../../case/history-data-case.files/image005.jpg" width="592" />

Figure 4 Paramètres généraux de l'affichage des données historiques

Choisissez cinq lignes d'affichage ; police et fond sont libres.

<img src="../../case/history-data-case.files/image006.jpg" width="592" />

Figure 5 Paramétrage des données de l'affichage des données historiques

Cochez les données à afficher et cliquez sur « OK » : un tableau apparaît à l'écran, comme ci-dessous :

<img src="../../case/history-data-case.files/image007.jpg" width="482" />

Figure 6 Affichage des données historiques à l'écran
