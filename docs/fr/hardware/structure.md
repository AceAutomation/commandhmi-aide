# Structure de l'IHM

Les IHM CommandHMI de la série HM se composent d'une zone d'affichage, de voyants, d'une interface d'alimentation et de ports de communication. La couleur de tous les modèles respecte les normes de design industriel, avec une bonne résistance aux salissures pour les environnements d'usine difficiles ; les voyants de la face avant permettent de vérifier l'état de l'appareil. L'alimentation et les ports de communication sont situés en bas de l'IHM.

<img src="../../hardware/structure.files/image002.jpg" width="838" />

• Port Ethernet : raccordement du câble Ethernet

• USB-B : insertion de la clé USB

• USB-A : liaison avec le PC ; téléchargement de la configuration du PC vers l'IHM

• Port de communication : communication avec l'automate
