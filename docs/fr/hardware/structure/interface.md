# Port de communication

Les ports de communication de l'IHM sont situés sur la face inférieure.

Avec un câble blindé, la distance de communication RS232 ne doit pas dépasser 15 mètres. Pour la liaison avec l'ordinateur, un port USB sert au téléchargement de la configuration (transfert de données), jusqu'à 10 Mbit/s. Le brochage du port de communication dépend de l'automate connecté (précisez le type d'automate à la commande pour obtenir le bon câble).
